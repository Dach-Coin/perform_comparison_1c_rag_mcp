## 2. Регистры сведений

### 2.1. ДействияЗадач
**Режим записи:** Подчинение регистратору (Документ.ДействиеЗадачи)  
**Периодичность:** Непериодический

**Измерения/ресурсы:**
| Поле | Тип | Роль |
|------|-----|------|
| ДействиеЗадачи | ДокументСсылка.ДействиеЗадачи | Измерение |
| Исполнитель | ОпределяемыйТип.УчастникЗадач | Измерение |
| Задача | ДокументСсылка.Задача | Ресурс |
| ВидДействия | СправочникСсылка.ВидыДействийЗадач | Ресурс |
| РезультатДействия | СправочникСсылка.РезультатыДействийЗадач | Ресурс |

**Назначение:** Витрина актуального состояния каждого действия задачи для быстрого доступа. Дополнительные поля (ЕстьПодзадачи, Трудозатраты, СостояниеКонтроля, КонтрольныйСрок, ЕстьЗамещающие) заполняются методами ОбновитьДанныеДействия/ОбновитьДанныеЗадачи.

---

### 2.2. ВсеИсполнителиДействийЗадач
**Режим записи:** Независимый  
**Периодичность:** Непериодический

**Измерения:**
| Поле | Тип | Признак |
|------|-----|---------|
| ДействиеЗадачи | ДокументСсылка.ДействиеЗадачи | Ведущее |
| Исполнитель | ОпределяемыйТип.УчастникЗадач | Ведущее |
| Основание | СправочникСсылка.ЗамещающиеИПомощники | Ведущее |

**Назначение:** Хранит всех фактических исполнителей действия задачи — основного и всех его замещающих/помощников. Используется для настройки прав доступа.

---

### 2.3. ЗадачиПоАвторам
**Режим записи:** Подчинение регистратору (Документ.Задача)  
**Периодичность:** Непериодический

**Ключевые поля:**
| Поле | Тип | Назначение |
|------|-----|------------|
| Автор | ОпределяемыйТип.УчастникЗадач | Автор задачи |
| Задача | ДокументСсылка.Задача | Ссылка на задачу |
| ВидСостоянияЗадачи | ПеречислениеСсылка.ВидыСостоянийЗадач | Текущий вид состояния |
| ВРаботе | Булево | Флаг "В работе" |
| Выполнена | Булево | Флаг "Выполнена" |
| Новая | Булево | Флаг "Новая" |
| ОжидаетВыполнения | Булево | Флаг "Ожидает выполнения" |
| ОжидаетПроверки | Булево | Флаг "Ожидает проверки" |
| Просрочена | Булево | Флаг "Просрочена" |
| ПросроченаИОжидаетВыполнения | Булево | Флаг "Просрочена и ожидает выполнения" |
| ЭтоЧерновик | Булево | Флаг "Это черновик" |
| МожетБытьПросрочена | Булево | Флаг потенциальной просрочки |
| КонтрольныйСрок | Дата | Срок контроля |
| Трудозатраты | Число(10,2) | Фактические трудозатраты |
| РезультатЗадачи | СправочникСсылка.РезультатыЗадач | Результат выполнения |

**Назначение:** Основная витрина для отображения задач автору — содержит денормализованное состояние задачи.

---

### 2.4. ИсторияЗадач
**Режим записи:** Независимый  
**Периодичность:** Непериодический

**Поля:**
| Поле | Тип |
|------|-----|
| Задача | ДокументСсылка.Задача |
| ДействиеЗадачи | ДокументСсылка.ДействиеЗадачи |
| Дата | Дата(ДатаВремя) |
| Событие | СправочникСсылка.СобытияЗадач |
| Автор | СправочникСсылка.Сотрудники/Пользователи |
| Контекст | ХранилищеЗначения |

**Назначение:** Хронологическая история изменений задачи (события: ИзмененаЗадача, Закрыта, ЗакрытаПодзадача и др.).

---

### 2.5. ПоступившиеОбновленияЗадач
**Режим записи:** Независимый  
**Периодичность:** Секунда

**Поля:**
| Поле | Тип |
|------|-----|
| ДействиеЗадачи | ДокументСсылка.ДействиеЗадачи |
| СобытиеОбновления | СправочникСсылка.СобытияОбновленияЗадач |

**Назначение:** Оперативные уведомления исполнителям об изменениях в задаче в реальном времени (периодичность — секунда).

## 3. Код, записывающий в регистры

### 3.1. ОбработкаПроведения документа Задача
**Файл:** `/app/code/Documents/Задача/Ext/ObjectModule.bsl`, строки 2698–2727

```bsl
Процедура ОбработкаПроведения(Отказ, Режим)

    КэшируемыеРеквизитыЗадачи = РегистрыНакопления.КоличествоЗадач.КэшируемыеРеквизитыЗадач();
    ОбщегоНазначенияДокументооборот.ДополнитьОтслеживаемыеРеквизиты(
        КэшируемыеРеквизитыЗадачи,
        РегистрыСведений.ЗадачиПоАвторам.КэшируемыеРеквизитыЗадач());
    РеквизитыЗадачи = Новый Структура(КэшируемыеРеквизитыЗадачи);
    ЗаполнитьЗначенияСвойств(РеквизитыЗадачи, ЭтотОбъект, КэшируемыеРеквизитыЗадачи);

    // Количество задач.
    Движения.КоличествоЗадач.Записывать = Истина;
    Движение = Движения.КоличествоЗадач.Добавить();
    Движение.Регистратор = Ссылка;
    Движения.КоличествоЗадач.ОбновитьДанныеЗадачи(РеквизитыЗадачи);

    // Задачи по авторам.
    Движения.ЗадачиПоАвторам.Записывать = Истина;
    Движение = Движения.ЗадачиПоАвторам.Добавить();
    Движение.Регистратор = Ссылка;
    Движение.Трудозатраты = Трудозатраты();
    Движение.ЕстьПодзадачи = РаботаСЗадачами.ЕстьПодзадачи(Ссылка);
    ПараметрыКонтроляДляКэша = Справочники.Контроль.ПараметрыКонтроляДляКэша(Ссылка);
    Движение.СостояниеКонтроля = ПараметрыКонтроляДляКэша.СостояниеКонтроля;
    Движение.КонтрольныйСрок = ПараметрыКонтроляДляКэша.СрокИсполнения;
    Движение.КонтрольныйСрокОбщий = ПараметрыКонтроляДляКэша.СрокИсполненияОбщий;
    Движения.ЗадачиПоАвторам.ОбновитьДанныеЗадачи(РеквизитыЗадачи);

    МоиДокументыСобытия.ДобавлениеВМоиДокументыПриПроведении(ЭтотОбъект, Отказ);

КонецПроцедуры
```

**Регистры:** КоличествоЗадач, ЗадачиПоАвторам (РС)

### 3.2. ОбработкаПроведения документа ДействиеЗадачи
**Файл:** `/app/code/Documents/ДействиеЗадачи/Ext/ObjectModule.bsl`, строки 470–505

```bsl
Процедура ОбработкаПроведения(Отказ, Режим)

    КэшируемыеРеквизитыДействия = РегистрыНакопления.КоличествоДействийЗадач.КэшируемыеРеквизитыДействий();
    ОбщегоНазначенияДокументооборот.ДополнитьОтслеживаемыеРеквизиты(
        КэшируемыеРеквизитыДействия,
        РегистрыСведений.ДействияЗадач.КэшируемыеРеквизитыДействий());
    РеквизитыДействия = Новый Структура(КэшируемыеРеквизитыДействия);
    ЗаполнитьЗначенияСвойств(РеквизитыДействия, ЭтотОбъект, КэшируемыеРеквизитыДействия);

    КэшируемыеРеквизитыЗадачи = РегистрыНакопления.КоличествоДействийЗадач.КэшируемыеРеквизитыЗадач();
    ОбщегоНазначенияДокументооборот.ДополнитьОтслеживаемыеРеквизиты(
        КэшируемыеРеквизитыЗадачи,
        РегистрыСведений.ДействияЗадач.КэшируемыеРеквизитыЗадач());
    РеквизитыЗадачи = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Задача, КэшируемыеРеквизитыЗадачи);

    // Количество действий задач.
    Движения.КоличествоДействийЗадач.Записывать = Истина;
    РегистрыНакопления.КоличествоДействийЗадач.ЗаполнитьНаборПоДействию(
        Движения.КоличествоДействийЗадач, Ссылка, РеквизитыДействия, РеквизитыЗадачи);

    // Действия задач.
    Движения.ДействияЗадач.Записывать = Истина;
    Движение = Движения.ДействияЗадач.Добавить();
    Движение.Регистратор = Ссылка;
    Движение.ЕстьПодзадачи = РаботаСЗадачами.ЕстьПодзадачи(Ссылка);
    Движение.Трудозатраты = Трудозатраты();
    ПараметрыКонтроляДляКэша = Справочники.Контроль.ПараметрыКонтроляДляКэша(Ссылка);
    Движение.СостояниеКонтроля = ПараметрыКонтроляДляКэша.СостояниеКонтроля;
    Движение.КонтрольныйСрок = ПараметрыКонтроляДляКэша.СрокИсполнения;
    Движение.КонтрольныйСрокОбщий = ПараметрыКонтроляДляКэша.СрокИсполненияОбщий;
    Движения.ДействияЗадач.ОбновитьДанныеДействия(РеквизитыДействия);
    Движения.ДействияЗадач.ОбновитьДанныеЗадачи(РеквизитыДействия, РеквизитыЗадачи);

    МоиДокументыСобытия.ДобавлениеВМоиДокументыПриПроведении(ЭтотОбъект, Отказ);

КонецПроцедуры
```

**Регистры:** КоличествоДействийЗадач (РН), ДействияЗадач (РС)

### 3.3. ЗаполнитьНаборПоДействию — логика замещающих
**Файл:** `/app/code/AccumulationRegisters/КоличествоДействийЗадач/Ext/ManagerModule.bsl`, строки 1089–1128

Ключевая часть алгоритма: при заполнении РН КоличествоДействийЗадач дополнительно создаются строки для каждого замещающего исполнителя:

```bsl
// Строка без замещения (основной исполнитель)
ЗаписьБезЗамещения = НаборЗаписей.Добавить();
НаборЗаписей.ОбновитьДанныеДействия(РеквизитыДействия);

// Строки для замещающих
ВсеЗамещенияПоДействию = РегистрыСведений.ВсеИсполнителиДействийЗадач.ЗамещенияПоДействию(ДействиеЗадачи);
Для Каждого СтрокаЗамещения Из ВсеЗамещенияПоДействию Цикл
    ЗаписьПоЗамещению = НаборЗаписей.Добавить();
    ЗаполнитьЗначенияСвойств(ЗаписьПоЗамещению, ЗаписьБезЗамещения);
    ЗаписьПоЗамещению.Замещающий = СтрокаЗамещения.Замещающий;
КонецЦикла;
```

**Файл:** `/app/code/Documents/Задача/Ext/ObjectModule.bsl`  
**Процедура:** `УстановитьСостояние(НовоеСостояниеЗадачи, ОбновитьДействияПоСостоянию)` (строки 1287–1361)

При переходе в состояние "Выполненная":
```bsl

    Справочники.СобытияЗадач.Закрыта,

РегистрыСведений.ИсторияЗадач.Добавить(
    ВышестоящаяЗадача, ВышестоящееДействие,
    ТекущаяДатаСеанса(),
    Справочники.СобытияЗадач.ЗакрытаПодзадача,
    КонтекстПодзадачи, Неопределено);
```

## 4. Как меняются данные при смене статуса задачи

### Жизненный цикл задачи и обновление регистров

```
Черновик
    │  [Задача.ОтправитьНаПроверку / НаправитьНаИсполнение]
    ▼
Новая ──────────────────────────────────────────────────────────────┐
    │  [ДействиеЗадачи.ОтметитьВРаботе]                             │
    ▼                                                                 │
В работе                                                             │
    │  [ДействиеЗадачи.ОтправитьНаПроверку /                        │
    │   ОтметитьОжидаетПроверки]                                     │
    ▼                                                                 │
Ожидает проверки                                                     │
    │  [Задача.ОтметитьПроверено / ОтметитьВозвращеноНаДоработку]   │
    ▼                                                                 │
Выполнена / Закрыта ◄────────────────────────────────────────────── ┘
    │  или [Задача.ОтметитьОтменена]
    ▼
Отменена
```

### Что происходит с регистрами на каждом этапе

| Событие | Регистр | Изменение |
|---------|---------|-----------|
| Создание задачи (Черновик) | КоличествоЗадач | +1 Черновиков |
| КоличествоЗадач | ЗадачиПоАвторам | Запись со флагом ЭтоЧерновик=Истина |
| Направление на исполнение | КоличествоЗадач | −1 Черновиков, +1 Новых |
| ДействиеЗадачи проводится | КоличествоДействийЗадач | +1 Новых (за исполнителя) |
| ДействиеЗадачи проводится | ДействияЗадач | Запись состояния действия |
| ДействиеЗадачи проводится | ВсеИсполнителиДействийЗадач | Строки для исполнителя + замещающих |
| Исполнитель начинает работу | КоличествоДействийЗадач | −1 Новых, +1 ВРаботе |
| Задача переходит В работе | КоличествоЗадач | −1 Новых, +1 ВРаботе |
| Отправка на проверку | КоличествоДействийЗадач | −1 ВРаботе, +1 ОжидающихПроверки |
| Задача на проверке | КоличествоЗадач | −1 ВРаботе, +1 ОжидающихПроверки |
| Завершение задачи | КоличествоЗадач | −все текущие, +1 Выполненных |
| Завершение задачи | ЗадачиПоАвторам | Выполнена=Истина |
| Завершение задачи | ИсторияЗадач | Событие "Закрыта" (+ "ЗакрытаПодзадача" для вышестоящей) |
| Смена реквизитов задачи | ИсторияЗадач | Событие "ИзмененаЗадача" |
| Любое изменение | ПоступившиеОбновленияЗадач | Запись уведомления (реальное время) |
| Отмена задачи | КоличествоЗадач | Перевод в статус Отменена |
| Отмена задачи | ЗадачиПоАвторам | ДатаОтмены + КтоОтменил |
| Просрочка наступила | КоличествоДействийЗадач | ОжидающихВыполнения → Просроченных |

### Алгоритм смены состояния (УстановитьСостояние в модуле Задача)

Процедура `ОбновитьСостоянияПриИзмененииУчастников()` реализует автоматическую смену состояния задачи при изменении участников:

1. **Удалили всех исполнителей** → `УстановитьСостояние(Черновик)`
2. **Добавили исполнителя** → `УстановитьСостояние(Новая)`
3. **Удалили последнего исполнителя, остались ожидающие проверки** → `УстановитьСостояние(НаПроверке)`
4. **Удалили последнего исполнителя, нет ожидающих проверки** → `УстановитьСостояние(Закрыта)`
5. **Добавили проверяющего, задача на проверке/закрыта** → `УстановитьСостояние(НаПроверке)`
6. **Удалили проверяющего, задача на проверке** → `УстановитьСостояние(Закрыта)`

При каждом вызове `УстановитьСостояние()` устанавливается флаг `ОбновитьДействияПоСостоянию`, который в `ПриЗаписи` инициирует перепроведение всех связанных документов ДействиеЗадачи — и тем самым полное обновление регистров КоличествоДействийЗадач и ДействияЗадач.

## 5. Сводная карта регистров

```
Документ.Задача
    ├── РН.КоличествоЗадач           ← счётчики задач по статусам и аналитике
    └── РС.ЗадачиПоАвторам           ← витрина задачи для автора (все флаги состояния)

Документ.ДействиеЗадачи
    ├── РН.КоличествоДействийЗадач   ← счётчики действий по статусам (+ по замещающим)
    └── РС.ДействияЗадач             ← витрина актуального состояния каждого действия

Независимые регистры (обновляются отдельно):
    ├── РС.ВсеИсполнителиДействийЗадач  ← фактические исполнители + замещающие
    ├── РС.ИсторияЗадач                 ← хронология событий
    └── РС.ПоступившиеОбновленияЗадач   ← оперативные уведомления (периодичность: секунда)
```
