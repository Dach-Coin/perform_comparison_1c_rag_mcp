## 1. Регистры накопления

### 1.1 РН КоличествоЗадач
**Категория:** AccumulationRegisters  
**Синоним:** Регистр накопления: Количество задач

**Структура:**
- Измерения (7): Автор, ВидЗадачи, Проект, Флаг, ТипПриложения, ВидПриложения, Контрагент
- Ресурсы (9): ВРаботе, Всего, Выполненных, Новых, ОжидающихВыполнения, ОжидающихПроверки, Просроченных, ПросроченныхОжидающихВыполнения, Черновиков
- Реквизиты: МожетБытьПросрочена, Срок

**Код записи — Documents/Задача/Ext/ObjectModule.bsl:**

```bsl
// ОбработкаПроведения, строки 2707-2711
Движения.КоличествоЗадач.Записывать = Истина;
Движение = Движения.КоличествоЗадач.Добавить();
Движение.Регистратор = Ссылка;
Движения.КоличествоЗадач.ОбновитьДанныеЗадачи(РеквизитыЗадачи);
```

Метод `ОбновитьДанныеЗадачи` (AccumulationRegisters/КоличествоЗадач/Ext/RecordSetModule.bsl, строки 11-63) заполняет ресурсы по текущему ВидСостоянияЗадачи:
- Всего = 1
- ВРаботе = 1 если ЭтоЗадачаВРаботе
- Выполненных = 1 если ЭтоВыполненнаяЗадача
- Новых = 1 если ЭтоНоваяЗадача
- ОжидающихВыполнения = 1 если ЭтоОжидающаяВыполненияЗадача
- ОжидающихПроверки = 1 если ЭтоОжидающаяПроверкиЗадача
- Просроченных = 1 если Просрочена
- Черновиков = 1 если ЭтоЧерновик

**Регламентное обслуживание:** ОбслуживаниеИтоговЗадач (CommonModules/РаботаСЗадачами, строки 6902-6929) пересчитывает итоги регистра по расписанию.

### 1.2 РН КоличествоДействийЗадач
**Категория:** AccumulationRegisters  
**Синоним:** Регистр накопления: Количество действий задач

**Структура:**
- Измерения (10): Исполнитель, Замещающий, Автор, ВидДействия, Проект, Флаг, ТипПриложения, ВидПриложения, ВидЗадачи, Контрагент
- Ресурсы (11): ВРаботе, Всего, ВСрок, Выполненных, Истекающих, Новых, ОжидающихВыполнения, ОжидающихПроверки, ПоступилиОбновления, Просроченных, ПросроченныхОжидающихВыполнения
- Реквизиты: МожетБытьПросрочена, ОписаниеПоступившихОбновлений, Срок

**Код записи — Documents/ДействиеЗадачи/Ext/ObjectModule.bsl:**

```bsl
// ОбработкаПроведения, строки 485-488
Движения.КоличествоДействийЗадач.Записывать = Истина;
РегистрыНакопления.КоличествоДействийЗадач.ЗаполнитьНаборПоДействию(
    Движения.КоличествоДействийЗадач, Ссылка, РеквизитыДействия, РеквизитыЗадачи);
```

**Обновление из документа Задача** (Documents/Задача/Ext/ObjectModule.bsl, ПриЗаписи, строки 2579-2625):
При изменении кэшируемых реквизитов Задачи вызывается:
```bsl
РегистрыНакопления.КоличествоДействийЗадач.ОбновитьДанныеЗадачи(
    АктивноеДействие, ДанныеДействия, РеквизитыЗадачи);
```
для каждого активного действия задачи.

## 2. Регистры сведений

### 2.1 РС ДействияЗадач
**Категория:** InformationRegisters  
**Синоним:** Регистр сведений: Действия задач

**Структура:**
- Измерения (3): Исполнитель, Дата, ДействиеЗадачи
- Ресурсы (40): Автор, ВидДействия, ВидЗадачи, ВидПриложения, ВидСостоянияУчастниковЗадач, ВРаботе, ВСрок, Выполнено, ДатаВыполнения, ДатаНачала, ДатаНачалаУчета, ДатаОкончанияУчета, ДатаСоздания, ЕстьЗамещающие, ЕстьПодзадачи, Заголовок, Задача, Запланировано, Истекает, КоличествоПереносовСроков, КонтрольныйСрок, КонтрольныйСрокОбщий, Новое, ОжидаетВыполнения, ОжидаетПроверки, ОписаниеПоступившихОбновлений, ПоступилиОбновления, Приоритет, Проект, Просрочено, ПросроченоИОжидаетВыполнения, РезультатДействия, СостояниеКонтроля, СостояниеУчастникаЗадачи, Срок, ТипПриложения, ТрудоемкостьДо, ТрудоемкостьОт, Трудозатраты, Флаг
- Реквизиты: МожетБытьПросрочена

**Код записи — Documents/ДействиеЗадачи/Ext/ObjectModule.bsl:**

```bsl
// ОбработкаПроведения, строки 490-501
Движения.ДействияЗадач.Записывать = Истина;
Движение = Движения.ДействияЗадач.Добавить();
Движение.Регистратор = Ссылка;
Движение.ЕстьПодзадачи = РаботаСЗадачами.ЕстьПодзадачи(Ссылка);
Движение.Трудозатраты = Трудозатраты();
Движение.СостояниеКонтроля = ПараметрыКонтроляДляКэша.СостояниеКонтроля;
Движение.КонтрольныйСрок = ПараметрыКонтроляДляКэша.СрокИсполнения;
Движение.КонтрольныйСрокОбщий = ПараметрыКонтроляДляКэша.СрокИсполненияОбщий;
Движения.ДействияЗадач.ОбновитьДанныеДействия(РеквизитыДействия);
Движения.ДействияЗадач.ОбновитьДанныеЗадачи(РеквизитыДействия, РеквизитыЗадачи);
```

**Обновление из документа Задача** (ПриЗаписи, строки 2603-2610):
При изменении кэшируемых реквизитов Задачи:
```bsl
РегистрыСведений.ДействияЗадач.ОбновитьДанныеЗадачи(
    АктивноеДействие, ДанныеДействия, РеквизитыЗадачи);
```

**Обновление подзадач** (ПриЗаписи, строки 2663-2682):
```bsl
РегистрыСведений.ДействияЗадач.ОбновитьПодзадачи(ВышестоящееДействие);
```

### 2.3 РС ИсторияЗадач
**Категория:** InformationRegisters  
**Синоним:** Регистр сведений: История задач

**Структура:**
- Измерения (4): Задача, Событие, Дата, ДействиеЗадачи
- Ресурсы (1): Контекст
- Реквизиты: Автор

**Код записи в нескольких местах:**

```bsl
// Documents/Задача/Ext/ObjectModule.bsl

// 1. При переносе срока задачи (ПриЗаписи, строки 2161-2167)
РегистрыСведений.ИсторияЗадач.Добавить(
    Ссылка,
    Документы.ДействиеЗадачи.ПустаяСсылка(),
    ТекущаяДатаСеанса(),
    Справочники.СобытияЗадач.ПеренесенСрок,
    КонтекстПереносаСрока,
    ПеренесСрок);

// 2. При завершении задачи (УстановитьСостояние, строки 1323-1329)
РегистрыСведений.ИсторияЗадач.Добавить(
    Ссылка,
    Документы.ДействиеЗадачи.ПустаяСсылка(),
    ДатаВыполнения,
    Справочники.СобытияЗадач.Закрыта,
    Неопределено, Неопределено);

// 3. При закрытии подзадачи (УстановитьСостояние, строки 1338-1344)
РегистрыСведений.ИсторияЗадач.Добавить(
    ВышестоящаяЗадача,
    ВышестоящееДействие,
    ТекущаяДатаСеанса(),
    Справочники.СобытияЗадач.ЗакрытаПодзадача,
    КонтекстПодзадачи, Неопределено);

// Documents/ДействиеЗадачи/Ext/ObjectModule.bsl
// 4. При переносе ОсобогоСрока действия (ПриЗаписи, строки 456-462)
РегистрыСведений.ИсторияЗадач.Добавить(
    Задача, Ссылка, ТекущаяДатаСеанса(),
    Справочники.СобытияЗадач.ПеренесенСрок,
    КонтекстПереносаСрока, ПеренесСрок);
```

## 3. Кастомный регистр Теста

### 3.1 РС тст_СрокиИсполненияЗадач (доработка Теста)
**Категория:** InformationRegisters

**Структура:**
- Измерения (1): Задача
- Ресурсы (4): СрокИсполненияДнейПлан, СрокИсполненияДнейФакт, ДосрочноДней, ПросроченоДней

**Код записи** — Tasks/ЗадачаИсполнителя/Ext/ObjectModule.bsl:

```bsl
// 1. ПередЗаписью, строка 252 — при согласовании (ТочкаМаршрута = Согласование):
РегистрыСведений.тст_СрокиИсполненияЗадач.ЗаполнитьДанныеПоСрокамИсполнения(
    Ссылка, Дата, СрокИсполнения, ДатаИсполнения, Ложь); // Ложь = не новая (факт заполнен)

// 2. ПриЗаписи, строка 534 — при создании новой ЗадачаИсполнителя:
РегистрыСведений.тст_СрокиИсполненияЗадач.ЗаполнитьДанныеПоСрокамИсполнения(
    Ссылка, Дата, СрокИсполнения, ДатаИсполнения, Истина); // Истина = новая (факт = NULL)
```

Менеджер-модуль (InformationRegisters/тст_СрокиИсполненияЗадач/Ext/ManagerModule.bsl, строки 1-36):
- При НоваяЗадача=Истина: сохраняет только план (СрокИсполненияДнейФакт=NULL)
- При НоваяЗадача=Ложь: вычисляет фактические дни, просроченность, досрочность
- Автор доработки: Тест Тё, 2022-05-31

## 4. Схема обновления регистров по событиям

### При создании документа Задача (первое проведение)

| Регистр | Метод | Модуль, строки |
|---|---|---|
| РН КоличествоЗадач | ОбработкаПроведения → ОбновитьДанныеЗадачи | ObjectModule.bsl [2708-2711] |
| РС ЗадачиПоАвторам | ОбработкаПроведения → ОбновитьДанныеЗадачи | ObjectModule.bsl [2714-2723] |
| РН КоличествоДействийЗадач | ОбработкаПроведения ДействиеЗадачи | ДействиеЗадачи/ObjectModule.bsl [486-488] |
| РС ДействияЗадач | ОбработкаПроведения ДействиеЗадачи | ДействиеЗадачи/ObjectModule.bsl [491-501] |
| РС ВсеИсполнителиДействийЗадач | ПриЗаписи ДействиеЗадачи (новый исполнитель) | ДействиеЗадачи/ObjectModule.bsl [402-414] |
| РС тст_СрокиИсполненияЗадач | ПриЗаписи ЗадачаИсполнителя (ЭтоНовый=Истина) | ЗадачаИсполнителя/ObjectModule.bsl [534] |

### При изменении задачи

| Событие | Регистр | Метод | Модуль, строки |
|---|---|---|---|
| Изменились реквизиты Задачи | РС ДействияЗадач | ОбновитьДанныеЗадачи | ПриЗаписи [2605-2608] |
| Изменились реквизиты Задачи | РН КоличествоДействийЗадач | ОбновитьДанныеЗадачи | ПриЗаписи [2614-2617] |
| Перенесён срок (Задача) | РС ИсторияЗадач | Добавить(ПеренесенСрок) | ПриЗаписи [2161-2167] |
| Перенесён ОсобыйСрок (ДействиеЗадачи) | РС ИсторияЗадач | Добавить(ПеренесенСрок) | ПриЗаписи [456-462] |
| Изменилась ВышестоящаяЗадача | РС ЗадачиПоАвторам | ОбновитьПодзадачи | ПриЗаписи [2649-2657] |
| Изменилось ВышестоящееДействие | РС ДействияЗадач | ОбновитьПодзадачи | ПриЗаписи [2670-2678] |
| Изменился Исполнитель (ДействиеЗадачи) | РС ВсеИсполнителиДействийЗадач | Записать() | ПриЗаписи [402-414] |
| Изменилось СостояниеУчастника | РС ОчередьОбновленияКэширующихДанных | Добавить | ПриЗаписи [386-389] |

### При завершении задачи (смена статуса → Выполнена/Закрыта)

| Событие | Регистр | Метод | Модуль, строки |
|---|---|---|---|
| УстановитьСостояние → Выполнена | РС ИсторияЗадач | Добавить(Закрыта) | ObjectModule.bsl [1323-1329] |
| УстановитьСостояние → Выполнена (подзадача) | РС ИсторияЗадач | Добавить(ЗакрытаПодзадача) | ObjectModule.bsl [1338-1344] |
| Изменение СостоянияЗадачи | все кэш-регистры | ОбработатьИзменениеСостоянияЗадачи | ПриЗаписи [2684-2685] |
| Выполнение ЗадачаИсполнителя | РС тст_СрокиИсполненияЗадач | ЗаполнитьДанныеПоСрокамИсполнения | ObjectModule.bsl [252] |
| Выполнение действия | РС ПоступившиеОбновленияЗадач | ЗаписатьПоступившиеОбновления | РаботаСЗадачами [12051-12086] |
