## 2. Заполнение при создании

При создании нового ВходящегоПисьма (в ПредЗаписью, стр. 5–47 ObjectModule):

1. **ЭтоНовоеПисьмо** = Ссылка.Пустая() — определяется новизна объекта
2. **НомерСпособаАдресации** — вычисляется через `ВстроеннаяПочтаСервер.ПолучитьСпособАдресацииОбъекта` для новых писем
3. **Папка** — автоматически устанавливается в папку «Входящие» соответствующей учётной записи через `ВстроеннаяПочтаСервер.ПрименитьПредопределенныеПравила` (код стр. 654–698 CommonModules/ВстроеннаяПочтаСервер/Ext/Module.bsl):
   ```
   Если ПисьмоОбъект.ЭтоНовый() И Не ЗначениеЗаполнено(ПисьмоОбъект.Папка) Тогда
       ПисьмоОбъект.Папка = РегистрыСведений.ПапкиУчетныхЗаписей.ПолучитьПапку(
           ПисьмоОбъект.УчетнаяЗапись, Перечисления.ВидыПапокПисем.Входящие);
   КонецЕсли;
   ```
4. **Проверка папки**: если Папка не заполнена — ПередЗаписью выбрасывает исключение «Не указана папка письма» (стр. 42–44)
5. **Применяются правила обработки писем**: `ВстроеннаяПочтаСервер.ПрименитьПравила(ЭтотОбъект)` (стр. 40) — запускает пользовательские правила сортировки

Форма документа при создании (ФормаДокумента/Module.bsl): `ПриСозданииНаСервере` → инициализация элементов формы.

## 4. Регистрация и нумерация входящего письма

Документ `ВходящееПисьмо` как таковой **не содержит регистрационного номера** в собственных реквизитах. Нумерация и регистрация осуществляется через связанный объект:

### 4.1 Карточка ДокументыПредприятия
Справочник `ДокументыПредприятия` является регистрационной карточкой. Ключевые реквизиты регистрации:
- **РегистрационныйНомер** — собственно рег. номер
- **ДатаРегистрации** — дата регистрации
- **Зарегистрировал** (CatalogRef.Сотрудники/Пользователи) — кто зарегистрировал

Реквизит **Предмет** бизнес-процесса «Регистрация» может принимать значение `ДокументСсылка.ВходящееПисьмо` или `СправочникСсылка.ДокументыПредприятия`.

### 4.2 Механизм регистрации через БП «Регистрация»
1. Инициатор запускает БП «Регистрация», указывая предметом `ВходящееПисьмо`
2. Задача назначается регистратору (реквизит Исполнитель БП)
3. Регистратор выполняет задачу в точке маршрута **«Зарегистрировать»** — устанавливает результат регистрации
4. Опционально — задача «Ознакомиться» для автора/руководителя

### 4.3 Настройки вида документа
В справочнике `ВидыДокументов` есть:
- `ЯвляетсяВходящейКорреспонденцией` (Boolean) — помечает вид как входящую корреспонденцию
- `тст_НеобходимаРегистрация` — кастомный реквизит Тест, флаг обязательной регистрации при создании

> Источник: `get_object_full_structure('ДокументыПредприятия')`, `get_object_full_structure('ВидыДокументов')`, `ManagerModule.bsl` стр. 1023–1034

## 5. Обработчики событий ObjectModule

**Файл:** `Documents/ВходящееПисьмо/Ext/ObjectModule.bsl`

### 5.1 ПередЗаписью (строки 5–47)
```bsl
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
```
Действия:
- Пропуск при загрузке обмена (`ОбменДанными.Загрузка`)
- Определение нового письма: `ДополнительныеСвойства.Вставить("ЭтоНовоеПисьмо", Ссылка.Пустая())`
- Для нового письма: установка `НомерСпособаАдресации` через `ВстроеннаяПочтаСервер.ПолучитьСпособАдресацииОбъекта`
- Получение предыдущих значений: `ПометкаУдаления`, `Папка` из базы
- При смене пометки удаления: помечает/снимает пометку с присоединённых файлов (`РаботаСФайламиВызовСервера.ПометитьНаУдалениеПриложенныеФайлы`)
- Проверка прав при смене папки (стр. 29–35): `ПроверитьПравоУдаленияИзПапки`, `ПроверитьПравоДобавленияВПапку`
- Применение правил сортировки: `ВстроеннаяПочтаСервер.ПрименитьПравила(ЭтотОбъект)`
- **Обязательный контроль**: если Папка не заполнена → Отказ = Истина + исключение «Не указана папка письма» (стр. 42–44)

### 5.2 ПриЗаписи (строки 49–107)
```bsl
Процедура ПриЗаписи(Отказ)
```
Действия:
- Пропуск при загрузке обмена
- При изменении Папки или ПометкиУдаления: **обновление РС КоличествоПисемВПапках** (стр. 64–68):
  - Очищает записи старой папки: `РегистрыСведений.КоличествоПисемВПапках.ОчиститьЗаписиПоПапке(ПредыдущаяПапка)`
  - Очищает записи новой папки: `РегистрыСведений.КоличествоПисемВПапках.ОчиститьЗаписиПоПапке(Папка)`
- При изменении пометки удаления: **протоколирование** `ПротоколированиеРаботыСотрудников.ЗаписатьПометкуУдаления` (стр. 77)
- **Расширение рабочей группы предмета** (стр. 80–105):
  - Если предмет ведёт автоматическое заполнение рабочей группы (`РаботаСРабочимиГруппами.ПоОбъектуВедетсяАвтоматическоеЗаполнениеРабочейГруппы`)
  - Запрос к РС `СведенияОбАдресатах` для нахождения сотрудников по адресатам письма (ПолучателиПисьма + ПолучателиКопий)
  - Добавление найденных сотрудников в рабочую группу объекта-предмета

### 5.3 ПередУдалением (строки 217–225)
Стандартный обработчик удаления.
