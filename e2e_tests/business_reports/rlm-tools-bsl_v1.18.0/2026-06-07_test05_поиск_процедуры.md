## Как работает

Процедура выполняет три основных действия:

### 1. Определение подходящих заместителей
Вызывает вспомогательную функцию `ПодходящиеЗамещения(ДействиеЗадачи)` — строка 314. Если заместителей нет, процедура завершается.

### 2. Запись в регистр `ВсеИсполнителиДействийЗадач`
- Добавляет запись для **основного исполнителя** задачи (строки 323-327)
- Для каждого заместителя из результата `ПодходящиеЗамещения` добавляет запись с полем `Основание = Замещение` (строки 329-334)

### 3. Расширение прав на бизнес-процессы и приложения
- Если задача входит в бизнес-процесс — добавляет заместителей в регистр `УчастникиПроцессов` (строки 342-361)
- Если у задачи есть приложения — добавляет заместителей в рабочие группы приложений через `РаботаСРабочимиГруппами.ДобавитьУчастниковВРабочуюГруппуОбъекта` (строки 408-418)

## Вспомогательная функция: `ПодходящиеЗамещения`

| Атрибут | Значение |
|---|---|
| **Имя** | `ПодходящиеЗамещения` |
| **Модуль** | `CommonModules/ЗамещающиеИПомощники/Ext/Module.bsl` |
| **Строки** | 482–613 |
| **Экспорт** | Да |
| **Параметры** | `ДействиеЗадачи`, `ВидЗамещения = Неопределено`, `КешДанных = Неопределено` |

**Сигнатура:**
```bsl
Функция ПодходящиеЗамещения(ДействиеЗадачи, ВидЗамещения = Неопределено, КешДанных = Неопределено) Экспорт
```

**Логика работы:**

Функция строит запрос к `Справочник.ЗамещающиеИПомощники`, соединяя с `РегистрСведений.СотрудникиВКонтейнерах` (для определения контейнера исполнителя). Условия отбора:
- Замещение `Действует = Истина`
- Область замещения (`ВопросыЗамещения`) подходит к типу задачи/документа:
  - `ВсеОбласти` — универсальное замещение
  - `Задачи` / `ЗадачиВыполнениеПрочихПоручений` — для задач без приложений  
  - Конкретная область документа — определяется по приложениям задачи через `Справочник.ОбластиЗамещения.Состав`
  - Область по виду задачи документа — через `ВидыЗадачДокументовПоОбластямЗамещения`
- Опционально: фильтр по `ВидЗамещения` (Замещающие/Помощники)

Возвращает таблицу значений с колонками: `Замещение` (ссылка на ЗамещающиеИПомощники), `Замещающий` (сотрудник).

## Смежная процедура: `ОбновитьДанныеЗадачПоЗамещению`

| Атрибут | Значение |
|---|---|
| **Имя** | `ОбновитьДанныеЗадачПоЗамещению` |
| **Модуль** | `Catalogs/ЗамещающиеИПомощники/Ext/ManagerModule.bsl` |
| **Строки** | 327–535 |
| **Экспорт** | Да |
| **Параметры** | `Замещение` |

Вызывается при **изменении записи замещения** (из `ПриЗаписи` справочника ЗамещающиеИПомощники), а не при назначении задачи. Обновляет регистры `ВсеИсполнителиДействийЗадач` и `ДействияЗадач` для всех активных задач, которые затрагивает данное замещение.

Вызывающие:
- `ПриЗаписи` → `Catalogs/ЗамещающиеИПомощники/Ext/ObjectModule.bsl` стр.84
- `ПриЗаписи` → `InformationRegisters/ИсполнителиРолей/Ext/RecordSetModule.bsl` стр.86
- `ОбновитьДанныеЗадачПоЗамещению` → `CommonModules/ОбработкаОчередиЗаданийСервер` стр.6945 (фоновое задание)

## Итоговая оценка

**ПОЛНОСТЬЮ**

Процедура найдена точно по бизнес-описанию:
- Учитывает замещения сотрудников — через `ПодходящиеЗамещения`, которая анализирует `Справочник.ЗамещающиеИПомощники` с учётом областей замещения
- Работает с ролями исполнителей — через `РС.СотрудникиВКонтейнерах` (контейнеры = роли исполнителей в 1С:ДО)  
- Вызывается при назначении задачи — из `ПриЗаписи` документов `ДействиеЗадачи` и `Задача`

Все факты получены исключительно через MCP rlm-tools-bsl.
