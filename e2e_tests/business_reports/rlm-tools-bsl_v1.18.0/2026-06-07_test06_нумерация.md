## 1. Автоматическая нумерация при создании документа

Нумерация документов в ДО КОРП является **двухэтапной**:

### 1.1 Временный номер (при сохранении до регистрации)

При записи справочника «Документы предприятия» (`Catalogs/ДокументыПредприятия`) в обработчике `ПередЗаписью` (строка 1191) вызывается:

```
Нумерация.УстановитьВременныйНомерПередЗаписью(ЭтотОбъект)
```

**Модуль:** `CommonModules/Нумерация/Ext/Module.bsl`, строки 659–706  
**Логика:** если у `ВидыДокументов.ИспользоватьВременныеНомера = Истина` и реквизит `РегистрационныйНомер` не заполнен, то формируется временный номер — по нумератору с назначением `ВременныйНомер` (перечисление `НазначенияНумераторов`), результат пишется в реквизит `ВременныйНомер`.

### 1.2 Регистрационный номер (при регистрации)

Основной метод: `CommonModules/Делопроизводство/Ext/Module.bsl`, строка 5599:

```
Функция ЗарегистрироватьПредмет(Предмет, СообщениеОбОшибке,
    РегистрационныйНомер = "", ДополнительныеПараметры = Неопределено,
    ЗаписыватьПредмет = Истина) Экспорт
```

Алгоритм:
1. Проверка права: `ДокументооборотПраваДоступа.ЕстьПравоРегистрации(Предмет)`
2. Блокировка объекта
3. Если `РегистрационныйНомер = ""` (автоматическая нумерация):
   - Вызов `НумерацияКлиентСервер.ПолучитьПараметрыНумерации(ПредметОбъект)` → структура параметров
   - Вызов `Нумерация.СформироватьЧисловойНомерДокумента(...)` → заполняет `ЧисловойНомер`
   - Вызов `Нумерация.СформироватьСтроковыйНомерДокумента(...)` → заполняет `РегистрационныйНомер`
4. Иначе: устанавливает переданный номер вручную
5. Устанавливает `Зарегистрировал = Сотрудники.ОсновнойСотрудник()`
6. Устанавливает `ДатаРегистрации = ТекущаяДатаСеанса()`

### 4.2 Синтаксис формата номера

**Модуль:** `CommonModules/Нумерация/Ext/Module.bsl`, функция `РазобратьФорматНомера` (строки 251–408)  
**Функция служебных полей:** `ПолучитьСписокСлужебныхПолей` (строки 1622–1650)

Формат номера — строка вида `{префикс}[СлужебноеПоле]{разделитель}[СлужебноеПоле]{суффикс}`.  
Статичные части между скобками — буквальные строки (префиксы, суффиксы, разделители).

**Доступные служебные поля:**

| Поле | Описание |
|---|---|
| `[День]` | День месяца |
| `[Месяц]` | Номер месяца |
| `[Квартал]` | Номер квартала |
| `[Год4]` | Год 4 знака |
| `[Год2]` | Год 2 знака |
| `[Номер]` | Основной числовой счётчик |
| `[ИндексОрг]` | Индекс организации из РС ИндексыНумерации |
| `[ИндексВидаДок]` | Индекс вида документа |
| `[ИндексПодр]` | Индекс подразделения |
| `[ИндексКонтр]` | Индекс контрагента |
| `[ИндексВопрДеят]` | Индекс вопроса деятельности |
| `[ИндексНомДел]` | Индекс номенклатуры дел |
| `[ИндексОтв]` | Индекс ответственного |
| `[ИндексПроекта]` | Индекс проекта |
| `[ИндексГрифаДоступа]` | Индекс грифа доступа |
| `[ИндексТематики]` | Индекс тематики |
| `[НомерСвязДок]` | Номер связанного документа |
| `[КодУзлаОбмена]` | Код узла обмена КОД |

**Пример формата:** `[ИндексОрг]-[Год4]/[Номер]` → результат вида `Тест-2026/00042`

### 4.3 Алгоритм выбора нумератора

**Модуль:** `CommonModules/Нумерация/Ext/Module.bsl`, функция `ПолучитьНумераторДокумента` (строки 1014–1204)

Из РС «НастройкиНумерации» выбираются все записи с подходящим `ТипДокумента` и `Назначение`. Каждой записи присваивается рейтинг — сумма очков за совпадение каждого из 7 измерений (ВидДокумента, Организация, Подразделение, ВопросДеятельности, Контрагент, Проект, Тематика, ГрифДоступа). Запись с наибольшим рейтингом считается победителем. Это позволяет задать «общий» нумератор (все измерения пусты = 0 очков) и «специальные» с приоритетом.

## 5. Разные схемы нумерации для разных видов документов

**Да, полностью реализовано** через несколько механизмов:

### 5.1 РС «НастройкиНумерации» — основная точка настройки

Для каждого вида документа (измерение `ВидДокумента`) назначается свой нумератор. Одному виду документа можно назначить несколько нумераторов для разных сочетаний аналитик (организация + подразделение + контрагент + проект + гриф + тематика + вопрос деятельности).

**Чтение:** `Нумерация.ПрочитатьНастройкиНумерацииВидаДокумента(ВидДокумента)` (строки 424–449) — запрос к РС НастройкиНумерации.  
**Запись:** `Нумерация.ЗаписатьНастройкиНумерацииВидаДокумента(ВидДокумента, НастройкиНумерации)` (строки 453–473)

### 5.2 Два назначения нумераторов

Перечисление `НазначенияНумераторов`:
- `РегистрационныйНомер` — для основного регистрационного номера
- `ВременныйНомер` — для предварительного номера до регистрации

Таким образом, у одного вида документа может быть отдельный нумератор временного и регистрационного номера.

### 5.3 Флаг «Нумеровать» в РС НастройкиНумерации

Реквизит `Нумеровать` позволяет отключить нумерацию для конкретного сочетания аналитик при сохранении записи в регистре.

### 5.4 Функциональные опции, влияющие на аналитики нумерации

Независимость нумерации по различным аналитикам включается только если соответствующая ФО активна:
- `ИспользоватьУчетПоОрганизациям` → НезависимаяНумерацияПоОрганизациям
- `ИспользоватьГрифыДоступа` → НезависимаяНумерацияПоГрифуДоступа
- `ИспользоватьВопросыДеятельности` → НезависимаяНумерацияПоВопросуДеятельности
- `ВестиУчетПоПроектам` → НезависимаяНумерацияПоПроекту
- `ИспользоватьКОД` → НезависимаяНумерацияПоУзлуКОД
- `ИспользоватьНоменклатуруДел` → [ИндексНомДел] в формате

### 5.5 Кастомизация Тест

- Реквизит `тст_ДлинаЧисловогоНомера` в справочнике «Нумераторы» задаёт ширину числового поля счётчика (с ведущими нулями), добавлен в `CommonModules/Нумерация/Ext/Module.bsl` строки 226–229
- Реквизит вида документа `тст_НеобходимаРегистрация` (Boolean) — признак автоматического запуска регистрации при создании документа
- Кастомные поля `тст_Номер`, `тст_НомерДоговора` в `Catalogs/ДокументыПредприятия` — для хранения внешних номеров контрагента/договора

## 7. Управление пропущенными номерами

При изменении или удалении регистрационного номера документа старый номер освобождается и помещается в РС «ПропускиРегистрационныхНомеров» (строки 1194–1214 в `ПередЗаписью`). Если у нумератора включён флаг `ИспользоватьПропущенныеНомера`, при следующей нумерации сначала проверяется наличие пропущенных номеров (метод `ЕстьПропущенныеНомера`, строка 773; `ТаблицаПропущенныхНомеров`, строка 819).
