# Оценка качества: TEST-06 — Нумерация и регистрация документов
**Сервер:** rlm-tools-bsl (v1.18.0)
**Дата:** 2026-06-07
**Оценщик:** Оркестратор (Claude Opus 4.8, 1M context)

## Общая оценка: ПОЛНОСТЬЮ

Все 5 подвопросов закрыты кодом и структурами: **двухэтапная нумерация** — временный номер (`ВременныйНомер`, `УстановитьВременныйНомерПередЗаписью`) и регистрационный (`РегистрационныйНомер`+`ЧисловойНомер` при БП «Регистрация»); **регистрация = БП Регистрация** (задача регистратору, шаблон `ШаблоныРегистрации`, точки маршрута `ЗарегистрироватьПередСозданиемЗадач`/`ОбработкаРезультатаОбработка`); **хранилище настроек** — РС `НастройкиНумерации` + РС `Нумерация` (счётчики) + справочник `Нумераторы` (формат, периодичность); **формат номера** — `РазобратьФорматНомера` + 18 служебных полей (`[Номер]`, `[День]…[Год4]`, `[ИндексОрг]…[ИндексТематики]`); **разные схемы** — приоритетный выбор нумератора в `ПолучитьНумераторДокумента` (стр. 1014–1204) по числу совпавших аналитик. Прочитан ключевой код: `СформироватьЧисловойНомерДокумента`, `СформироватьСтроковыйНомерДокумента`, `ЗарегистрироватьПредмет`, `ПередЗаписью` `ДокументыПредприятия`.

## Что сервер дал хорошо
- **Чистый прогон**: 100% полезных, 0 шумных, 0 retry — лучшая «гигиена вызовов» раунда наряду с TEST-09.
- **Структуры всех регистров/справочников нумерации** (#7–8): `Нумерация`, `НастройкиНумерации`, `ИндексыНумерации`, `Нумераторы` (включая `тст_ДлинаЧисловогоНомера`) — точные измерения/ресурсы.
- **Алгоритмы формирования номера построчно** (#10–12, #25): `СформироватьЧисловойНомерДокумента`, `РазобратьФорматНомера`, список 18 служебных полей (стр. 1622–1650), `СформироватьСтроковыйНомерДокумента`.
- **Точка присвоения номера** (#16–19): `ПередЗаписью` `ДокументыПредприятия` (стр. 1162/1173/1177) + основной API `ЗарегистрироватьПредмет` (Делопроизводство, стр. 5599) с полным алгоритмом авторегистрации.
- **Приоритетный выбор нумератора** (#27): `ПолучитьНумераторДокумента` — рейтинг по 7 аналитикам, победитель с максимальным `Порядком`.

## Что сервер НЕ дал
- **Конец `ПолучитьНумераторДокумента`** (сортировка УБЫВ) не дочитан — но алгоритм ясен из первых 80 строк.
- **Структура `ВидыДокументов`** дала разовую ошибку вывода (#22) — несущественно, добрано в #23.

## Паттерны поведения агента
- Цикл: `search_objects` → `get_object_full_structure` (регистры/справочники) → `find_exports`/`extract_procedures` (модуль Нумерация) → `read_procedure` (алгоритмы) → БП Регистрация → `ПередЗаписью` ДокументыПредприятия → `ЗарегистрироватьПредмет`.
- 0 retry, 0 шума — образцовая дисциплина.
- Крупнейшие вклады — #17 (`Делопроизводство` exports 8 960 симв) и #16 (ПередЗаписью 6 178), без ⚠️.
