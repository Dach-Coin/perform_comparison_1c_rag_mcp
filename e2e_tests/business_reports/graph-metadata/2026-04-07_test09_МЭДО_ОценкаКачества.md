# Оценка качества: TEST-09 — Интеграция с МЭДО
**Сервер:** 1c-graph-metadata
**Дата:** 2026-04-07
**Оценщик:** Оркестратор (Claude Opus 4.6)

## Общая оценка: ЧАСТИЧНО

## Метрики
| Метрика                | Значение      |
| ---------------------- | ------------- |
| Вызовов MCP            | 30            |
| Полезных               | 22 (73%)      |
| Шумных                 | 8 (27%)       |
| Retry                  | 2             |
| Общее время агента     | ~12.5 мин     |
| Токенов агента (total) | ~67 876       |

## Что сервер дал хорошо
- **Полная карта подсистемы** — 53 объекта метаданных МЭДО по всем категориям через один Cypher-запрос (#4). Ни один другой сервер не дал такой обзор
- **Структура всех 3 документов с типами** через Cypher: 17 реквизитов + 9 ТЧ (47 строк) УведомлениеМЭДО; 18 реквизитов + 1 ТЧ "Пакеты" ДанныеДокументаМЭДО; 14 реквизитов КвитанцияМЭДО
- **Нашёл ТЧ "Пакеты" у ДанныеДокументаМЭДО** с реквизитами ВерсияМЭДО и ИдентификаторСообщения — cloud-embeddings и code-metadata этого не нашли
- **Реквизиты "УдалитьВерсияМЭДО" и "УдалитьИдентификаторСообщения"** в ДанныеДокументаМЭДО — помечены к удалению, перенесены в ТЧ Пакеты (инсайт)
- **Реквизит "ФормулировкаУведомления"** в УведомлениеМЭДО (Строка(1000)) — найден только graph
- **Все 7 перечислений МЭДО** с полными значениями (16 состояний СостоянияДокументовМЭДО, типы уведомлений, версии формата и т.д.)
- **4 регистра сведений** с полной структурой измерений/ресурсов (ЖурналСобытийМЭДО, НастройкиОрганизацийМЭДО, НастройкиКонтрагентовМЭДО, СостоянияДокументовМЭДО)
- **3 справочника** МЭДО с реквизитами
- **4 пакета XDTO** для форматов 2.7/2.7.1
- **5 констант, 1 ФО, 2 роли** подсистемы
- **Подписка на событие** СинхронизироватьДанныеДокументаМЭДО — найдена только graph
- **Жизненный цикл документа** через 16 состояний перечисления — уникальный контент
- **Транспорт: FTP + сетевые каталоги** — подтверждено через Cypher и search_code

## Что сервер НЕ дал
- **business_search** — ошибка `Vector indexer not initialized` (0 вызовов полезных)
- **search_metadata** — требует OpenAI API (недоступен)
- **answer_metadata_question** — вернул нерелевантные результаты (элементы стиля интерфейса, уверенность 50%)
- **Тело процедур** — search_code отдаёт только 3-5 строк превью, полная логика процедур недоступна
- **Детальная цепочка вызовов при отправке** — известны точки входа (МЭДОВызовСервера → МЭДО), но промежуточные процедуры (СоздатьПаспортКонтейнера, ЗаписатьСообщениеПоИсходящему) не раскрыты

## Паттерны поведения агента
- Быстро определил неработоспособность business_search и search_metadata (#1, #2), перешёл на Cypher (#3 — получил схему БД)
- **Cypher-запросы — основная стратегия**: 15 из 30 вызовов. Каждый точно сфокусирован (реквизиты документа, ТЧ, перечисления, регистры, XDTO-пакеты, роли, константы, подписки)
- **search_code** дополнял Cypher, но с ограниченным успехом (превью 3-5 строк недостаточно для понимания логики)
- Наибольшее число вызовов (30), но самый компактный общий объём (~49K символов, ~89K токенов) — Cypher-ответы точные и лаконичные
- Агент систематически обошёл все категории объектов: документы → модули → перечисления → регистры → XDTO → подписки → константы → роли → справочники — методичный подход

## Выявленные проблемы RAG
| Проблема | Проявление в этом тесте |
| -------- | ----------------------- |
| business_search не инициализирован | `Vector indexer not initialized` — семантический поиск по бизнес-вопросам недоступен |
| search_metadata требует OpenAI API | Без внешнего API семантический поиск метаданных невозможен, только Cypher |
| answer_metadata_question нерелевантен | Вернул элементы стиля интерфейса вместо информации о МЭДО — RAG-контекст не попадает в нужные чанки |
| search_code ограничен превью | 3-5 строк превью недостаточно для анализа логики процедур (ОтправитьИсходящиеДокументы — нужен весь код) |
| Высокое число вызовов | 30 вызовов при 8 шумных — агенту приходится «обходить» неработающие инструменты |

## Вывод
Graph-metadata — лучший сервер для анализа структуры подсистемы МЭДО. Cypher-запросы дали полную карту 53 объектов, все реквизиты/ТЧ с типами, перечисления с значениями, регистры с измерениями, XDTO-пакеты, подписки, роли — это уникальный контент, недоступный другим серверам. Компактность ответов (89K токенов vs 377K у cloud и 344K у code) — ключевое преимущество в экономии контекста. Слабая сторона — невозможность заглянуть внутрь кода процедур, поэтому процесс отправки описан только на уровне "кто вызывает кого", без деталей реализации. Для этого теста graph дал лучший покров по 4 из 5 подвопросов, уступив только по детализации процесса отправки.
