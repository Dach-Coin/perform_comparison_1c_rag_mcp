# Регистры, обновляемые при работе с задачами (1С:Документооборот КОРП 3.0)
**Дата:** 2026-04-07  
**Источник:** MCP-сервер 1c-graph-metadata (Neo4j + fulltext search)  
**Тест:** TEST-04

---

## Краткое резюме

При работе с документами **Задача** и **ДействиеЗадачи** обновляются:
- **2 регистра накопления** (счётчики-остатки для дашбордов)
- **2 регистра сведений** (актуальные данные для UI)
- Код записи находится в `ОбработкаПроведения` каждого документа

## 1. Регистры накопления

### 1.1. РегистрНакопления.КоличествоЗадач

**Назначение:** Хранит счётчики задач по авторам для дашбордов и обзоров задач.

| Тип | Поле | Описание |
|-----|------|----------|
| Измерение | Автор | Автор задачи |

| Измерение | ВидПриложения | К чему привязана задача |
| Измерение | ТипПриложения | Тип приложения |
| Измерение | Флаг | Флаг объекта |
| Измерение | Проект | Проект (если есть) |
| Измерение | Контрагент | Контрагент |
| Ресурс | Всего | Общее количество задач |
| Ресурс | ОжидающихВыполнения | Ожидают выполнения |
| Ресурс | ОжидающихПроверки | Ожидают проверки (у автора) |
| Ресурс | ВРаботе | В работе у исполнителя |
| Ресурс | Новых | Новые (ещё не взяты в работу) |
| Ресурс | Выполненных | Выполнено |
| Ресурс | Просроченных | Просрочено и ожидает выполнения |

| Атрибут | МожетБытьПросрочена | Флаг возможной просрочки |

**Когда записывается:**  
В `ОбработкаПроведения` документа **Задача**:
```bsl
// Количество задач.
Движения.КоличествоЗадач.Записывать = Истина;
Движение = Движения.КоличествоЗадач.Добавить();
Движение.Регистратор = Ссылка;
Движения.КоличествоЗадач.ОбновитьДанныеЗадачи(РеквизитыЗадачи);
```
Метод `ОбновитьДанныеЗадачи` вызывается на наборе движений — он заполняет все ресурсы на основе текущего состояния задачи (кэшируемые реквизиты).

В `ОбработкаПроведения` документа **ДействиеЗадачи**:
```bsl
// Действия задач.
Движения.ДействияЗадач.Записывать = Истина;
Движение = Движения.ДействияЗадач.Добавить();
Движение.Регистратор = Ссылка;
Движение.ЕстьПодзадачи = РаботаСЗадачами.ЕстьПодзадачи(Ссылка);
Движение.Трудозатраты = Трудозатраты();
// ... заполняются контрольные сроки ...
Движения.ДействияЗадач.ОбновитьДанныеДействия(РеквизитыДействия);
Движения.ДействияЗадач.ОбновитьДанныеЗадачи(РеквизитыДействия, РеквизитыЗадачи);
```

**Публичный API регистра** (модуль менеджера):
- `АктуальныйКлюч(ДействиеЗадачи)` — находит актуальную запись
- `ДанныеДействийЗадач(МассивДействийЗадач)` — возвращает ТЗ с данными для UI
- `ДанныеДействияЗадачи(ДействиеЗадачи)` — данные одного действия
- `КэшируемыеРеквизитыДействий()` — список реквизитов для кэша (используется в ОбработкаПроведения)

## 3. Ключевые процедуры

### 3.1. Документ.Задача — ОбработкаПроведения

Вызывается при любом проведении задачи (создание, изменение, смена статуса через `Записать(Проведение)`).

```bsl
Процедура ОбработкаПроведения(Отказ, Режим)
    
    КэшируемыеРеквизитыЗадачи = РегистрыНакопления.КоличествоЗадач.КэшируемыеРеквизитыЗадач();
    ОбщегоНазначенияДокументооборот.ДополнитьОтслеживаемыеРеквизиты(
        КэшируемыеРеквизитыЗадачи,
        РегистрыСведений.ЗадачиПоАвторам.КэшируемыеРеквизитыЗадач());
    РеквизитыЗадачи = Новый Структура(КэшируемыеРеквизитыЗадачи);
    ЗаполнитьЗначенияСвойств(РеквизитыЗадачи, ЭтотОбъект, КэшируемыеРеквизитыЗадачи);
    
    // Количество задач (регистр накопления).
    Движения.КоличествоЗадач.Записывать = Истина;
    Движение = Движения.КоличествоЗадач.Добавить();
    Движение.Регистратор = Ссылка;
    Движения.КоличествоЗадач.ОбновитьДанныеЗадачи(РеквизитыЗадачи);
    
    // Задачи по авторам (регистр сведений — снимок задачи).
    Движения.ЗадачиПоАвторам.Записывать = Истина;
    Движение = Движения.ЗадачиПоАвторам.Добавить();
    Движение.Регистратор = Ссылка;
    Движение.Трудозатраты = Трудозатраты();
    Движение.ЕстьПодзадачи = РаботаСЗадачами.ЕстьПодзадачи(Ссылка);
    ПараметрыКонтроляДляКэша = Справочники.Контроль.ПараметрыКонтроляДляКэша(Ссылка);
    Движение.СостояниеКонтроля = ПараметрыКонтроляДляКэша.СостояниеКонтроля;
    Движение.КонтрольныйСрок = ПараметрыКонтроляДляКэша.СрокИсполнения;
    Движение.КонтрольныйСрокОбщий = ПараметрыКонтроляДляКэша.СрокИсполненияОбщий;
    Движения.ЗадачиПоАвторам.ОбновитьДанныеЗадачи(РеквизитыЗадачи);
    
    МоиДокументыСобытия.ДобавлениеВМоиДокументыПриПроведении(ЭтотОбъект, Отказ);

КонецПроцедуры
```

### 3.2. Документ.ДействиеЗадачи — ОбработкаПроведения

Вызывается при проведении действия (взятие в работу, выполнение, возврат, проверка).

```bsl
Процедура ОбработкаПроведения(Отказ, Режим)
    
    // Подготовка кэшируемых реквизитов
    КэшируемыеРеквизитыДействия = РегистрыНакопления.КоличествоДействийЗадач.КэшируемыеРеквизитыДействий();
    ОбщегоНазначенияДокументооборот.ДополнитьОтслеживаемыеРеквизиты(
        КэшируемыеРеквизитыДействия,
        РегистрыСведений.ДействияЗадач.КэшируемыеРеквизитыДействий());
    РеквизитыДействия = Новый Структура(КэшируемыеРеквизитыДействия);
    ЗаполнитьЗначенияСвойств(РеквизитыДействия, ЭтотОбъект, КэшируемыеРеквизитыДействия);
    
    КэшируемыеРеквизитыЗадачи = РегистрыНакопления.КоличествоДействийЗадач.КэшируемыеРеквизитыЗадач();
    ОбщегоНазначенияДокументооборот.ДополнитьОтслеживаемыеРеквизиты(
        КэшируемыеРеквизитыЗадачи,
        РегистрыСведений.ДействияЗадач.КэшируемыеРеквизитыЗадач());
    РеквизитыЗадачи = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Задача, КэшируемыеРеквизитыЗадачи);
    
    // Количество действий задач (регистр накопления).
    Движения.КоличествоДействийЗадач.Записывать = Истина;
    РегистрыНакопления.КоличествоДействийЗадач.ЗаполнитьНаборПоДействию(
        Движения.КоличествоДействийЗадач, Ссылка, РеквизитыДействия, РеквизитыЗадачи);
    
    // Действия задач (регистр сведений — снимок действия).
    Движения.ДействияЗадач.Записывать = Истина;
    Движение = Движения.ДействияЗадач.Добавить();
    Движение.Регистратор = Ссылка;
    Движение.ЕстьПодзадачи = РаботаСЗадачами.ЕстьПодзадачи(Ссылка);
    Движение.Трудозатраты = Трудозатраты();
    ПараметрыКонтроляДляКэша = Справочники.Контроль.ПараметрыКонтроляДляКэша(Ссылка);
    Движение.СостояниеКонтроля = ПараметрыКонтроляДляКэша.СостояниеКонтроля;
    Движение.КонтрольныйСрок = ПараметрыКонтроляДляКэша.СрокИсполнения;
    Движение.КонтрольныйСрокОбщий = ПараметрыКонтроляДляКэша.СрокИсполненияОбщий;
    Движения.ДействияЗадач.ОбновитьДанныеДействия(РеквизитыДействия);
    Движения.ДействияЗадач.ОбновитьДанныеЗадачи(РеквизитыДействия, РеквизитыЗадачи);
    
    МоиДокументыСобытия.ДобавлениеВМоиДокументыПриПроведении(ЭтотОбъект, Отказ);

КонецПроцедуры
```

### 3.3. Общий модуль РаботаСЗадачами — ключевые процедуры

#### ЗакрытьЗадачу (смена статуса на «Закрыта»)
```bsl
Процедура ЗакрытьЗадачу(Задача) Экспорт
    НачатьТранзакцию();
    Попытка
        ЗадачаОбъект = Задача.ПолучитьОбъект();
        ДанныеВидаЗадачи = РаботаСЗадачамиПовтИсп.ДанныеВидаЗадачи(ЗадачаОбъект.ВидЗадачи);
        ЗадачаОбъект.УстановитьСостояние(ДанныеВидаЗадачи.СостояниеЗадачиЗакрыта, Истина);
        ЗадачаОбъект.Записать(РежимЗаписиДокумента.Проведение); // <- вызывает ОбработкуПроведения
        ЗакрытьПодзадачи(Задача);

    Исключение
        ОтменитьТранзакцию();
        ВызватьИсключение;
    КонецПопытки;
КонецПроцедуры
```

## 4. Как меняются данные при смене статуса задачи

Ключевой механизм: **любая смена статуса** задачи или действия задачи происходит через:
1. Вызов `УстановитьСостояние(НовоеСостояние, КтоОтметил)` на объекте документа
2. Вызов `ЗадачаОбъект.Записать(РежимЗаписиДокумента.Проведение)`
3. Платформа 1С выполняет `ОбработкаПроведения` — записываются движения в регистры

| Событие | Документ-регистратор | Регистры накопления | Регистры сведений |
|---------|---------------------|---------------------|-------------------|
| Создание задачи | Задача (новый) | КоличествоЗадач ↑ | ЗадачиПоАвторам (новая запись) |
| Изменение реквизитов задачи | Задача (перепроведение) | КоличествоЗадач (пересчёт) | ЗадачиПоАвторам (обновление) |
| Взятие действия в работу | ДействиеЗадачи | КоличествоДействийЗадач: Новых↓, ВРаботе↑ | ДействияЗадач: ВРаботе=Истина, Новое=Ложь |
| Выполнение действия | ДействиеЗадачи | КоличествоДействийЗадач: ВРаботе↓, ОжидающихПроверки↑ | ДействияЗадач: Выполнено=Истина |
| Проверка выполнения (автором) | ДействиеЗадачи | КоличествоДействийЗадач: перераспределение | ДействияЗадач: СостояниеКонтроля обновляется |
| Возврат на доработку | Задача | КоличествоЗадач: ОжидающихВыполнения↑ | ЗадачиПоАвторам: обновление статуса |
| Закрытие задачи | Задача | КоличествоЗадач: Выполненных↑, остальные↓ | ЗадачиПоАвторам: Выполнена=Истина |
| Просрочка (фоновое задание) | — | КоличествоЗадач: Просроченных↑ | ЗадачиПоАвторам: Просрочена=Истина |
| Эскалация | — | — | ЭскалированныеЗадачи, ЭскалированныеДействия |

## 6. Архитектурная схема

```
Документ.Задача ──(Проведение)──> ОбработкаПроведения
    ├── Движения.КоличествоЗадач  ──────────────────> РН.КоличествоЗадач
    └── Движения.ЗадачиПоАвторам ──────────────────> РС.ЗадачиПоАвторам

Документ.ДействиеЗадачи ──(Проведение)──> ОбработкаПроведения
    ├── Движения.КоличествоДействийЗадач ──────────> РН.КоличествоДействийЗадач
    └── Движения.ДействияЗадач ─────────────────────> РС.ДействияЗадач

Общий модуль РаботаСЗадачами
    ├── ЗакрытьЗадачу()         → ЗадачаОбъект.Записать(Проведение)
    ├── ВзятьВРаботу()          → ДействиеЗадачиОбъект.Записать(Проведение)
    └── ВернутьНаДоработку()    → ЗадачаОбъект.Записать(Проведение)

РС.ДействияЗадач ─────> используется в UI (ДанныеДействийЗадач, АктуальныйКлюч)
РН.КоличествоЗадач ───> используется в дашбордах (ЗадачиАвторовИтоги)
РН.КолДействийЗадач ──> используется в дашбордах (ЗадачиМнеИтоги)
```
