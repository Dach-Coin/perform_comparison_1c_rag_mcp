# Бизнес-отчёт: Электронные подписи и подписание документов
**Конфигурация:** 1С:Документооборот КОРП 3.0 (DO3)
**Источник данных:** MCP-сервер 1c-graph-metadata
**Дата:** 2026-04-07 | TEST-07

---

## 1. Бизнес-процесс "Подписание" — общая структура

В конфигурации реализован отдельный бизнес-процесс **`БизнесПроцессы.Подписание`**. Процесс поддерживает:
- Многоэтапное подписание с последовательным или параллельным порядком выполнения
- Несколько итераций (повторное подписание)
- Привязку к шаблону (Справочник.ШаблоныПодписания)
- Работу с предметами (12 типов: документы предприятия, входящие/исходящие письма, файлы, проекты и др.)

### Ключевые реквизиты БП

| Реквизит | Тип | Назначение |
|----------|-----|-----------|
| СпособПодписания | Перечисление.СпособыПодписанияПредметаПроцесса | Вид подписи при запуске |
| РезультатПодписания | Перечисление.РезультатыПроцессаПодписания | Итог подписания |
| ПорядокВыполненияУчастниками | Перечисление.ПорядокВыполненияЭтапаПроцесса | Последовательно/Параллельно |
| КоличествоИтераций | Число(2,0) | Число повторных кругов |
| НомерИтерации | Число(10,0) | Текущий номер итерации |
| Шаблон | СправочникСсылка.ШаблоныПодписания | Шаблон для автозапуска |
| Состояние | Перечисление.СостоянияБизнесПроцессов | Текущее состояние процесса |
| СрокИсполненияПроцесса | Дата(ДатаВремя) | Общий срок |
| Важность | Перечисление.ВариантыВажностиОбъектов | Приоритет |
| ГлавнаяЗадача | ЗадачаСсылка.ЗадачаИсполнителя | Связь с задачей |

## 3. Поддержка электронной подписи (ЭП/ЭЦП)

### Виды подписания (перечисление СпособыПодписанияПредметаПроцесса)

| Значение | Расшифровка |
|----------|-------------|
| **УЭП** | Усиленная электронная подпись (КЭП или НЭП) |
| **ПЭП** | Простая электронная подпись |
| **НаБумаге** | Традиционное подписание бумажного документа |

### Виды ЭП (перечисление ВидыЭлектронныхПодписей)

| Значение | Описание |
|----------|----------|
| УсиленнаяКвалифицированная | КЭП с квалифицированным сертификатом |
| Простая | ПЭП (логин/пароль, код подтверждения) |

### Глобальные настройки (константы)

| Константа | Назначение |
|-----------|-----------|
| ИспользоватьЭлектронныеПодписи | Включение/выключение ЭП в системе |
| СоздаватьЭлектронныеПодписиНаСервере | Серверное создание ЭП |
| ПроверятьЭлектронныеПодписиНаСервере | Серверная проверка ЭП |
| ТипПодписиКриптографииПоУмолчанию | Тип подписи по умолчанию |
| УсовершенствоватьПодписиАвтоматически | Авто-усовершенствование (архивная подпись) |
| ИспользоватьВнешнееПодписание | Подписание через внешний сервис |
| АдресСервисаПодключенияЭлектронной ПодписиВМоделиСервиса | Облачный сервис ЭП |

## 4. Хранение данных о подписях

### Основной регистр: РС "ЭлектронныеПодписи"

Основное хранилище всех ЭП в системе.

**Измерения:**
- `ПодписанныйОбъект` — ссылка на подписанный объект
- `ПорядковыйНомер` — порядковый номер подписи

**Ресурсы:**
| Поле | Назначение |
|------|-----------|
| Подпись | Двоичные данные ЭП |
| ТипПодписи | Тип подписи (КЭП/ПЭП) |
| Сертификат | Данные сертификата |
| КомуВыданСертификат | Владелец сертификата |
| Отпечаток | Отпечаток сертификата |
| ПодписьВерна | Результат проверки |
| СертификатДействителен | Статус сертификата |
| УстановившийПодпись | Кто подписал |
| ДатаПодписи | Дата/время подписания |
| ДатаПроверкиПодписи | Когда проверялась |
| ИмяФайлаПодписи | Имя файла .sig |
| ИдентификаторПодписи | Уникальный идентификатор |

### РС "ПростыеЭлектронныеПодписи"

Хранение ПЭП (простых подписей):
- Измерения: ПодписанныйОбъект, ПорядковыйНомер
- Ресурсы: ВладелецПодписи, Пользователь, ДатаПодписи, Должность

## 5. Изменение статуса документа после подписания

В справочнике **`ДокументыПредприятия`** (основная карточка внутреннего документа) реализованы следующие реквизиты, отражающие результат подписания:

| Реквизит | Тип | Значение |
|----------|-----|---------|
| **ПодписанЭП** | Булево | Документ подписан ЭП |
| **ПодписанВсеми** | Булево | Все участники подписали |
| **РезультатПодписания** | Перечисление.РезультатыПодписания | Подписано / НеПодписано / Выполнено |
| Подписал | Сотрудники / Пользователи | Последний подписант |
| ПодписалОтКонтрагента | КонтактныеЛица | Подписант со стороны контрагента |
| ДатаПодписания | Дата | Дата подписания |
| ДатаУстановкиПодписи | Дата | Дата фактической установки подписи |
| КомментарийПодписи | Строка | Комментарий при подписании |

В ТЧ **РезультатыПодписания** бизнес-процесса фиксируется результат каждого участника:
- ЗадачаПроцесса — ссылка на задачу
- РезультатПодписания (Подписано / НеПодписано)
- НомерИтерации

Также в ТЧ **РезультатыОбработок** хранится флаг **ОтправленоНаПовторноеПодписание** — возможность отправить на повторный круг.

## Итоговая схема процесса подписания

```
Запуск БП Подписание
  │
  ├─ Параметры запуска:
  │   ├─ СпособПодписания: УЭП / ПЭП / НаБумаге
  │   ├─ ТЧ Участники: список Подписывающих (Сотрудник или Роль)
  │   ├─ ТЧ Этапы: этапы с порядком (Последовательно/Параллельно)
  │   ├─ ТЧ Предметы: документы/файлы для подписания
  │   └─ Шаблон: готовый набор настроек
  │
  ├─ Выполнение:
  │   ├─ Создаются задачи ЗадачаИсполнителя для участников
  │   ├─ При подписании → РС.ЭлектронныеПодписи (для УЭП)
  │   │                 → РС.ПростыеЭлектронныеПодписи (для ПЭП)
  │   └─ Результат пишется в ТЧ.РезультатыПодписания
  │
  └─ Завершение:
      ├─ Справочник.ДокументыПредприятия:
      │   ├─ ПодписанЭП = Истина
      │   ├─ ПодписанВсеми = Истина
      │   └─ РезультатПодписания = Подписано
      └─ БП.РезультатПодписания = Подписано
```
