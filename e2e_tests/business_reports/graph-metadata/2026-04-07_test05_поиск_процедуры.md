## Сигнатура функции

```bsl
// Выполняет попытку определения фактического исполнения.
// 
// Параметры:
//  ДействияЗадач - Массив из ДокументСсылка.ДействиеЗадачи.
//  ВыполнитьОтИмени - СправочникСсылка.Пользователи.
//  ВыбранныйФактическийИсполнитель - Структура.
//  РеквизитыДействийЗадач - Соответствие.
// 
// Возвращаемое значение:
//  Структура:
//   * ДействияБезФактИсполнителя - Массив из ДокументСсылка.ДействиеЗадачи
//   * ДействияБезКомуАдресовано - Массив из ДокументСсылка.ДействиеЗадачи
//   * ФактическиеИсполнителиПолные - Соответствие
//   * ФактическиеИсполнителиПоДействиям - Соответствие
//   * ОснованияФактИсполнителейПоДействиям - Соответствие
//
Функция ОпределитьФактическихИсполнителей(
    ДействияЗадач,
    ВыполнитьОтИмени,
    ВыбранныйФактическийИсполнитель,
    РеквизитыДействийЗадач = Неопределено) Экспорт
```

---

## Как работает: алгоритм (с замещениями и ролями)

Функция перебирает массив действий задач и для каждого определяет фактического исполнителя через последовательную проверку трёх условий:

### Шаг 1: Прямой исполнитель-сотрудник

```bsl
// Проверим, выполняет ли сам сотрудник.
Если ТипЗнч(РеквизитыДействия.Исполнитель) = Тип("СправочникСсылка.Сотрудники") Тогда
    
    Если ВыполняетСотрудник Тогда
        ФактическиеИсполнителиПолные[ДействиеЗадачи] = 
            Справочники.ФактическиеИсполнители.НайтиСоздатьФактическогоИсполнителя(
                РеквизитыДействия.Исполнитель);
        ФактическиеИсполнителиПоДействиям[ДействиеЗадачи] = РеквизитыДействия.Исполнитель;
        Продолжить;
    КонецЕсли;
    
КонецЕсли;
```

Если назначен конкретный сотрудник (не роль) и он совпадает с текущим пользователем — задача выполняется напрямую.

### Шаг 2: Исполнитель через роль (`ПолныеРоли`)

```bsl
// Проверим, выполняет ли исполнитель роли.
Если ТипЗнч(РеквизитыДействия.Исполнитель) = Тип("СправочникСсылка.ПолныеРоли") Тогда
    
    Если ВыполняетИсполнительРоли Тогда
        // Получить список сотрудников роли
        ИсполнителиРоли = РегистрыСведений.ИсполнителиРолей.ИсполнителиРоли(
            РеквизитыДействия.Исполнитель);
        // Найти пересечение с сотрудниками текущего пользователя
        ПодходящиеСотрудники =
            ОбщегоНазначенияДокументооборотКлиентСервер.ПересечениеМассивов(
                ВсеСотрудники, ИсполнителиРоли);
        
        // Создать запись ФактическогоИсполнителя:
        //  Адресат = Роль, План = Сотрудник, Факт = Сотрудник, Отметил = Сотрудник
        ФактическиеИсполнителиПолные[ДействиеЗадачи] = 
            Справочники.ФактическиеИсполнители.НайтиСоздатьФактическогоИсполнителя(
                РеквизитыДействия.Исполнитель,
                СотрудникИсполняющийРоль,
                СотрудникИсполняющийРоль,
                СотрудникИсполняющийРоль);
        Продолжить;
    КонецЕсли;
    
КонецЕсли;
```

Если назначена роль — ищет текущего пользователя среди исполнителей роли. Пересечение через `РегистрыСведений.ИсполнителиРолей`.

### Шаг 3: Замещающий или помощник

```bsl
// Проверим, выполняет ли заместитель или помощник.
Если ТаблицаВсехЗамещений = Неопределено Тогда
    ТаблицаВсехЗамещений =
        Справочники.ЗамещающиеИПомощники.ВсеЗамещенияПоДействиямЗадач(
            ДействияЗадач, ВсеСотрудники);
КонецЕсли;

// ...
Для Каждого СтрЗамещения Из ТаблицаЗамещений Цикл
    
    ЭтоПомощник = СтрЗамещения.ВидЗамещения = Перечисления.ВидыЗамещения.Помощники;
    
    Если ЭтоПомощник Тогда
        // Помощник: Адресат=Роль/Сотрудник, План=Помощник, Факт=Помощник, Отметил=Основной
        ФактИсполнитель = Справочники.ФактическиеИсполнители.НайтиСоздатьФактическогоИсполнителя(
            РеквизитыДействия.Исполнитель,
            СтрЗамещения.Сотрудник, 
            СтрЗамещения.Сотрудник,
            ОсновнойСотрудник);
    ИначеЕсли СтрЗамещения.ВидЗамещения = Перечисления.ВидыЗамещения.Замещающие Тогда
        // Замещающий: Адресат=Роль/Сотрудник, План=Замещающий, Факт=ОсновнойСотрудник
        ФактИсполнитель = Справочники.ФактическиеИсполнители.НайтиСоздатьФактическогоИсполнителя(
            РеквизитыДействия.Исполнитель,
            СтрЗамещения.Сотрудник,
            ОсновнойСотрудник,
            ОсновнойСотрудник);
    КонецЕсли;
    
КонецЦикла;
```

Разница **Помощник vs Замещающий**:
- **Помощник**: фактически исполняет помощник (поле `Факт` = помощник)
- **Замещающий**: фактически исполняет основной сотрудник (поле `Факт` = ОсновнойСотрудник), а план = замещающий

## Связанные объекты

### Справочник `ФактическиеИсполнители`

Хранит запись о том, кто фактически выполнил задачу:

| Реквизит | Тип | Назначение |
|----------|-----|-----------|
| `Адресат` | Сотрудники / ПолныеРоли | Плановый адресат (кому адресована задача) |
| `План` | Сотрудники | Плановый исполнитель |
| `Факт` | Сотрудники | Фактический исполнитель |
| `Отметил` | Сотрудники | Кто отметил результат |

Ключевые методы модуля:
- `НайтиСоздатьФактическогоИсполнителя(Адресат, План, Факт, Отметил)` — находит или создаёт запись
- `ВсеФактическиеИсполнителиАдресата(Адресат)` — все записи по адресату

### РегистрСведений `ВсеИсполнителиДействийЗадач`

Хранит всех исполнителей (включая замещающих) по каждому действию задачи:

| Измерение | Тип | Назначение |
|-----------|-----|-----------|
| `ДействиеЗадачи` | ДокументСсылка.ДействиеЗадачи | Действие задачи |
| `Исполнитель` | ОпределяемыйТип.УчастникЗадач | Исполнитель |
| `Основание` | СправочникСсылка.ЗамещающиеИПомощники | Основание (запись замещения) |

Ключевые методы:
- `ЗамещенияПоДействию(ДействиеЗадачи, ВидЗамещения)` — актуальные замещения по действию
- `ЕстьЗамещающиеПоДействию(ДействиеЗадачи)` — булево, есть ли замещающие

### Перечисление `ВидыЗамещения`

Используется для разграничения типов замещений в функции:
- `Замещающие` — замещающий сотрудник
- `Помощники` — помощник

## Кто вызывает ОпределитьФактическихИсполнителей

Функция вызывается из 4 внешних модулей:

### 1. `БизнесПроцессыИЗадачиСервер.ПринятьКИсполнению()`
**Контекст:** При принятии задачи процесса к исполнению (задачи БП, не DO3-задачи)

```bsl
// Вызывается когда исполнитель задачи не заполнен (задача роли)
ДанныеФактическихИсполнителей = 
    РаботаСЗадачами.ОпределитьФактическихИсполнителей(
        ОбщегоНазначенияКлиентСервер.ЗначениеВМассиве(ДействиеЗадачи),
        КтоОтметил,
        ВыбранныйФактическийИсполнитель);

РезультатПринятияКИсполнению.НужноВыбратьФактическогоИсполнителя = 
    ДанныеФактическихИсполнителей.ДействияБезФактИсполнителя.Количество() > 0
    Или ДанныеФактическихИсполнителей.ДействияБезКомуАдресовано.Количество() > 0;
```

### 2. `РаботаСЗадачамиВызовСервера.ЗаполнитьФактическогоИсполнителя()`
**Контекст:** Фасад при выполнении действия задачи из клиентского кода

```bsl
// Служебная процедура, инициирует процедуру указания данных
Процедура ЗаполнитьФактическогоИсполнителя(
    ДействияЗадач, РеквизитыДействийЗадач,
    ПараметрыВыполнения, ДанныеВыполнения)

    ДанныеФактическихИсполнителей = РаботаСЗадачами.ОпределитьФактическихИсполнителей(
        ДействияЗадач,
        ПараметрыВыполнения.ВыполнитьОтИмени,
        ПараметрыВыполнения.ВыбранныйФактическийИсполнитель,
        РеквизитыДействийЗадач);
```

### 3. `ЭскалацияЗадач`
**Контекст:** При автоматическом выполнении задачи по правилу эскалации

```bsl
ДанныеФактическихИсполнителей = РаботаСЗадачами.ОпределитьФактическихИсполнителей(
    ДействияЗадач,
    ПараметрыВыполнения.ВыполнитьОтИмени,
    ПараметрыВыполнения.ВыбранныйФактическийИсполнитель,
    РеквизитыДействийЗадач);
```

### 4. `РаботаСВнешнимПодписанием`
**Контекст:** При обработке результатов внешнего подписания документа

```bsl
ДанныеФактическихИсполнителей = РаботаСЗадачами.ОпределитьФактическихИсполнителей(
    ДействияЗадач,
    ПараметрыВыполнения.ВыполнитьОтИмени,
    ПараметрыВыполнения.ВыбранныйФактическийИсполнитель,
    РеквизитыДействийЗадач);
```

### 5. Внутри самого `РаботаСЗадачами` — функция `ВзятьВРаботу()`
**Контекст:** При взятии задачи с ролевым исполнителем в работу

```bsl
// Только если исполнитель — роль (ПолныеРоли)
Если ТипЗнч(ДействиеЗадачиОбъект.Исполнитель) = Тип("СправочникСсылка.ПолныеРоли") Тогда
    
    ДанныеФактическихИсполнителей = 
        ОпределитьФактическихИсполнителей(
            ОбщегоНазначенияКлиентСервер.ЗначениеВМассиве(ДействиеЗадачи),
            КтоОтметил,
            ВыбранныйФактическийИсполнитель);
```

## Схема вызовов

```
Взятие в работу / Выполнение задачи
        │
        ├── РаботаСЗадачами.ВзятьВРаботу()
        │       └── (если исполнитель = роль)
        │               └── ОпределитьФактическихИсполнителей()
        │
        ├── РаботаСЗадачамиВызовСервера.ЗаполнитьФактическогоИсполнителя()
        │       └── ОпределитьФактическихИсполнителей()
        │
        ├── БизнесПроцессыИЗадачиСервер.ПринятьКИсполнению()
        │       └── ОпределитьФактическихИсполнителей()
        │
        ├── ЭскалацияЗадач (автоматическое выполнение)
        │       └── ОпределитьФактическихИсполнителей()
        │
        └── РаботаСВнешнимПодписанием (внешнее подписание)
                └── ОпределитьФактическихИсполнителей()
                        │
                        ├── [Шаг 1] Прямой сотрудник
                        │       └── ФактическиеИсполнители.НайтиСоздатьФактическогоИсполнителя()
                        │
                        ├── [Шаг 2] Роль (ПолныеРоли)
                        │       ├── РегистрыСведений.ИсполнителиРолей.ИсполнителиРоли()
                        │       └── ФактическиеИсполнители.НайтиСоздатьФактическогоИсполнителя()
                        │
                        └── [Шаг 3] Замещение/Помощник
                                ├── Справочники.ЗамещающиеИПомощники.ВсеЗамещенияПоДействиямЗадач()
                                ├── Справочники.ЗамещающиеИПомощники.АктуальныеЗамещенияПоДействиямЗадач()
                                └── ФактическиеИсполнители.НайтиСоздатьФактическогоИсполнителя()
```

|----------|-----------|
| Название процедуры | `ОпределитьФактическихИсполнителей()` |
