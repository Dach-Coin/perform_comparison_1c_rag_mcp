## 1. Реквизиты шапки справочника Сотрудники

Справочник содержит **9 пользовательских реквизитов** (помимо стандартных: Код, Наименование, Пометка удаления):

| Реквизит | Тип | Назначение |
|----------|-----|------------|
| Должность | СправочникСсылка.Должности | Должность сотрудника |
| Подразделение | СправочникСсылка.СтруктураПредприятия | Подразделение-место работы |
| ГрафикРаботы | СправочникСсылка.ГрафикиРаботы | График рабочего времени |
| Помещение | СправочникСсылка.ТерриторииИПомещения | Рабочее место/офис |
| ПредставлениеВДокументах | Строка(0, Переменная) | Как отображается в документах |
| ПредставлениеВПереписке | Строка(0, Переменная) | Как отображается в переписке |
| ДатаНачалаДействия | Дата(Дата) | Дата начала работы/полномочий |
| ДатаОкончанияДействия | Дата(Дата) | Дата окончания работы/полномочий |
| Действует | Булево | Признак действующего сотрудника |

**Обратите внимание:** В справочнике Сотрудники **нет реквизита ФИО**. ФИО хранится в справочнике ФизическиеЛица и доступно через регистр ОсновныеСотрудники (см. раздел 3).

### Формы справочника
- **ФормаЭлемента** — карточка сотрудника
- **ФормаВыбора** — подбор сотрудника
- **ФормаСотрудниковДолжности** — список сотрудников на должности
- **ФормаСотрудниковПодразделения** — список сотрудников подразделения
- **СотрудникиОбоМне** — сотрудники о текущем пользователе

## 3. Связи с другими справочниками

### 3.1. Справочник ФизическиеЛица

**Тип связи:** через регистр сведений  
**Объект:** РегистрСведений.ОсновныеСотрудники

```
Измерение: ФизическоеЛицо → СправочникСсылка.ФизическиеЛица
Ресурс:    Сотрудник       → СправочникСсылка.Сотрудники
```

Это **ключевая архитектурная особенность** Документооборота: один элемент ФизическиеЛица может быть связан с несколькими записями в справочнике Сотрудники (например, при смене должности или подразделения создаётся новый элемент Сотрудники).

**Реквизиты справочника ФизическиеЛица:**
| Реквизит | Тип |
|----------|-----|
| ДатаРождения | Дата(Дата) |
| Пол | ПеречислениеСсылка.ПолФизическогоЛица |
| ИНН | Строка(12, Переменная) |
| СтраховойНомерПФР | Строка(14, Переменная) |
| ФайлФотографии | ХранилищеЗначения |
| ГруппаДоступа | СправочникСсылка.ГруппыДоступаФизическихЛиц |
| Комментарий | Строка(0, Переменная) |

### 3.2. Справочник Должности

**Тип связи:** прямой реквизит  
`Сотрудники.Должность → СправочникСсылка.Должности`

Справочник Должности минималистичный — содержит только стандартное наименование и расширение тст_ТиповаяПечатнаяФорма.

### 3.3. Справочник СтруктураПредприятия (Подразделения)

**Тип связи:** двусторонняя  
- Прямая: `Сотрудники.Подразделение → СправочникСсылка.СтруктураПредприятия`  
- Обратная: `СтруктураПредприятия.Руководитель → Сотрудники | Пользователи`

**Реквизиты подразделения:**
| Реквизит | Тип |
|----------|-----|
| ВидПодразделения | СправочникСсылка.ВидыПодразделений |
| ГрафикРаботы | СправочникСсылка.ГрафикиРаботы |
| Руководитель | Сотрудники / Пользователи |
| Ранг | Число(3,0) |
| УказанОсобыйРанг | Булево |
| Комментарий | Строка |

Иерархия подразделений и их руководители хранятся также в регистре **ПодчиненностьПодразделений** (с полями РуководительВышестоящего и РуководительПодчиненного).

### 3.4. Связь с пользователями системы

**Объект:** РегистрСведений.СотрудникиПользователей  
```
Измерение: Сотрудник  → СправочникСсылка.Сотрудники
Измерение: Пользователь → СправочникСсылка.Пользователи
```

## 4. Механизм замещения сотрудников

### Объект реализации
**Справочник.ЗамещающиеИПомощники** — основной объект механизма замещения

### Структура справочника

| Реквизит | Тип | Назначение |
|----------|-----|------------|
| Сотрудник | СправочникСсылка.Сотрудники | Кого замещают/кому назначен помощник |
| Замещающий | СправочникСсылка.Сотрудники | Кто замещает/является помощником |
| ВидЗамещения | ПеречислениеСсылка.ВидыЗамещения | Тип: Замещающие или Помощники |
| ДатаНачала | Дата(Дата) | Начало периода замещения |
| ДатаОкончания | Дата(Дата) | Конец периода замещения |
| Действует | Булево | Активность замещения |
| Основание | ДокументСсылка.Отсутствие | Документ-основание (приказ об отпуске и т.д.) |
| Создал | СправочникСсылка.Сотрудники | Кто создал запись |
| Комментарий | Строка(0, Переменная) | Пояснение |

### Виды замещения (Перечисление.ВидыЗамещения)
- **Замещающие** — полное замещение полномочий (замещающий получает права отсутствующего)
- **Помощники** — неполное замещение (помощник работает от имени, но без снятия прав)

### Как работает замещение в задачах
Регистр накопления **КоличествоДействийЗадач** содержит измерение:
- `Замещающий → СправочникСсылка.Сотрудники` — задачи, поступающие замещающему

### Формы
- ФормаСписка — основной список замещений
- ФормаЭлемента — карточка замещения
- НастройкаОтбора — фильтрация списка

                    ┌─────────────────────────────────────┼──────────────────────────┐
                    │                                     │                          │

## 7. Выводы и примечания

1. **Архитектура "Сотрудник без ФИО"**: В DO3 справочник Сотрудники не хранит ФИО — это намеренное разделение "рабочей роли" (должность, подразделение) и "персональных данных" (ФизЛицо). Такой подход позволяет одному физлицу иметь несколько рабочих ролей.

2. **Замещение реализовано отдельным справочником**: ЗамещающиеИПомощники — полноценный управляемый объект с документом-основанием (Отсутствие), периодами действия и двумя видами (полное замещение vs помощник).

3. **Богатая аналитика по времени**: Три уровня учёта: ЗанятостьСотрудников (укрупнённо), ДоступноеВремяСотрудников (расписание), ХронометражРабочегоВремениСотрудников (детально по объектам).

4. **Интеграционный потенциал**: Наличие регистра ДанныеSAPСотрудники указывает на готовность конфигурации к синхронизации с SAP HR.

5. **Двойная типизация**: Многие регистры хранят поле Сотрудник как `Сотрудники | Пользователи` (составной тип) — это позволяет учитывать внешних пользователей, не являющихся штатными сотрудниками.
