## Что сервер дал хорошо

- **Полная структура БП Подписание** — через Cypher получены все 20 реквизитов с типами и все 6 табличных частей (Участники, РезультатыПодписания, РезультатыОбработок, Предметы, Этапы, ДополнительныеРеквизиты) — самый полный набор ТЧ из трёх серверов
- **Перечисления** — найдены все три перечисления: СпособыПодписанияПредметаПроцесса (УЭП/ПЭП/НаБумаге), РезультатыПроцессаПодписания (Подписано/НеПодписано), ПорядокВыполненияЭтапаПроцесса (Последовательно/Параллельно), ВидыЭлектронныхПодписей (УсиленнаяКвалифицированная/Простая)
- **Регистр ЭлектронныеПодписи** — полная структура с измерениями и всеми 12+ ресурсами (Подпись, ТипПодписи, Сертификат, ПодписьВерна, УстановившийПодпись, ДатаПодписи, КомуВыданСертификат, Отпечаток, ИмяФайлаПодписи, СертификатДействителен, ДатаПроверкиПодписи, ТребуетсяПроверка) — самый полный набор из трёх серверов
- **Изменение статуса документа** — через Cypher найдены реквизиты в ДокументыПредприятия: ПодписанЭП, ПодписанВсеми, РезультатПодписания, Подписал, ПодписалОтКонтрагента, ДатаПодписания, КомментарийПодписи — уникальная находка, не найденная другими серверами
- **96 общих модулей** — через Cypher по паттерну имени найдены все модули по теме ЭП — самый полный список из трёх серверов
- **Константы управления ЭП** — 7 констант (ИспользоватьЭлектронныеПодписи, СоздаватьНаСервере, ПроверятьНаСервере, УсовершенствоватьАвтоматически, ВнешнееПодписание и др.) — уникальная находка
- **Дополнительные регистры и справочники** — нашёл ОчередьОбработкиРезультатовВнешнегоПодписания, СервисыВнешнегоПодписания, ПрограммыЭлектроннойПодписиИШифрования — объекты, не найденные другими серверами
- **Документ СведенияОВнешнемПодписании** — полная структура (17 реквизитов) — уникальная находка

## Что сервер НЕ дал

- **Код модулей и функций** — Cypher даёт структуру метаданных, но не код. search_code (fulltext) нашёл только 5 модулей с краткими описаниями. Нет сигнатур функций (которые cloud нашёл хорошо)
- **Логика смены статуса** — реквизиты ДокументыПредприятия найдены, но какой именно код устанавливает ПодписанЭП = Истина — не показано (code-metadata нашёл это в модуле ДействияСервер)
- **search_metadata недоступен** — требует OpenAI API, который не подключён → 1 шумный вызов
- **search_code (semantic) недоступен** — Vector indexer not initialized → 1 шумный вызов
- **Подписки на события БП** — не найдены (code-metadata нашёл 3 подписки)

## Паттерны поведения агента

- Агент начал с answer_metadata_question (низкая релевантность), затем search_metadata (недоступен) — 2 неудачных начала
- После получения схемы через get_metadata_prompt агент переключился на Cypher-запросы — стратегия стала эффективной
- 12 из 21 вызова — execute_metadata_cypher, все 12 с высокой релевантностью. Cypher — основная сила этого сервера
- 4 вызова search_code: 2 fulltext дали результат, 1 semantic недоступен, 1 пустой — ненадёжный инструмент
- Объём ответов компактный (100-4600 символов за вызов) — **самый экономный по токенам** из трёх серверов (~93K total)
- Быстрее всех: ~8.5 мин vs 12 мин у cloud и code-metadata

## Выявленные проблемы RAG

| Проблема | Проявление в этом тесте |
| -------- | ----------------------- |
| search_metadata недоступен | Требует OpenAI API — инструмент бесполезен без ключа |
| search_code (semantic) не работает | Vector indexer not initialized — семантический поиск по коду отключён |
| answer_metadata_question низкое качество | 50% уверенность, общий ответ без конкретики — ненадёжный инструмент |
| Нет кода модулей | Cypher даёт структуру, но не содержимое кода — невозможно увидеть логику функций |
| search_code (fulltext) ограничен | Находит только имена модулей, не фрагменты кода с контекстом |

## Вывод

Graph-metadata показал **самый экономный и структурно полный** результат: через Cypher-запросы получена исчерпывающая структура БП Подписание (все ТЧ, перечисления, регистры), полная структура регистра ЭлектронныеПодписи с 12+ ресурсами, 96 общих модулей, и уникальные находки (реквизиты подписания в ДокументыПредприятия, константы управления ЭП). Однако сервер **не даёт код** — для понимания логики работы функций нужен code-metadata или cloud-embeddings. Идеальная комбинация: graph для структуры + code-metadata для логики.
