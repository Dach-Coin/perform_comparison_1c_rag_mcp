# Система нумерации и регистрации документов в 1С:Документооборот КОРП 3.0

**Дата:** 2026-04-07  
**Источник данных:** MCP-сервер 1c-graph-metadata (Neo4j граф метаданных)  
**Конфигурация:** 1С:Документооборот КОРП 3.0 (DO3)

---

## 1. Общая архитектура системы нумерации

В ДО КОРП нумерация документов реализована через трёхуровневую структуру:

```
ВидыДокументов (настройки включения)
    ↓
НастройкиНумерации (РС) — привязка нумератора к виду документа
    ↓
Нумераторы (Справочник) — схема нумерации
    ↓
Нумерация (РС) — счётчик ТекущийНомер
```

Точка хранения итогового номера — **Справочник.ДокументыПредприятия** с реквизитами:
- `РегистрационныйНомер` — тип ОпределяемыйТип.РегистрационныйНомер
- `ВременныйНомер` — тип ОпределяемыйТип.РегистрационныйНомер  
- `ЧисловойНомер` — Число(10,0) — числовая часть номера
- `ДатаРегистрации` — Дата(ДатаВремя)
- `Зарегистрировал` — СправочникСсылка.Сотрудники / Пользователи

## 2. Автоматическая нумерация при создании документа

### Способы нумерации (Перечисление.СпособыНумерации)
- `Автоматически` — система присваивает номер самостоятельно при создании/регистрации
- `Вручную` — пользователь вводит номер самостоятельно

### Назначения нумераторов (Перечисление.НазначенияНумераторов)
- `ВременныйНомер` — промежуточный номер до регистрации документа
- `РегистрационныйНомер` — постоянный номер, присваивается при регистрации

Таким образом, документ может получать номера дважды: сначала временный (при создании), затем регистрационный (при прохождении бизнес-процесса Регистрация).

Включение временных номеров управляется на уровне вида документа: реквизит `ИспользоватьВременныеНомера` (Булево) в Справочнике.ВидыДокументов.

Программная реализация — в **ОбщийМодуль.Нумерация**:
- Экспортируемая процедура `СформироватьЧисловойНомерДокумента(СтруктураПараметров, СформированныйНомер)`

## 3. Регистрация документа — бизнес-процесс

Регистрация реализована как **БизнесПроцесс.Регистрация**.

### Основные реквизиты БП
| Реквизит | Тип | Назначение |
|----------|-----|------------|
| Исполнитель | Сотрудники/Пользователи | Кто выполняет регистрацию |
| ИсточникДанных | — | Источник для регистрации |
| Шаблон | — | Шаблон процесса регистрации |
| ПовторитьРегистрацию | — | Признак повторной регистрации |
| РезультатРегистрации | — | Итог выполнения |
| Состояние | — | Текущее состояние процесса |

### Табличные части
- **Предметы** — документы, участвующие в регистрации
- **ПредметыЗадач** — предметы задач в рамках регистрации
- **РезультатыРегистрации** — фиксация результатов
- **ДополнительныеРеквизиты**

### Формы
- `ФормаБизнесПроцесса` — основная форма
- `ФормаИзменениеПараметров` — изменение параметров в ходе процесса
- `ФормаИсторияРегистрации` — история прохождения регистрации

### Шаблоны регистрации
**Справочник.ШаблоныРегистрации** хранит настроенные шаблоны для запуска БП Регистрация. Шаблон может быть встроен в комплексный бизнес-процесс (реквизит `ШаблонВКомплексномПроцессе`).

### Результат регистрации (Перечисление.РезультатыРегистрации)
- `НеЗарегистрировано`
- `Зарегистрировано`

## 4. Хранилища настроек нумерации

### 4.1. РегистрСведений.НастройкиНумерации — главная таблица настроек

Это центральный объект конфигурации нумерации. Связывает вид документа с нумератором.

**Измерения (ключ записи):**

| Измерение | Тип |
|-----------|-----|
| ВидДокумента | СправочникСсылка.ВидыДокументов |
| Назначение | ПеречислениеСсылка.НазначенияНумераторов |
| Организация | СправочникСсылка.Организации |
| Подразделение | СправочникСсылка.СтруктураПредприятия |
| ТипДокумента | ПеречислениеСсылка.ТипыОбъектов |
| Контрагент | СправочникСсылка.Контрагенты |
| Тематика | СправочникСсылка.ТематикиДокументов |
| УзелКОД | СправочникСсылка.УзлыКОД |
| ВопросДеятельности | СправочникСсылка.ВопросыДеятельности |
| Проект | СправочникСсылка.Проекты |
| ГрифДоступа | СправочникСсылка.ГрифыДоступа |

**Ресурсы:**
- `Нумератор` (СправочникСсылка.Нумераторы) — какая схема используется
- `СпособНумерации` (ПеречислениеСсылка.СпособыНумерации) — авто или вручную

**Вывод:** Для каждой комбинации вид-документа + назначение (временный/регистрационный) + организация можно назначить свой нумератор со своим способом нумерации.

### 4.2. РегистрСведений.Нумерация — счётчик номеров

Хранит текущее значение счётчика для каждой уникальной комбинации параметров.

**Измерения:**

| Измерение | Тип |
|-----------|-----|
| ВидДокумента | СправочникСсылка.ВидыДокументов |
| Нумератор | СправочникСсылка.Нумераторы |
| Организация | СправочникСсылка.Организации |
| ПериодНумерации | Дата — для периодической нумерации |
| Подразделение | СправочникСсылка.СтруктураПредприятия |
| Проект | СправочникСсылка.Проекты |
| СвязанныйДокумент | СправочникСсылка.ДокументыПредприятия |
| Тематика | СправочникСсылка.ТематикиДокументов |
| ВопросДеятельности | СправочникСсылка.ВопросыДеятельности |
| ГрифДоступа | СправочникСсылка.ГрифыДоступа |
| УзелКОД | СправочникСсылка.УзлыКОД |

**Ресурс:**
- `ТекущийНомер` — Число(10,0, Неотрицательный) — **это и есть счётчик**

### 4.3. РегистрСведений.ИндексыНумерации — строковые индексы

Хранит Индекс (Строка(10)) по Объекту (составной тип: ВидыДокументов, Организации, Сотрудники, Контрагенты, Проекты, ТематикиДокументов, ГрифыДоступа, ВопросыДеятельности). Используется для подстановки кодов/индексов в формат номера.

### 4.4. РегистрСведений.ПропускиРегистрационныхНомеров

Хранит пропущенные номера для их повторного использования.

**Измерения:** Нумератор, ВидДокумента, Организация, Подразделение, Проект, СвязанныйДокумент, Тематика, УзелКОД, ПропущенныйНомер (число).  
**Ресурс:** ДатаФиксации.  
**Форма:** ВыборПропущенныхНомеров — UI для выбора пропущенного номера.

Программный интерфейс: `НумерацияКлиент.ВыборПропущенныхНомеров()`.

### 4.5. РегистрСведений.НумерацияШК — нумерация штрихкодов

Аналог РС.Нумерация для штрихкодирования. Измерение: Нумератор. Ресурс: ТекущийНомер.

## 5. Формирование регистрационного номера — формат, префиксы, счётчики

### Справочник.Нумераторы — схема нумерации

Центральный объект настройки формата номера.

| Реквизит | Тип | Назначение |
|----------|-----|------------|
| ФорматНомера | Строка(0) | Шаблон формата (маска номера) |
| Пример | Строка(120) | Пример сформированного номера |
| Периодичность | ПеречислениеСсылка.ПериодичностьНумераторов | Периодичность сброса счётчика |
| Назначение | ПеречислениеСсылка.НазначенияНумераторов | ВременныйНомер / РегистрационныйНомер |
| ИспользоватьПропущенныеНомера | Булево | Повторно использовать пропущенные номера |
| НезависимаяНумерацияПоВидуДокумента | Булево | Отдельный счётчик по виду |
| НезависимаяНумерацияПоОрганизациям | Булево | Отдельный счётчик по организации |
| НезависимаяНумерацияПоПодразделению | Булево | Отдельный счётчик по подразделению |
| НезависимаяНумерацияПоПроекту | Булево | Отдельный счётчик по проекту |
| НезависимаяНумерацияПоВопросуДеятельности | Булево | Отдельный счётчик по вопросу деятельности |
| НезависимаяНумерацияПоГрифуДоступа | Булево | Отдельный счётчик по грифу |
| НезависимаяНумерацияПоТематике | Булево | Отдельный счётчик по тематике |
| НезависимаяНумерацияПоУзлуКОД | Булево | Отдельный счётчик по узлу корпоративного обмена |
| НезависимаяНумерацияПоСвязанномуДокументу | Булево | Отдельный счётчик по связанному документу |
| тст_ДлинаЧисловогоНомера | Число(2,0) | Минимальная длина числовой части (дополнение нулями) |

### Периодичность нумерации (Перечисление.ПериодичностьНумераторов)
- `Непериодический` — единый сквозной счётчик без сброса
- `День` — счётчик сбрасывается ежедневно
- `Месяц` — сброс ежемесячно
- `Квартал` — сброс ежеквартально
- `Год` — сброс ежегодно

### Принцип формирования номера
1. Из РС.НастройкиНумерации определяется нумератор для данного вида документа + назначения
2. В нумераторе задан ФорматНомера (строка-шаблон)
3. В РС.ИндексыНумерации хранятся строковые коды для подстановки (индексы организаций, видов документов и т.д.)
4. В РС.Нумерация берётся ТекущийНомер и инкрементируется
5. Из ФорматНомера, индексов и числового счётчика собирается итоговый номер
6. Результат записывается в ДокументыПредприятия.РегистрационныйНомер

Реализация: **ОбщийМодуль.Нумерация**, процедура `СформироватьЧисловойНомерДокумента`.

Клиентская часть: **ОбщийМодуль.НумерацияКлиент**, **НумерацияКлиентСервер**.  
Точка расширяемости: **НумерацияПереопределяемый** (переопределяемый модуль).

## 6. Разные схемы нумерации для разных видов документов

**Да, поддерживается и реализована гибко.**

Механизм:
1. Для каждого вида документа (Справочник.ВидыДокументов) в РС.НастройкиНумерации можно задать свой нумератор
2. Одному виду документа можно назначить разные нумераторы для разных комбинаций: организация + подразделение + тематика + узел КОД
3. Каждый нумератор имеет свой ФорматНомера и периодичность
4. Реквизиты НезависимаяНумерацияПо* в нумераторе управляют тем, ведётся ли отдельный счётчик для каждой организации/подразделения/проекта

**Пример сценария:** Входящие письма нумеруются по схеме `ВХ-{ГОД}/{NN}` с ежегодным сбросом, а договоры — по схеме `ДОГ-{ОРГ}-{NN}` с независимым счётчиком по организации.

## 8. Схема взаимодействия объектов

```
Справочник.ВидыДокументов
  └─ ИспользоватьВременныеНомера: Булево
  └─ [связан через РС.НастройкиНумерации]

РС.НастройкиНумерации (ВидДокумента + Назначение + Организация + ...)
  └─ Нумератор → Справочник.Нумераторы
  └─ СпособНумерации: Авто/Вручную

Справочник.Нумераторы
  └─ ФорматНомера: Строка (шаблон)
  └─ Периодичность: Год/Месяц/...
  └─ НезависимаяНумерацияПо*: Булево × 9

РС.Нумерация (Нумератор + ВидДокумента + Организация + ПериодНумерации + ...)
  └─ ТекущийНомер: Число (счётчик)

РС.ИндексыНумерации (Объект)
  └─ Индекс: Строка(10) (код для подстановки)

РС.ПропускиРегистрационныхНомеров
  └─ ПропущенныйНомер: Число

ОМ.Нумерация
  └─ СформироватьЧисловойНомерДокумента() Экспорт

БП.Регистрация
  └─ Шаблон → Справочник.ШаблоныРегистрации
  └─ РезультатРегистрации → НеЗарегистрировано / Зарегистрировано
  └─ ТЧ.РезультатыРегистрации

Справочник.ДокументыПредприятия
  └─ РегистрационныйНомер: ОпределяемыйТип.РегистрационныйНомер
  └─ ВременныйНомер: ОпределяемыйТип.РегистрационныйНомер
  └─ ЧисловойНомер: Число(10,0)
  └─ ДатаРегистрации: Дата
  └─ Зарегистрировал: Сотрудники/Пользователи
```

## 9. Ответы на вопросы теста

| Вопрос | Ответ |
|--------|-------|
| Есть ли автоматическая нумерация при создании документа? | Да — СпособНумерации = Автоматически в РС.НастройкиНумерации. Поддерживается двухступенчатая нумерация: ВременныйНомер → РегистрационныйНомер |
| Что такое регистрация документа — бизнес-процесс? | БизнесПроцесс.Регистрация с исполнителем, предметами, результатом (Зарегистрировано/НеЗарегистрировано). Поддерживает шаблоны (Справочник.ШаблоныРегистрации) |
| Где хранятся настройки нумерации? | РС.НастройкиНумерации (привязка нумератора к виду) + Справочник.Нумераторы (схема) + РС.Нумерация (счётчик) |
| Как формируется регистрационный номер — префиксы, суффиксы, счётчики? | ФорматНомера в Нумераторе задаёт шаблон; индексы для подстановки в РС.ИндексыНумерации; числовой счётчик в РС.Нумерация.ТекущийНомер; сборка в ОМ.Нумерация.СформироватьЧисловойНомерДокумента() |
| Можно ли настроить разные схемы нумерации для разных видов документов? | Да — через РС.НастройкиНумерации разным видам документов назначаются разные нумераторы, с учётом разреза по организации, подразделению, проекту и т.д. |
