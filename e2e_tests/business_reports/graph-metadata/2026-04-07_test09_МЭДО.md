## 1. Обзор подсистемы

МЭДО (Межведомственный Электронный Документооборот) — подсистема для обмена электронными документами между органами государственной власти по стандартам МЭДО 2.5, 2.7 и 2.7.1.

В конфигурации подсистема содержит **53 объекта метаданных** следующих категорий:

| Категория | Количество | Примеры |
|-----------|-----------|---------|
| Документы | 3 | УведомлениеМЭДО, ДанныеДокументаМЭДО, КвитанцияМЭДО |
| ОбщиеМодули | 8 | МЭДО, МЭДОВызовСервера, МЭДОДокументооборот, МЭДОКлиент и др. |
| Перечисления | 7 | ВерсииФорматаМЭДО, СостоянияДокументовМЭДО, ТипыУведомленийМЭДО и др. |
| ОпределяемыеТипы | 10 | ВидДокументаМЭДО, КонтрагентМЭДО, ПредметМЭДО и др. |
| РегистрыСведений | 4 | ЖурналСобытийМЭДО, НастройкиОрганизацийМЭДО и др. |
| ПакетыXDTO | 4 | IEDMSContainerМЭДО_2_7, IEDMSMessageМЭДО_2_7_1 и др. |
| Константы | 5 | ИспользоватьМЭДО, АвтоматическиОтправлятьКвитанцииМЭДО и др. |
| Справочники | 3 | ВидыДокументовМЭДО, МестаСоставленияДокументовМЭДО и др. |
| РегламентныеЗадания | 1 | ВыполнениеОбменаМЭДО |
| Роли | 2 | БазовыеПраваМЭДО, РаботаСМЭДО |
| Прочие | 6 | Обработки, Макеты, ПодпискиНаСобытия, ФункциональныеОпции |

## 3. Процесс отправки документа через МЭДО

### 3.1. Общая схема

```
Пользователь/РЗ
    │
    ▼
МЭДОКлиент (клиентский модуль)
    │ вызов на сервер
    ▼
МЭДОВызовСервера.ОтправитьИсходящиеДокументы(Организация, ДанныеОтвета)
    │ делегирует в основной модуль
    ▼
МЭДО.ОтправитьИсходящиеДокументы(...)
    │
    ├── Формирование пакета XDTO (IEDMSMessage / IEDMSContainer)
    │   ├── Формат 2.5 / 2.7 / 2.7.1 (из НастройкиКонтрагентовМЭДО.ВерсияФорматаМЭДО)
    │   └── Упаковка в ZIP-архив (АрхивЭСД)
    │
    ├── Транспортная отправка (из НастройкиОрганизацийМЭДО.СпособОбмена)
    │   ├── FTP → КаталогОтправкиFTP
    │   └── ДискСеть → КаталогОтправки
    │
    ├── Запись состояния → РегистрСведений.СостоянияДокументовМЭДО
    └── Запись лога → РегистрСведений.ЖурналСобытийМЭДО
```

### 3.2. Задействованные модули

| Модуль | Назначение |
|--------|-----------|
| **МЭДО** | Основной серверный модуль. Содержит `ОтправитьИсходящиеДокументы`, обёртки значений |
| **МЭДОВызовСервера** | Модуль вызова сервера — прокси для клиент→сервер. Метод `ОтправитьИсходящиеДокументы` |
| **МЭДОКлиент** | Клиентский модуль. Конструктор простого ответа `НовыйЛегкийОтвет` |
| **МЭДОКлиентПереопределяемый** | Переопределяемая клиентская часть |
| **МЭДОПереопределяемый** | Переопределяемый серверный модуль. Проверка доступа пользователя к МЭДО |
| **МЭДОДокументооборот** | Методы специфичные для ДО 2.1/3.0. Направление от кэша вида документа |
| **МЭДОСтруктурыДанных** | Конструкторы структур данных: `НовыйЛегкийОтвет`, структуры ответов |
| **МЭДОПовтИсп** | Модуль повторного использования (кэши настроек) |

### 3.3. Ключевые процедуры

- `МЭДОВызовСервера.ОтправитьИсходящиеДокументы(Организация, ДанныеОтвета)` — точка входа с клиента/РЗ
- `МЭДО.ОтправитьИсходящиеДокументы(...)` — основная логика формирования и отправки пакетов
- `МЭДОСтруктурыДанных.НовыйЛегкийОтвет(ЛокальноеИмя)` — создание структуры для zip-архива сообщения МЭДО
- `МЭДОПереопределяемый.ЕстьДоступКМЭДО(...)` — проверка прав пользователя

## 4. HTTP-сервисы и веб-сервисы для интеграции с МЭДО

**Прямых HTTP-сервисов или веб-сервисов с именем "МЭДО" в конфигурации нет.**

Обмен реализован через **файловый транспорт** двух видов (перечисление `СпособыОбменаМЭДО`):

| Способ обмена | Настройки (НастройкиОрганизацийМЭДО) |
|--------------|--------------------------------------|
| **FTP** | КаталогОтправкиFTP, КаталогПолученияFTP |
| **ДискСеть** (сетевая папка) | КаталогОтправки, КаталогПолучения |

Формат сообщений определяется пакетами XDTO:
- `IEDMSContainerМЭДО_2_7` — конверт формата 2.7
- `IEDMSContainerМЭДО_2_7_1` — конверт формата 2.7.1
- `IEDMSMessageМЭДО_2_7` — сообщение формата 2.7
- `IEDMSMessageМЭДО_2_7_1` — сообщение формата 2.7.1

*Конфигурация также содержит WebСервисы (DMMessageService, DMService, DMReg, DMX), которые относятся к ЭДО, но не к МЭДО напрямую.*

## 5. Регламентные задания подсистемы МЭДО

Подсистема обслуживается **одним регламентным заданием**:

| Задание | Назначение |
|---------|-----------|
| **ВыполнениеОбменаМЭДО** | Периодически вызывает отправку исходящих и получение входящих документов. Вызывает `МЭДОВызовСервера.ОтправитьИсходящиеДокументы` |

Настройка автоматической отправки управляется константами:
- `ИспользоватьМЭДО` — включение подсистемы
- `АвтоматическиОтправлятьКвитанцииМЭДО` — автоматическая отправка квитанций
- `ВариантАвтосозданияУведомленийМЭДО` (перечисление: НеСоздавать / Создавать / СоздаватьИОтправлять)
- `РазмерПорцииОбработкиМЭДО` — количество документов за один сеанс
- `ВремяХраненияЖурналаСобытийМЭДО` — срок хранения лога

## 7. Жизненный цикл документа в МЭДО

На основе значений перечисления `СостоянияДокументовМЭДО`:

**Исходящий документ:**
```
ДокументЗарегистрированГотовКОтправке
    → ИсходящийДокументЕщеНеОтправлен
    → ДокументОтправлен
    → (ИсходящееУведомлениеЕщеНеОтправлено → ОтправленоУведомление)
    → (СозданаИсходящаяКвитанция → ОтправленаКвитанция)
    ИЛИ → ОтправкаОтменена
```

**Входящий документ:**
```
ДокументПолучен
    → ВходящийДокументЗарегистрирован
    → ПолученоУведомление
    → ПолученаКвитанция
    ИЛИ → ПолученаКвитанцияОбОшибке
```
