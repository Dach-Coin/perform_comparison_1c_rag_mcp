## Сигнатура и описание

```bsl
// Выполняет попытку определения фактического исполнения.
// 
// Параметры:
//  ДействияЗадач - Массив из ДокументСсылка.ДействиеЗадачи.
//  ВыполнитьОтИмени - СправочникСсылка.Пользователи.
//  ВыбранныйФактическийИсполнитель - Структура.
//  РеквизитыДействийЗадач - Соответствие.
// 
// Возвращаемое значение:
//  Структура:
//   * ДействияБезФактИсполнителя     - Массив из ДокументСсылка.ДействиеЗадачи
//   * ДействияБезКомуАдресовано       - Массив из ДокументСсылка.ДействиеЗадачи
//   * ФактическиеИсполнителиПолные    - Соответствие (ДействиеЗадачи → Справочник.ФактическиеИсполнители)
//   * ФактическиеИсполнителиПоДействиям - Соответствие (ДействиеЗадачи → Сотрудник/Пользователь)
//   * ОснованияФактИсполнителейПоДействиям - Соответствие (ДействиеЗадачи → Замещение)
//
Функция ОпределитьФактическихИсполнителей(
    ДействияЗадач,
    ВыполнитьОтИмени,
    ВыбранныйФактическийИсполнитель,
    РеквизитыДействийЗадач) Экспорт
```

---

## Как работает функция (алгоритм)

Функция реализует многоуровневый алгоритм определения того, **кто фактически выполнит задачу**, с учётом ролевой адресации, замещений и делегирования.

### Шаг 1: Проверка явно указанного исполнителя

Если `ВыбранныйФактическийИсполнитель` передан (пользователь уже выбрал из интерфейса) — исполнитель берётся напрямую. Вызывается:
```bsl
ФактИсполнительПолный = Справочники.ФактическиеИсполнители
    .НайтиСоздатьФактическогоИсполнителя(
        РеквизитыДействия.Исполнитель,
        Адресат,
        ФактИсполнитель,
        ОсновнойСотрудник);
```

### Шаг 2: Проверка ролевой адресации

Если исполнитель задачи — роль (`СправочникСсылка.ПолныеРоли`), функция проверяет: является ли текущий пользователь исполнителем этой роли.

```bsl
Если ТипЗнч(РеквизитыДействия.Исполнитель) = Тип("СправочникСсылка.ПолныеРоли") Тогда
    // Проверка через ВыполнениеОтИмени или ЭтоРольТекущегоПользователя()
    ...
```

Данные о том, кто является исполнителем роли, берутся из:
- `РегистрСведений.ИсполнителиРолейИДелегаты` — хранит соответствие «роль ↔ исполнитель-делегат» с учётом областей делегирования

### Шаг 3: Определение замещающего

Если исполнитель по роли не определён, функция обращается к механизму замещений:

```bsl
ТаблицаЗамещений = Справочники.ЗамещающиеИПомощники
    .АктуальныеЗамещенияПоДействиямЗадач(
        ДействияЗадач,
        ВсеСотрудники);

Для Каждого СтрЗамещения Из ТаблицаЗамещений Цикл
    ...
    ФактИсполнитель = ?(ЭтоПомощник, 
        СтрЗамещения.Сотрудник, 
        ОсновнойСотрудник);
    ОснованияФактИсполнителейПоДействиям[ДействиеЗадачи] = СтрЗамещения.Замещение;
КонецЦикла;
```

Запрос к данным замещений использует:
- `РегистрСведений.ВсеИсполнителиДействийЗадач` — INNER JOIN с `Справочник.ЗамещающиеИПомощники`
- Фильтр по `ВидЗамещения = Замещающие`
- Список `СотрудникиТекущегоПользователя` через `Сотрудники.ВсеСотрудникиТекущегоПользователя()`

### Шаг 4: Если исполнитель — конкретный сотрудник (не роль)

```bsl
Если ВыполняетСотрудник Тогда
    ФактическиеИсполнителиПолные[ДействиеЗадачи] = 
        Справочники.ФактическиеИсполнители
            .НайтиСоздатьФактическогоИсполнителя(
                РеквизитыДействия.Исполнитель);
    ФактическиеИсполнителиПоДействиям[ДействиеЗадачи] = 
        РеквизитыДействия.Исполнитель;
    Продолжить;
КонецЕсли;
```

### Возврат результата

```bsl
ДанныеФактическихИсполнителей = Новый Структура;
ДанныеФактическихИсполнителей.Вставить("ДействияБезФактИсполнителя", ДействияБезФактИсполнителя);
ДанныеФактическихИсполнителей.Вставить("ДействияБезКомуАдресовано", ДействияБезКомуАдресовано);
ДанныеФактическихИсполнителей.Вставить("ФактическиеИсполнителиПолные", ФактическиеИсполнителиПолные);
ДанныеФактическихИсполнителей.Вставить("ФактическиеИсполнителиПоДействиям", ФактическиеИсполнителиПоДействиям);
ДанныеФактическихИсполнителей.Вставить("ОснованияФактИсполнителейПоДействиям", ОснованияФактИсполнителейПоДействиям);
```

## Кто вызывает эту функцию

Функция вызывается в 5 местах системы:

| # | Модуль-вызыватель | Контекст вызова |
|---|-------------------|-----------------|
| 1 | `ОбщиеМодули.БизнесПроцессыИЗадачиСервер` | Функция `ПринятьКИсполнению` — при принятии задачи в работу пользователем |
| 2 | `ОбщиеМодули.РаботаСЗадачами` | Функция `ВзятьВРаботу` — внутренний вызов при взятии задачи в работу (когда исполнитель — роль) |
| 3 | `ОбщиеМодули.РаботаСЗадачамиВызовСервера` | Процедура `ЗаполнитьФактическогоИсполнителя` — при выполнении/взятии в работу из интерфейса |
| 4 | `ОбщиеМодули.ЭскалацияЗадач` | Функции эскалации задач — при автоматическом выполнении просроченных задач |
| 5 | `ОбщиеМодули.РаботаСВнешнимПодписанием` | `ПриВзятииЗадачиВРаботу` / `ПриВыполненииДействияЗадачи` — при работе с КЭП |

### Пример вызова из `БизнесПроцессыИЗадачиСервер.ПринятьКИсполнению`:

```bsl
ДанныеФактическихИсполнителей = 
    РаботаСЗадачами.ОпределитьФактическихИсполнителей(
        ОбщегоНазначенияКлиентСервер.ЗначениеВМассиве(ДействиеЗадачи),
        КтоОтметил,
        ВыбранныйФактическийИсполнитель);

РезультатПринятияКИсполнению.НужноВыбратьФактическогоИсполнителя = 
    ДанныеФактическихИсполнителей.ДействияБезФактИсполнителя.Количество() > 0
    Или ДанныеФактическихИсполнителей.ДействияБезКомуАдресовано.Количество() > 0;

Если Не РезультатПринятияКИсполнению.НужноВыбратьФактическогоИсполнителя Тогда
    ПараметрыПринятияКИсполнению.Исполнитель =
        ДанныеФактическихИсполнителей.ФактическиеИсполнителиПоДействиям[ДействиеЗадачи];
КонецЕсли;
```

### Пример вызова из `РаботаСЗадачамиВызовСервера.ЗаполнитьФактическогоИсполнителя`:

```bsl
// Процедура ЗаполнитьФактическогоИсполнителя — 
// выполняет попытку заполнения фактического исполнения.
// В случае недостаточности данных инициализирует процедуру указания данных.

ДанныеФактическихИсполнителей = РаботаСЗадачами.ОпределитьФактическихИсполнителей(
    ДействияЗадач,
    ПараметрыВыполнения.ВыполнитьОтИмени,
    ПараметрыВыполнения.ВыбранныйФактическийИсполнитель,
    РеквизитыДействийЗадач);

Если ДанныеФактическихИсполнителей.ДействияБезФактИсполнителя.Количество() > 0
    Или ДанныеФактическихИсполнителей.ДействияБезКомуАдресовано.Количество() > 0 Тогда
    // Инициализация интерактивного выбора исполнителя
    ДанныеВыполнения.ВыбратьИсполнителяЗадачи = Истина;
    ДанныеВыполнения.ТребуетсяИнтерактивноеДействие = Истина;
КонецЕсли;
```

## Связанные объекты метаданных

| Объект | Роль |
|--------|------|
| `РегистрСведений.ИсполнителиРолейИДелегаты` | Хранит текущих исполнителей ролей и делегатов; используется для разрешения ролей в конкретных сотрудников |
| `Справочник.ЗамещающиеИПомощники` | Справочник замещений; метод `АктуальныеЗамещенияПоДействиямЗадач` возвращает актуальных замещающих для набора действий |
| `РегистрСведений.ВсеИсполнителиДействийЗадач` | Промежуточный регистр с кешем исполнителей для действий задач |
| `Справочник.ФактическиеИсполнители` | Справочник-кеш пар «адресат + факт»; метод `НайтиСоздатьФактическогоИсполнителя` создаёт или находит запись |
| `РегистрСведений.ИсполнителиВместоНедействительных` | Хранит замещающих для недействительных сотрудников |

## Схема логики определения фактического исполнителя

```
ДействиеЗадачи
      │
      ▼
[Явный выбор пользователя?]
      │ Да → использовать ВыбранныйФактическийИсполнитель
      │ Нет ↓
      ▼
[Исполнитель — конкретный сотрудник?]
      │ Да → ФактИсполнитель = Исполнитель (прямое совпадение)
      │ Нет ↓
      ▼
[Исполнитель — роль (ПолныеРоли)?]
      │ Да → Поиск в ИсполнителиРолейИДелегаты
      │      → Найден → ФактИсполнитель = исполнитель роли
      │      → Не найден → переход к замещениям
      │ Нет ↓
      ▼
[Есть актуальное замещение?] (ЗамещающиеИПомощники)
      │ Да → ФактИсполнитель = Замещающий или ОсновнойСотрудник
      │ Нет ↓
      ▼
[Добавить в ДействияБезФактИсполнителя]
→ Пользователю будет показан диалог выбора исполнителя
```

## Вывод

Искомая процедура — `РаботаСЗадачами.ОпределитьФактическихИсполнителей` в `ОбщиеМодули.РаботаСЗадачами.Модуль`.

Она точно соответствует описанию:
- **Учитывает замещения** — через `ЗамещающиеИПомощники.АктуальныеЗамещенияПоДействиямЗадач`
- **Работает с ролями исполнителей** — через `ИсполнителиРолейИДелегаты` и тип `ПолныеРоли`
- **Вызывается при назначении/взятии задачи** — из `ПринятьКИсполнению`, `ВзятьВРаботу`, `ЗаполнитьФактическогоИсполнителя`
