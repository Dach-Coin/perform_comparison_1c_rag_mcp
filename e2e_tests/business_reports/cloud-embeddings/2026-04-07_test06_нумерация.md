**Источник:** MCP-сервер 1c-cloud-embeddings

## 1. Автоматическая нумерация при создании документа

Нумерация в 1С:Документооборот КОРП **не происходит автоматически при создании** карточки документа. Регистрационный номер присваивается **после прохождения процессов согласования и утверждения**.

Механизм получения номера:
- Пользователь нажимает кнопку **"№"** в карточке документа
- Система вызывает `НумерацияКлиентСервер.ПолучитьПараметрыНумерации(Объект)` и передаёт их в `Нумерация.СформироватьЧисловойНомерДокумента` / `Нумерация.СформироватьСтроковыйНомерДокумента`
- Если нумератор не определён (ручная нумерация) — пользователю предлагается **ввести номер вручную** через диалог

При записи документа (`ПередЗаписью`) выполняется проверка:
- Если нумератор найден и способ — автоматический, то номер формируется автоматически
- Если нумератор не задан и параметр `УказанРегистрационныйНомер` не установлен — система запрашивает ручной ввод
- Существуют **временные номера** (назначение `НазначенияНумераторов.ВременныйНомер`) — документ получает временный номер до регистрации

## 2. Бизнес-процесс "Регистрация"

Регистрация документа — это отдельный **бизнес-процесс** (`БизнесПроцесс.Регистрация`), который отвечает за официальное присвоение регистрационного номера.

### Правила инициации
- Документы, подписанные **руководителем организации**, регистрирует **секретарь** (централизованная регистрация)
- Остальные документы регистрируются **авторами в подразделениях** самостоятельно

### Точки маршрута процесса (задачи)
- **Зарегистрировано** (`ЗадачаЗарегистрировано`) — регистратор присвоил номер
- **Не зарегистрировано** (`ЗадачаНеЗарегистрировано`) — регистратор отказал
- **Ознакомиться с регистрацией** (`ЗадачаРегистрацияОзнакомился`) — автор ознакамливается с результатом
- **Повторить регистрацию** (`ЗадачаРегистрацияПовторить`) — при отрицательном результате

### Условия регистрации
- Документ должен быть **утверждён** (неутверждённые документы не регистрируются)
- Регистрацию нужно выполнить **в день утверждения** или не позднее первой половины следующего рабочего дня
- При регистрации обязательно заполняются: **регистрационный номер** и **хранение**

### Программная точка входа
Ключевая функция: `ОбщиеМодули.Делопроизводство.ЗарегистрироватьПредмет(Предмет, СообщениеОбОшибке, РегистрационныйНомер)` — проверяет права и регистрирует документ.

## 3. Хранение настроек нумерации

Настройки нумерации хранятся в **регистре сведений `РегистрыСведений.НастройкиНумерации`** и связываются с видом документа.

### Структура регистра НастройкиНумерации

| Поле | Тип | Назначение |
|------|-----|-----------|
| ВидДокумента | СправочникСсылка | Вид документа, для которого действует настройка |
| ТипДокумента | Перечисление | Внутренний/Входящий/Исходящий |
| Организация | СправочникСсылка | Организация (может быть пустой — для всех) |
| Подразделение | СправочникСсылка | Подразделение (может быть пустой) |
| ВопросДеятельности | СправочникСсылка | Вопрос деятельности |
| Контрагент | СправочникСсылка | Контрагент |
| Проект | СправочникСсылка | Проект |
| Тематика | СправочникСсылка | Тематика документа |
| ГрифДоступа | СправочникСсылка | Гриф доступа |
| Нумератор | СправочникСсылка | Ссылка на нумератор |
| СпособНумерации | Перечисление | Автоматически / Вручную |
| Назначение | Перечисление | РегистрационныйНомер / ВременныйНомер |
| Нумеровать | Строка | Отображаемое поле "Нумеровать" |

### Работа с настройками
- Чтение: `ОбщиеМодули.Нумерация.ПрочитатьНастройкиНумерацииВидаДокумента(ВидДокумента)`
- Запись: `ОбщиеМодули.Нумерация.ЗаписатьНастройкиНумерацииВидаДокумента(ВидДокумента, НастройкиНумерации)`
- Форма настройки доступна через карточку вида документа в разделе **"Нормативно-справочная информация"**

### Счётчики номеров: РегистрСведений.Нумерация
Фактические счётчики хранятся в отдельном регистре `РегистрСведений.Нумерация` с ресурсом `ТекущийНомер`. При автоматической нумерации на запись накладывается **блокировка данных** по ключу (Нумератор, ПериодНумерации, Организация, ...) для исключения дублирования номеров.

Для пропущенных номеров существует отдельный регистр `РегистрыСведений.ПропускиРегистрационныхНомеров` — ведётся учёт и повторное использование пропущенных номеров.

## 4. Формирование регистрационного номера

### Справочник Нумераторы (Справочники.Нумераторы)

Нумератор — основной объект настройки вида номера. Ключевые реквизиты:

| Реквизит | Назначение |
|----------|-----------|
| **ФорматНомера** | Шаблон строкового номера (например: `[Номер]-[Год4]` или `[Организация]/[Номер]`) |
| **Периодичность** | Период сброса счётчика |
| **Назначение** | РегистрационныйНомер / ВременныйНомер |
| **НезависимаяНумерацияПоОрганизациям** | Отдельный счётчик для каждой организации |
| **НезависимаяНумерацияПоСвязанномуДокументу** | Счётчик по связанному документу |
| **НезависимаяНумерацияПоПодразделению** | Счётчик по подразделению |
| **НезависимаяНумерацияПоПроекту** | Счётчик по проекту |
| **НезависимаяНумерацияПоВопросуДеятельности** | Счётчик по вопросу деятельности |
| **НезависимаяНумерацияПоВидуДокумента** | Счётчик по виду документа |
| **НезависимаяНумерацияПоТематике** | Счётчик по тематике |
| **НезависимаяНумерацияПоГрифуДоступа** | Счётчик по грифу доступа |
| **НезависимаяНумерацияПоУзлуКОД** | Счётчик по узлу распределённой базы |

### Переменные формата номера

В строке формата используются теги вида `[ИмяПеременной]`:

| Тег | Значение |
|-----|---------|
| `[Номер]` | Порядковый числовой номер (из счётчика) |
| `[День]` | День даты регистрации (2 цифры) |
| `[Месяц]` | Месяц даты регистрации (2 цифры) |
| `[Год4]` | Год в формате 4 цифры (2026) |
| `[Год2]` | Год в формате 2 цифры (26) |
| `[Квартал]` | Квартал (1-4) |
| `[ИндексВидаДок]` | Буквенный индекс вида документа |
| `[Организация]` | Код или наименование организации |
| `[Проект]` | Проект документа |
| `[ГрифДоступа]` | Гриф доступа |

Пример форматов:
- Стандартный: `[Номер]` → `00125`
- С годом: `[Номер]-[Год4]` → `125-2026`
- Временный: `[Номер]-[ИндексВидаДок]` → `125-ВнД`
- Сложный: `[Организация]/[Год2]/[Номер]` → `ООО/26/125`

### Периодичность нумерации

| Значение | Смысл |
|----------|-------|
| `День` | Счётчик сбрасывается ежедневно |
| `Месяц` | Счётчик сбрасывается ежемесячно |
| `Квартал` | Счётчик сбрасывается ежеквартально |
| `Год` | Счётчик сбрасывается ежегодно |
| `Непериодический` | Счётчик никогда не сбрасывается (сквозная нумерация) |

### Стандартные префиксы (ПрефиксацияОбъектов)

Параллельно с нумерацией ДО3 существует механизм стандартных префиксов (из БСП), который добавляет к номеру 2-значный или 5-значный буквенно-цифровой префикс (идентификатор узла базы данных). Определяется функцией `НомерСодержитСтандартныйПрефикс` — позиция разделителя "-" на 3-й или 5-й позиции.

## 5. Разные схемы нумерации для разных видов документов

**Да, полностью поддерживается.** Архитектура позволяет настроить:

### Уровни гибкости

1. **По виду документа** — каждому виду назначается свой нумератор через `РегистрыСведений.НастройкиНумерации`
2. **По организации** — один вид документа может нумероваться по-разному в разных организациях (флаг `НезависимаяНумерацияПоОрганизациям`)
3. **По подразделению** — отдельный счётчик для каждого подразделения
4. **По проекту, тематике, грифу доступа** — дополнительные измерения для детальной сегментации

### Настройка через карточку вида документа
- Раздел: **"Нормативно-справочная информация" → "Виды документов"**
- Количество видов документов не ограничено
- Каждый вид может иметь собственный нумератор или быть без нумерации (ручной ввод)

### Предопределённые нумераторы
- `Справочники.Нумераторы.ДокументыПредприятия` — общий нумератор по умолчанию для внутренних документов
- Нумератор "Временные номера" — создаётся автоматически при первом запуске системы

### Способы нумерации
- **Автоматически** (`Перечисления.СпособыНумерации.Автоматически`) — система присваивает следующий номер из счётчика
- **Вручную** — пользователь вводит номер самостоятельно

## Итоговая схема архитектуры

```
Вид документа (Справочники.ВидыДокументов)
    └─► РегистрСведений.НастройкиНумерации
              ├─ Нумератор → Справочники.Нумераторы
              │     ├─ ФорматНомера: "[Номер]-[Год4]"
              │     ├─ Периодичность: Год
              │     └─ НезависимаяНумерацияПо...: флаги
              └─ СпособНумерации: Автоматически

При регистрации документа:
    ОбщиеМодули.Нумерация
        ├─ ПолучитьНумераторДокумента() → из НастройкиНумерации
        ├─ СформироватьЧисловойНомерДокумента()
        │     └─► РегистрСведений.Нумерация (блокировка, инкремент ТекущийНомер)
        ├─ СформироватьСтроковыйНомерДокумента()
        │     └─► РазобратьФорматНомера() + ПолучитьЗначенияПараметровНомера()
        │         └─► СформироватьНомерДокументаПоФормату()
        └─ Результат: РегистрационныйНомер в карточке документа

Если номер пропущен:
    └─► РегистрыСведений.ПропускиРегистрационныхНомеров
```
