# Регистры, обновляемые при работе с задачами в 1С:ДО КОРП 3.0
**Конфигурация:** ДокументооборотКОРП v3.0.14.31 (Тест ДО3)  
**Дата анализа:** 2026-06-05  
**Источник:** анализ исходного кода через rlm-tools-bsl v1.17.0

---

## Предварительное замечание об архитектуре

«Задача» в 1С:ДО КОРП 3.0 — это **Documents.Задача** (не объект Tasks.ЗадачаИсполнителя, который является нестандартным типом Tasks и не имеет механизма проведения). Каждый участник задачи представлен отдельным документом **Documents.ДействиеЗадачи**. Именно эти два объекта являются основными регистраторами движений.

## 1. Регистры накопления

### 1.1 КоличествоЗадач
**Синоним:** Регистр накопления: Количество задач

**Измерения:**
- `Автор` — автор задачи
- `ВидЗадачи` (CatalogRef.ВидыЗадач) — тип задачи
- `Проект` (CatalogRef.Проекты)
- `Флаг` (EnumRef.ФлагиОбъектов)
- `ТипПриложения` (EnumRef.ТипыПриложенийЗадач)
- `ВидПриложения`
- `Контрагент` (CatalogRef.Контрагенты)

**Ресурсы:** `Всего`, `ВРаботе`, `Выполненных`, `Новых`, `ОжидающихВыполнения`, `ОжидающихПроверки`, `Просроченных`, `ПросроченныхОжидающихВыполнения`, `Черновиков`

**Кто пишет:** Documents/Задача/Ext/ObjectModule.bsl — процедура `ОбработкаПроведения`

**Как заполняется:** При проведении задачи вызывается `Движения.КоличествоЗадач.ОбновитьДанныеЗадачи(РеквизитыЗадачи)` — метод RecordSetModule, который устанавливает ресурсы (1 или 0) в зависимости от `ВидСостоянияЗадачи`:
```bsl
Запись.ВРаботе = ?(ВРаботе, 1, 0);
Запись.Выполненных = ?(Выполнена, 1, 0);
Запись.Новых = ?(Новая, 1, 0);
Запись.ОжидающихВыполнения = ?(ОжидаетВыполнения, 1, 0);
...
```

---

### 1.2 КоличествоДействийЗадач
**Синоним:** Регистр накопления: Количество действий задач

**Измерения (10):** `Исполнитель`, `Замещающий` (CatalogRef.Сотрудники), `Автор`, `ВидДействия` (CatalogRef.ВидыДействийЗадач), `Проект`, `Флаг`, `ТипПриложения`, `ВидПриложения`, `ВидЗадачи`, `Контрагент`

**Ресурсы (11):** `Всего`, `ВРаботе`, `ВСрок`, `Выполненных`, `Истекающих`, `Новых`, `ОжидающихВыполнения`, `ОжидающихПроверки`, `ПоступилиОбновления`, `Просроченных`, `ПросроченныхОжидающихВыполнения`

**Кто пишет:** Documents/ДействиеЗадачи/Ext/ObjectModule.bsl — `ОбработкаПроведения`

**Как заполняется:** Через `РегистрыНакопления.КоличествоДействийЗадач.ЗаполнитьНаборПоДействию(Движения.КоличествоДействийЗадач, Ссылка, ...)`. Важно: для каждого действия создаётся **одна запись для основного исполнителя + по записи для каждого замещающего** из регистра ВсеИсполнителиДействийЗадач:
```bsl
ВсеЗамещенияПоДействию = РегистрыСведений.ВсеИсполнителиДействийЗадач.ЗамещенияПоДействию(ДействиеЗадачи);
Для Каждого СтрокаЗамещения Из ВсеЗамещенияПоДействию Цикл
    ЗаписьПоЗамещению = НаборЗаписей.Добавить();
    ЗаписьПоЗамещению.Замещающий = СтрокаЗамещения.Замещающий;
КонецЦикла;
```

Также обновляется при изменении реквизитов задачи через `КоличествоДействийЗадач.ОбновитьДанныеЗадачи(ДействиеЗадачи, ...)`.

## 2. Регистры сведений

### 2.1 ДействияЗадач
**Синоним:** Регистр сведений: Действия задач

**Измерения (3):** `Исполнитель`, `Дата`, `ДействиеЗадачи`

**Ресурсы (40):** Включают `Автор`, `ВидДействия`, `ВидЗадачи`, `ВидСостоянияУчастниковЗадач`, `ВРаботе`, `ВСрок`, `Выполнено`, `ДатаВыполнения`, `ДатаНачала`, `ЕстьЗамещающие`, `ЕстьПодзадачи`, `Заголовок`, `Задача`, `Истекает`, `Новое`, `ОжидаетВыполнения`, `ОжидаетПроверки`, `Просрочено`, `ПросроченоИОжидаетВыполнения`, `Срок`, `Трудозатраты`, `Флаг` и другие (всего 40 ресурсов).

**Кто пишет:** Documents/ДействиеЗадачи — `ОбработкаПроведения` и `ПриЗаписи`; также Documents/Задача — `ПриЗаписи` (при изменении реквизитов задачи)

**Как заполняется:**
- При проведении ДействиеЗадачи: `Движения.ДействияЗадач.ОбновитьДанныеДействия(РеквизитыДействия)` + `ОбновитьДанныеЗадачи(РеквизитыДействия, РеквизитыЗадачи)` — заполняет все 40 ресурсов, в т.ч. `ЕстьЗамещающие = ВсеИсполнителиДействийЗадач.ЕстьЗамещающиеПоДействию()`
- При изменении задачи (Documents/Задача.ПриЗаписи): `РегистрыСведений.ДействияЗадач.ОбновитьДанныеЗадачи(АктивноеДействие, ДанныеДействия, РеквизитыЗадачи)` — обновляет заголовок, срок, проект, трудоёмкость в записях уже существующих действий
- При изменении вышестоящего задачи/действия: `ДействияЗадач.ОбновитьПодзадачи(ВышестоящееДействие)`

---

### 2.2 ВсеИсполнителиДействийЗадач
**Синоним:** Регистр сведений: Все исполнители действий задач

**Измерения (3):** `ДействиеЗадачи`, `Исполнитель`, `Основание`

**Ресурсы:** нет (только измерения — это таблица принадлежности)

**Кто пишет:** Documents/ДействиеЗадачи — `ПриЗаписи` (строки 402-415)

**Как заполняется:** При создании нового действия или смене исполнителя — прямая запись набора:
```bsl
Набор = РегистрыСведений.ВсеИсполнителиДействийЗадач.СоздатьНаборЗаписей();
Набор.Отбор.ДействиеЗадачи.Установить(Ссылка);
Набор.Отбор.Исполнитель.Установить(Исполнитель);
Запись = Набор.Добавить();
Набор.Записать();
```
Также через `ЗамещающиеИПомощники.ЗаписатьДоступЗамещающихПоДействиюЗадачи(Ссылка)` — добавляет замещающих.

### 2.3 ЗадачиПоАвторам
**Синоним:** Регистр сведений: Задачи по авторам

**Измерения (3):** `Автор`, `Дата`, `Задача` (DocumentRef.Задача)

**Ресурсы (27):** Включают `ВидЗадачи`, `ВидСостоянияЗадачи`, `ВРаботе`, `Выполнена`, `ДатаВыполнения`, `ЕстьПодзадачи`, `Заголовок`, `КонтрольныйСрок`, `Новая`, `ОжидаетВыполнения`, `ОжидаетПроверки`, `Просрочена`, `ПросроченаИОжидаетВыполнения`, `СостояниеЗадачи`, `Срок`, `Трудозатраты`, `Флаг`, `ЭтоЧерновик` и другие

**Кто пишет:** Documents/Задача — `ОбработкаПроведения`

**Как заполняется:**
- При проведении: `Движения.ЗадачиПоАвторам.ОбновитьДанныеЗадачи(РеквизитыЗадачи)` — заполняет состояние, срок, контрольный срок, трудозатраты
- При изменении вышестоящей задачи: `ЗадачиПоАвторам.ОбновитьПодзадачи(ВышестоящаяЗадача)`

### 2.4 ИсторияЗадач
**Синоним:** Регистр сведений: История задач

**Измерения (4):** `Задача` (DocumentRef.Задача), `Событие` (CatalogRef.СобытияЗадач), `Дата` (DateTime), `ДействиеЗадачи` (DocumentRef.ДействиеЗадачи)

**Ресурсы (1):** `Контекст` (структура с параметрами события)

**Кто пишет:**
- Documents/Задача — `ПриЗаписи` (перенос срока) и `УстановитьСостояние` (выполнение/закрытие)
- Documents/ДействиеЗадачи — `ПриЗаписи` (перенос особого срока действия)

**Как заполняется — ключевые события:**
```bsl
// При выполнении задачи (УстановитьСостояние):
РегистрыСведений.ИсторияЗадач.Добавить(Ссылка, ..., СобытияЗадач.Закрыта, ...);
// При закрытии подзадачи:
РегистрыСведений.ИсторияЗадач.Добавить(ВышестоящаяЗадача, ..., СобытияЗадач.ЗакрытаПодзадача, ...);
// При переносе срока:
РегистрыСведений.ИсторияЗадач.Добавить(Ссылка, ..., СобытияЗадач.ПеренесенСрок, КонтекстПереносаСрока, ...);
```

## 4. Как меняются данные при смене статуса задачи

Статусы задачи определяются через `ВидыСостоянийЗадач` (перечисление): `Черновик`, `Новая`, `ВРаботе`, `ОжидаетВыполнения`, `ОжидаетПроверки`, `Выполнена`, `Отменена`, `Отложена`.

### Схема обновлений по событиям:

#### Создание задачи (новый документ → Проведение)
1. **ОбработкаПроведения** (Documents/Задача):
   - `КоличествоЗадач` — добавляется запись; `Новых=1`, `Всего=1`, остальные =0
   - `ЗадачиПоАвторам` — добавляется запись со состоянием «Новая»
2. **ПриЗаписи** (Documents/Задача):
   - Для каждого участника создаётся Documents/ДействиеЗадачи
3. **ОбработкаПроведения** (Documents/ДействиеЗадачи):
   - `КоличествоДействийЗадач` — `Новых=1`, `Всего=1`
   - `ДействияЗадач` — новая запись с `Новое=Истина`
4. **ПриЗаписи** (Documents/ДействиеЗадачи):
   - `ВсеИсполнителиДействийЗадач` — запись исполнителя

#### Взятие в работу (статус → ВРаботе)
- Задача перепроводится: `КоличествоЗадач`: `ВРаботе=1`, `Новых=0`
- ДействиеЗадачи перепроводится: `КоличествоДействийЗадач`: `ВРаботе=1`, `Новых=0`
- `ДействияЗадач`: `ВРаботе=Истина`, `Новое=Ложь`

#### Изменение реквизитов (без смены состояния)
- Если изменились «кэшируемые реквизиты» задачи (список возвращается `КэшируемыеРеквизитыЗадач()`):
  - `ДействияЗадач.ОбновитьДанныеЗадачи(...)` — обновляет заголовок, срок, проект в записях всех активных действий
  - `КоличествоДействийЗадач.ОбновитьДанныеЗадачи(...)` — обновляет измерения
- Если изменился список участников:
  - Новому участнику создаётся ДействиеЗадачи → записи во всех регистрах как при создании
  - `ДействияЗадач.ОбновитьДанныеЗадачи(...)` вызывается для всех активных действий

#### Завершение задачи (статус → Выполнена)
- `УстановитьСостояние()` (Documents/Задача):
  - `ИсторияЗадач.Добавить(...)` событие `Закрыта` с датой выполнения
  - Если есть вышестоящая задача: `ИсторияЗадач.Добавить(ВышестоящаяЗадача, ...)` событие `ЗакрытаПодзадача`
- При перепроведении документа Задача:
  - `КоличествоЗадач`: `Выполненных=1`, `ВРаботе=0`, `ОжидающихВыполнения=0`
  - `ЗадачиПоАвторам`: `Выполнена=Истина`, `ВРаботе=Ложь`
- При перепроведении документов ДействиеЗадачи:
  - `КоличествоДействийЗадач`: `Выполненных=1`, `ВСрок` или `Просроченных` по факту
  - `ДействияЗадач`: `Выполнено=Истина`, `ОжидаетВыполнения=Ложь`

#### Перенос срока
- `ПриЗаписи` (Documents/Задача или ДействиеЗадачи):
  - `ИсторияЗадач.Добавить(...)` событие `ПеренесенСрок` с контекстом (СтарыйСрок, НовыйСрок)

#### Регламентное обновление просроченности (задание ПометкаЗадачПросроченными)
Обновляются все 5 регистров сразу по актуальному состоянию всех задач:
```
РегистрыСведений.ДействияЗадач.ПометитьПросроченныеЗадачи()
РегистрыСведений.ДействияЗадач.ПометитьИстекающиеЗадачи()
РегистрыСведений.ЗадачиПоАвторам.ПометитьПросроченныеЗадачи()
РегистрыНакопления.КоличествоЗадач.ПометитьПросроченныеЗадачи()
РегистрыНакопления.КоличествоДействийЗадач.ПометитьПросроченныеЗадачи()
РегистрыНакопления.КоличествоДействийЗадач.ПометитьИстекающиеЗадачи()
```
