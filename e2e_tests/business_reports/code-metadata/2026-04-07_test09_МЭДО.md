# Подсистема МЭДО в 1С:Документооборот КОРП 3.0
**Дата анализа**: 2026-04-07  
**Сервер**: 1c-code-metadata  
**Конфигурация**: 1С:Документооборот КОРП 3.0

---

## 1. Обзор подсистемы

МЭДО (Межведомственный электронный документооборот) — отдельная подсистема в составе конфигурации, расположена в дереве подсистем:  
`Подсистемы.СтандартныеПодсистемыДокументооборота.Подсистемы.МЭДО`

Подсистема управляется функциональной опцией `ФункциональныеОпции.ИспользоватьМЭДО` (хранится в константе `Константы.ИспользоватьМЭДО`).

## 3. Процесс отправки документа через МЭДО

### 3.1 Архитектура обмена

МЭДО работает через **файловый обмен** — запись/чтение zip-архивов ЭСД (Электронных Сообщений Документооборота) в каталоги отправки и получения на файловой системе сервера. Формат контейнера — МЭДО 2.7 / 2.7.1 (пакеты XDTO IEDMSContainer, IEDMSMessage).

HTTP-сервисов и веб-сервисов специфически для МЭДО в конфигурации **нет**. Для интеграции используется **каталог отправки** (КаталогОтправки) и **каталог получения** (КаталогПолучения), настраиваемые в РегистрСведений.НастройкиОрганизацийМЭДО.

Настройки транспорта хранятся в РегистрСведений.НастройкиОрганизацийМЭДО, реквизит `СпособОбмена` (тип: Перечисление.СпособыОбменаМЭДО).

### 3.2 Пошаговый процесс отправки исходящего документа

1. **Подготовка документа** (на стороне пользователя или другой подсистемы)  
   - На документе предприятия устанавливается признак "готов к отправке" через МЭДО
   - Создаётся запись `Документ.ДанныеДокументаМЭДО` с реквизитами ГотовКОтправке=Истина

2. **Регламентное задание** `ВыполнениеОбменаМЭДО` (метод: `МЭДО.ВыполнитьОбменМЭДО`)  
   - Запускается по расписанию  
   - В цикле по организациям: получает настройки КаталогОтправки / КаталогПолучения из РС НастройкиОрганизацийМЭДО

3. **Отправка исходящих документов**: `МЭДО.ОтправитьИсходящиеДокументы(Настройки, ДанныеОтвета)`  
   - Вызывает `МЭДО.ОтправитьИсходящийДокумент(Настройки, Документ, ДанныеОтвета)` для каждого документа  
   - Формирует XML-контейнер через пакеты XDTO (IEDMSContainer/IEDMSMessage)  
   - Записывает zip-архив в КаталогОтправки  
   - Устанавливает признак Отправлен=Истина в ДанныеДокументаМЭДО

4. **Отправка исходящих уведомлений**: `МЭДО.ОтправитьИсходящиеУведомления(Настройки, ДанныеОтвета)`  
   - Выбирает Документ.УведомлениеМЭДО с ГотовоКОтправке=Истина  
   - Формирует XML-уведомление нужного типа (через ИсходящееУведомление_ЗаполнитьXxx-процедуры)  
   - Записывает в КаталогОтправки

5. **Отправка квитанций**: `МЭДО.ОтправитьИсходящиеКвитанции(Настройки, ДанныеОтвета)`  
   - Аналогично для КвитанцияМЭДО с ГотоваКОтправке=Истина

6. **Получение входящих**: `МЭДО.ПолучитьВходящиеСообщения(Настройки, "Транспортный контейнер, Документ, Уведомление, Квитанция")`  
   - Читает zip-файлы из КаталогПолучения  
   - Для каждого файла вызывает `МЭДО.ОбработатьВходящееЭСД(ФайлZip, Организация, ТипКонтента, ДанныеОтвета)`  
   - Распаковывает zip, обрабатывает communication-объект XDTO  
   - Создаёт ДанныеДокументаМЭДО, УведомлениеМЭДО или КвитанцияМЭДО  
   - Делает движение в РС.СостоянияДокументовМЭДО

## 4. HTTP-сервисы и веб-сервисы для интеграции с МЭДО

**HTTP-сервисов для МЭДО в конфигурации нет.**  

Интеграция МЭДО реализована через файловый обмен:
- Исходящие: запись zip-архивов ЭСД в **КаталогОтправки**
- Входящие: чтение zip-архивов из **КаталогПолучения**

Формат контейнеров: **МЭДО 2.7 / 2.7.1** (XDTO-пакеты IEDMSContainerМЭДО_2_7, IEDMSContainerМЭДО_2_7_1, IEDMSMessageМЭДО_2_7, IEDMSMessageМЭДО_2_7_1).

Настройка транспорта (способ обмена) хранится в `РегистрСведений.НастройкиОрганизацийМЭДО.СпособОбмена` — тип `Перечисление.СпособыОбменаМЭДО`. Конкретные значения этого перечисления (ЧерезПапку, ЧерезConnector и т.п.) в ходе анализа точно установить не удалось.

| Имя | Синоним | Метод | По умолчанию |
|-----|---------|-------|--------------|
| ВыполнениеОбменаМЭДО | Выполнение обмена МЭДО | МЭДО.ВыполнитьОбменМЭДО | Использование: Ложь (выключено) |

## 6. Вспомогательные объекты подсистемы

### Регистры сведений
- `НастройкиОрганизацийМЭДО` — настройки каталогов и параметров обмена
- `НастройкиКонтрагентовМЭДО` — настройки контрагентов (версия МЭДО, адрес и т.д.)
- `СостоянияДокументовМЭДО` (срез последних) — текущие состояния документов
- `ЖурналСобытийМЭДО` — журнал операций

### Справочники
- `ВидыДокументовМЭДО` — классификатор видов (КодМЭДО, НаименованиеПолное)
- `МестаСоставленияДокументовМЭДО` — классификатор мест составления
- `ПричиныОтказаВРегистрацииМЭДО` — причины отказа

### Перечисления
- `ТипыУведомленийМЭДО` — типы уведомлений
- `СостоянияДокументовМЭДО` — состояния (Отправлено, ПолученаКвитанция, ОтправленоУведомление, ПолученаКвитанцияОбОшибке и др.)
- `НаправленияСообщенийМЭДО` — Входящее / Исходящее
- `ВерсииФорматаМЭДО` — версии формата (2_7, 2_7_1)
- `УровниСобытийМЭДО` — Информация, Предупреждение, Ошибка
- `СпособыОбменаМЭДО` — способы обмена (значения не раскрыты)

### Роли
- `РаботаСМЭДО` — основная роль пользователя МЭДО
- `БазовыеПраваМЭДО` — базовые права
