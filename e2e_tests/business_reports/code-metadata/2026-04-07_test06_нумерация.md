## 1. Общая архитектура подсистемы нумерации

В DO3 нумерация и регистрация — два разных, но связанных механизма:

- **Нумерация** — автоматическое присвоение регистрационного номера по шаблону (технический механизм)
- **Регистрация** — бизнес-процесс фиксации факта получения/создания документа (организационный акт)

Основной общий модуль: `Нумерация` (CommonModules/Нумерация/Ext/Module.bsl)

## 2. Автоматическая нумерация при создании документа

**Нет** — номер НЕ присваивается автоматически при создании документа.

Механизм работает следующим образом:

1. При сохранении незарегистрированного документа вызывается `Нумерация.УстановитьВременныйНомерПередЗаписью(ЭтотОбъект)` — документ получает **временный номер** (реквизит `ДокументыПредприятия.ВременныйНомер`).
2. Регистрационный номер присваивается **в момент регистрации** — при нажатии кнопки **"№"** на форме документа или при выполнении бизнес-процесса регистрации.
3. После нажатия кнопки "№" вызывается `Нумерация.СформироватьСтроковыйНомерДокумента()`, который и формирует итоговый строковый номер.
4. Регистрационный номер присваивается **только после согласования и утверждения** документа.

Реквизит вида документа `ВидыДокументов.ИспользоватьВременныеНомера` (Булево) управляет — показывать ли временный номер до регистрации.

**Где хранится:** реквизит `Справочники.ДокументыПредприятия.РегистрационныйНомер` (тип `ОпределяемыйТип.РегистрационныйНомер`), аналогичный реквизит в `РС.ДанныхДокументовПредприятия.РегистрационныйНомер`.

## 3. Регистрация документа — бизнес-процесс

В DO3 существует **отдельный бизнес-процесс** `БизнесПроцессы.Регистрация`.

### Бизнес-логика регистрации:
- Документы, которые подписывает руководитель организации, регистрирует **секретарь**
- Остальные документы регистрируются в подразделениях **авторами самостоятельно**
- Срок: **в день утверждения** или не позднее первой половины следующего рабочего дня
- Незарегистрированные (неутверждённые) документы регистрации не подлежат

### Точки маршрута бизнес-процесса Регистрация:
- `Ознакомиться` — основная задача регистратора
- `ПовторитьРегистрацию` — повторная регистрация при необходимости

### Программная регистрация:
При записи документа вызывается `Делопроизводство.ЗарегистрироватьПредмет(ЭтотОбъект, СообщениеОбОшибке, НовыйРегистрационныйНомер, ПараметрыЗаписи, Ложь)`.

### Обязательные поля при регистрации:
- Регистрационный номер
- Хранение (место хранения документа)

## 5. Формирование регистрационного номера

### Справочник Нумераторы (Catalog.Нумераторы)

Нумератор — центральный объект настройки нумерации. Ключевые реквизиты:

| Реквизит | Тип | Описание |
|----------|-----|----------|
| ФорматНомера | Строка (переменная, многострочная, обязательная) | Шаблон формирования номера |
| Периодичность | ПеречислениеСсылка.ПериодичностьНумераторов | Период сброса счётчика (дефолт: **Год**) |
| Назначение | ПеречислениеСсылка.НазначенияНумераторов | Дефолт: **РегистрационныйНомер** |
| ТипСвязи | СправочникСсылка.ТипыСвязей | Связь, необходимая для нумерации |

**ФорматНомера** — строковый шаблон, в который подставляются значения из контекста документа (год, вид, подразделение и т.п.). Тип строка без ограничения длины, многострочный (поддерживает сложные шаблоны).

**Периодичность** определяет, когда сбрасывается числовой счётчик. Значение по умолчанию — **Год** (ежегодный сброс). Используется тип `ПеречислениеСсылка.ПериодичностьНумераторов`.

### Алгоритм выбора нумератора (весовая система)

Общий модуль `Нумерация.ПолучитьНумераторДокумента()` применяет **весовую систему приоритетов**:

```
Вес = совпадение(ВидДокумента) × 1
    + совпадение(Организация) × 1
    + совпадение(Подразделение) × 1
    + совпадение(ВопросДеятельности) × 1
    + совпадение(Контрагент) × 1
    + совпадение(Проект) × 1
    + ...
```

Побеждает нумератор с наибольшим суммарным весом (наиболее специфичная настройка побеждает общую).

### Этапы формирования номера:
1. Определяется нумератор по весовой системе
2. Из нумератора читается `ФорматНомера`
3. Числовой номер получается из `РС.Нумерация` (по ключу: Нумератор + ПериодНумерации + ВидДокумента)
4. Строковый номер формируется подстановкой значений в шаблон ФорматНомера
5. Числовой номер хранится в `ДокументыПредприятия.ЧисловойНомер`, строковый — в `РегистрационныйНомер`

При ручном изменении номера пользователем устанавливается `ЧисловойНомер = -1` (флаг ручного изменения).

## 6. Разные схемы нумерации для разных видов документов

**Да** — полностью поддерживается.

Механизм настройки:
1. Создаётся **нумератор** с нужным ФорматНомером и Периодичностью
2. В `РС.НастройкиНумерации` создаётся запись: ВидДокумента → Нумератор (+ опциональный контекст: Организация, Подразделение, ВопросДеятельности, Контрагент, Проект, Тематика, ГрифДоступа, УзелКОД)
3. Чем больше контекстных полей заполнено в настройке — тем выше приоритет при выборе нумератора

**Пример сценариев:**
- Разные форматы номеров для разных видов документов (приказ, договор, служебная записка)
- Разные счётчики для разных организаций в рамках одного вида
- Разные нумераторы для разных подразделений
- Специальная нумерация для документов с определённым ВопросомДеятельности
- Нумерация для МЭДО-узла (поле УзелКОД)

Настройка нумераторов доступна через интерфейс справочника Нумераторы, где можно задать список условий (НастройкиНумерации) непосредственно в форме элемента.

## 7. Специальные механизмы

### Временные номера
- Управляются флагом `ВидыДокументов.ИспользоватьВременныеНомера`
- До регистрации документ может иметь временный номер (`ДокументыПредприятия.ВременныйНомер`)
- При регистрации временный номер освобождается, назначается постоянный

### Пропуски номеров
- `РС.ПропускиРегистрационныхНомеров` — хранит освобождённые номера (при удалении, отмене регистрации)
- Измерения: Нумератор, ВидДокумента, ПериодНумерации

### Смена периода нумерации
- Функция `Нумерация.ПроверитьСменуПериодаНумерации()` — проверяет, изменился ли период
- При смене периода номер освобождается и формируется новый

### Индексы нумерации
- `РС.ИндексыНумерации` — вспомогательный регистр для оптимизации нумерации

## 8. Итоговая схема взаимодействия объектов

```
Справочник ВидыДокументов
    ↓ (для каждого вида — настройки)
РС.НастройкиНумерации [ВидДокумента + контекст → Нумератор]
    ↓ (нумератор определяется по весовой системе)
Справочник Нумераторы [ФорматНомера, Периодичность, ТипСвязи]
    ↓ (текущий счётчик)
РС.Нумерация [Нумератор + ПериодНумерации + ВидДокумента → числовой номер]
    ↓ (подстановка в шаблон)
Справочник ДокументыПредприятия.РегистрационныйНомер (строковый)
                                 .ЧисловойНомер (числовой)
```
