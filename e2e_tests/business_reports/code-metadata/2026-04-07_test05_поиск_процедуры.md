## Сигнатура функции

```bsl
Функция ОпределитьФактическихИсполнителей(
    ДействияЗадач,                      // Массив - список ДействиеЗадачи для обработки
    ВыполнитьОтИмени,                   // СправочникСсылка.Сотрудники или Неопределено
    ВыбранныйФактическийИсполнитель,    // Структура или Неопределено - если уже выбран
    РеквизитыДействийЗадач = Неопределено   // Соответствие - кэш реквизитов
) Экспорт
```

## Как работает функция

Функция реализует многоступенчатый алгоритм определения того, кто фактически выполняет задачу.

### Шаг 1: Инициализация

```bsl
ИсполнителиРолей = Новый Соответствие;
ДействияБезФактИсполнителя = Новый Массив;
ДействияБезКомуАдресовано = Новый Массив;
ФактическиеИсполнителиПолные = Новый Соответствие;
ФактическиеИсполнителиПоДействиям = Новый Соответствие;
ОснованияФактИсполнителейПоДействиям = Новый Соответствие;

// Определяем, кто является основным сотрудником (текущий пользователь или ВыполнитьОтИмени)
ВсеСотрудникиТекущегоПользователя = СотрудникиПовтИсп.ВсеСотрудникиТекущегоПользователя();
Если ВыполнитьОтИмени = Неопределено
    Или ВсеСотрудникиТекущегоПользователя.Найти(ВыполнитьОтИмени) <> Неопределено Тогда
    ОсновнойСотрудник = Сотрудники.ОсновнойСотрудник();
    ВсеСотрудники = СотрудникиПовтИсп.ВсеСотрудникиТекущегоПользователя();
```

### Шаг 2: Перебор действий задач и проверка условий

Для каждого действия задачи функция последовательно проверяет:

**Ветка А: Прямое исполнение сотрудником** (исполнитель — `СправочникСсылка.Сотрудники`)  
Если текущий пользователь является исполнителем напрямую, фактический исполнитель = исполнитель.
```bsl
Если ВыполняетСотрудник Тогда
    ФактическиеИсполнителиПолные[ДействиеЗадачи] =
        Справочники.ФактическиеИсполнители.НайтиСоздатьФактическогоИсполнителя(
            РеквизитыДействия.Исполнитель);
```

**Ветка Б: Ролевое исполнение** (исполнитель — `СправочникСсылка.ПолныеРоли`)  
Если исполнитель является ролью, функция проверяет, входит ли текущий пользователь/сотрудник в эту роль:
```bsl
Если ТипЗнч(РеквизитыДействия.Исполнитель) = Тип("СправочникСсылка.ПолныеРоли") Тогда
    Если ВыполнениеОтИмени <> Неопределено Тогда
        ВыполняетИсполнительРоли =
            ВыполнениеОтИмени.Найти(РеквизитыДействия.Исполнитель) <> Неопределено;
    Иначе
        ВыполняетИсполнительРоли = ЭтоРольТекущегоПользователя(РеквизитыДействия.Исполнитель);
    КонецЕсли;
```

**Ветка В: Выбранный фактический исполнитель** (явно указан, например при диалоге выбора)  
```bsl
ФактИсполнитель = ВыбранныйФактическийИсполнитель.Сотрудник;
ФактИсполнительПолный = Справочники.ФактическиеИсполнители.НайтиСоздатьФактическогоИсполнителя(
    РеквизитыДействия.Исполнитель,
    Адресат,
    ФактИсполнитель,
    ОсновнойСотрудник);
```

### Шаг 3: Обработка замещений

Для действий, у которых фактический исполнитель ещё не определён (`ДействияБезФактИсполнителя`), функция запрашивает актуальные замещения:

```bsl
Если ДействияБезФактИсполнителя.Количество() > 0 Тогда
    // Получаем таблицу замещений через справочник ЗамещающиеИПомощники
    ТаблицаЗамещений = Справочники.ЗамещающиеИПомощники.АктуальныеЗамещенияПоДействиямЗадач(
        ДействияЗадач,
        ВсеСотрудники);

    Для Каждого СтрЗамещения Из ТаблицаЗамещений Цикл
        ЭтоПомощник = СтрЗамещения.ВидЗамещения = Перечисления.ВидыЗамещения.Помощники;
        // Замещающий всегда является фактическим исполнителем, а ОбрабатывающийРезолюцию никогда.
        Если ЭтоПомощник Тогда
            // Помощник: фактический исполнитель = помощник
            ФактИсполнитель = Справочники.ФактическиеИсполнители.НайтиСоздатьФактическогоИсполнителя(
                РеквизитыДействия.Исполнитель,
                СтрЗамещения.Сотрудник,   // адресат = помощник
                СтрЗамещения.Сотрудник,   // факт = помощник
                ОсновнойСотрудник);
        ИначеЕсли СтрЗамещения.ВидЗамещения = Перечисления.ВидыЗамещения.Замещающие Тогда
            // Замещающий: фактический исполнитель = основной сотрудник
            ФактИсполнитель = Справочники.ФактическиеИсполнители.НайтиСоздатьФактическогоИсполнителя(
                РеквизитыДействия.Исполнитель,
                СтрЗамещения.Сотрудник,
                ОсновнойСотрудник,
                ОсновнойСотрудник);
        КонецЕсли;
        ОснованияФактИсполнителейПоДействиям[ДействиеЗадачи] = СтрЗамещения.Замещение;
    КонецЦикла;
КонецЕсли;
```

### Шаг 4: Формирование возвращаемой структуры

```bsl
ДанныеФактическихИсполнителей = Новый Структура;
ДанныеФактическихИсполнителей.Вставить("ДействияБезФактИсполнителя",    ДействияБезФактИсполнителя);
ДанныеФактическихИсполнителей.Вставить("ДействияБезКомуАдресовано",     ДействияБезКомуАдресовано);
ДанныеФактическихИсполнителей.Вставить("ФактическиеИсполнителиПолные",  ФактическиеИсполнителиПолные);
ДанныеФактическихИсполнителей.Вставить("ФактическиеИсполнителиПоДействиям", ФактическиеИсполнителиПоДействиям);
ДанныеФактическихИсполнителей.Вставить("ОснованияФактИсполнителейПоДействиям", ОснованияФактИсполнителейПоДействиям);
Возврат ДанныеФактическихИсполнителей;
```

## Вспомогательные объекты

### Справочник `ФактическиеИсполнители`
**Путь:** `/app/code/Catalogs/ФактическиеИсполнители/Ext/ManagerModule.bsl`

Хранит комбинации «плановый адресат + кто фактически выполнил». Функция `НайтиСоздатьФактическогоИсполнителя` находит или создаёт запись с нужной комбинацией.

| Реквизит  | Тип                              | Описание                   |
|-----------|----------------------------------|----------------------------|
| Адресат   | СправочникСсылка.ПолныеРоли / Сотрудники | Плановый адресат    |
| Факт      | СправочникСсылка.Сотрудники      | Фактический исполнитель    |

### Справочник `ЗамещающиеИПомощники`
**Путь:** `/app/code/Catalogs/ЗамещающиеИПомощники/Ext/ManagerModule.bsl`

Содержит данные о действующих замещениях. Метод `АктуальныеЗамещенияПоДействиямЗадач` возвращает таблицу с колонками: `ДействиеЗадачи`, `ВидЗамещения`, `Сотрудник` (замещающий), `Замещение` (основание).

## Схема вызовов

```
Пользователь нажимает "Выполнить" / "Взять в работу"
    │
    ▼
РаботаСЗадачамиВызовСервера (сервер)
    │
    ├─► ОпределитьФактическихИсполнителей (РаботаСЗадачами)
    │       │
    │       ├─► [прямой сотрудник] → НайтиСоздатьФактическогоИсполнителя
    │       │
    │       ├─► [ролевой исполнитель] → ЭтоРольТекущегоПользователя
    │       │       └─► НайтиСоздатьФактическогоИсполнителя
    │       │
    │       └─► [замещение] → АктуальныеЗамещенияПоДействиямЗадач
    │               (Справочники.ЗамещающиеИПомощники)
    │               └─► НайтиСоздатьФактическогоИсполнителя
    │
    └─► ДанныеФактическихИсполнителей → запись в ДействиеЗадачи.ФактическийИсполнитель

Параллельно (при эскалации):
ЭскалацияЗадач → ОпределитьФактическихИсполнителей (тот же путь)
```

## Ключевые бизнес-правила

1. **Прямой сотрудник:** фактический исполнитель совпадает с плановым.
2. **Роль:** фактический исполнитель — тот сотрудник (из состава роли), кто взял задачу.
3. **Замещающий** (`ВидыЗамещения.Замещающие`): замещающий берёт задачу, фактический исполнитель — **основной сотрудник** (от чьего имени действует замещающий). Основание — ссылка на запись замещения.
4. **Помощник** (`ВидыЗамещения.Помощники`): помощник выполняет и он же является фактическим исполнителем.
5. **Явный выбор** (`ВыбранныйФактическийИсполнитель`): если исполнитель выбран вручную (диалог), это значение имеет приоритет над автоматическим определением.
6. Если фактический исполнитель не удалось определить — `ДействияБезФактИсполнителя` не пуст → система запрашивает интерактивный выбор (`ТребуетсяИнтерактивноеДействие = Истина`).

## Итог

Искомая процедура найдена — это **`РаботаСЗадачами.ОпределитьФактическихИсполнителей`** в общем модуле `РаботаСЗадачами`. Функция является центральным механизмом определения того, кто фактически выполняет задачу, с учётом: прямого назначения, ролевого назначения и всех видов замещений. Вызывается при взятии задачи в работу и её выполнении.
