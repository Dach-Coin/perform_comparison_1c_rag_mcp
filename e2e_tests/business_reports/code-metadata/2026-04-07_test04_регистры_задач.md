# Регистры, обновляемые при работе с задачами
**Конфигурация:** 1С:Документооборот КОРП 3.0  
**Дата анализа:** 2026-04-07  
**Сервер:** 1c-code-metadata  

---

## 1. Регистры накопления

### 1.1. РН.КоличествоЗадач

**Вид:** Остатки  
**Назначение:** Хранит текущие остатки задач в разрезе авторов, видов, статусов.

**Измерения:**

| Измерение     | Тип                                        |
|---------------|--------------------------------------------|
| Автор         | ОпределяемыйТип.УчастникЗадач              |
| ВидЗадачи     | СправочникСсылка.ВидыЗадач                 |
| Проект        | СправочникСсылка.Проекты                   |
| Флаг          | ПеречислениеСсылка.ФлагиОбъектов           |
| ТипПриложения | ПеречислениеСсылка.ТипыПриложенийЗадач     |
| ВидПриложения | ОпределяемыйТип.ВидПриложенияЗадач         |
| Контрагент    | СправочникСсылка.Контрагенты               |

**Реквизиты записи:**

| Реквизит          | Тип     | Назначение                                 |
|-------------------|---------|--------------------------------------------|
| МожетБытьПросрочена | Булево | Флаг возможности просрочки (индексируется) |
| Срок              | Дата    | Срок исполнения задачи                     |

**Ресурсы (счётчики по статусу задачи):**

| Ресурс                        | Описание                     |
|-------------------------------|------------------------------|
| ВРаботе                       | Задачи в статусе "В работе"  |
| Всего                         | Все задачи                   |
| Выполненных                   | Завершённые задачи           |
| Новых                         | Новые задачи                 |
| ОжидающихВыполнения           | Ожидают выполнения           |
| ОжидающихПроверки             | Ожидают проверки             |
| Просроченных                  | Просроченные                 |
| ПросроченныхОжидающихВыполнения | Просроченные ожидающие      |
| Черновиков                    | Черновики                    |

**Кто записывает:**  
Документ **Задача**, в процедуре `ОбработкаПроведения`:
```bsl
Движения.КоличествоЗадач.Записывать = Истина;
Движение = Движения.КоличествоЗадач.Добавить();
Движение.Регистратор = Ссылка;
Движения.КоличествоЗадач.ОбновитьДанныеЗадачи(РеквизитыЗадачи);
```
Метод `ОбновитьДанныеЗадачи` — процедура в ManagerModule РН.КоличествоЗадач, которая на основе реквизитов задачи (статус, срок, флаги) заполняет ресурсы записи.

---

### 1.2. РН.КоличествоДействийЗадач

**Вид:** Остатки  
**Назначение:** Хранит текущие остатки действий задач в разрезе исполнителей, видов действий, статусов.

**Измерения:**

| Измерение     | Тип                                        |
|---------------|--------------------------------------------|
| Исполнитель   | ОпределяемыйТип.УчастникЗадач              |
| Замещающий    | СправочникСсылка.Сотрудники                |
| Автор         | ОпределяемыйТип.УчастникЗадач              |
| ВидДействия   | СправочникСсылка.ВидыДействийЗадач         |
| ВидЗадачи     | СправочникСсылка.ВидыЗадач                 |
| Проект        | СправочникСсылка.Проекты                   |
| Флаг          | ПеречислениеСсылка.ФлагиОбъектов           |
| ТипПриложения | ПеречислениеСсылка.ТипыПриложенийЗадач     |
| ВидПриложения | ОпределяемыйТип.ВидПриложенияЗадач         |
| Контрагент    | СправочникСсылка.Контрагенты               |

**Реквизиты записи:**

| Реквизит                      | Тип       | Назначение                                   |
|-------------------------------|-----------|----------------------------------------------|
| МожетБытьПросрочена           | Булево    | Флаг возможности просрочки                   |
| ОписаниеПоступившихОбновлений | Строка150 | Текст последних обновлений по действию        |
| Срок                          | Дата      | Срок исполнения                              |

**Ресурсы:**

| Ресурс                        | Описание                                  |
|-------------------------------|-------------------------------------------|
| ВРаботе                       | Действия в работе                         |
| Всего                         | Все действия                              |
| ВСрок                         | Выполненных в срок                        |
| Выполненных                   | Завершённые действия                      |
| Истекающих                    | С истекающим сроком                       |
| Новых                         | Новые действия                            |
| ОжидающихВыполнения           | Ожидают выполнения                        |
| ОжидающихПроверки             | Ожидают проверки (ожидание ознакомления)  |
| ПоступилиОбновления           | Поступили обновления по действию          |
| Просроченных                  | Просроченные                              |
| ПросроченныхОжидающихВыполнения | Просроченные ожидающие                  |

**Кто записывает:**  
Документ **ДействиеЗадачи**, в процедуре `ОбработкаПроведения`:
```bsl
Процедура ОбработкаПроведения(Отказ, Режим)
    // Считываем кэшируемые реквизиты для обоих регистров
    КэшируемыеРеквизитыДействия = РегистрыНакопления.КоличествоДействийЗадач.КэшируемыеРеквизитыДействий();
    КэшируемыеРеквизитыЗадачи   = РегистрыНакопления.КоличествоДействийЗадач.КэшируемыеРеквизитыЗадач();
    РеквизитыДействия = Новый Структура(КэшируемыеРеквизитыДействия);
    ЗаполнитьЗначенияСвойств(РеквизитыДействия, ЭтотОбъект, КэшируемыеРеквизитыДействия);
    РеквизитыЗадачи = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(Задача, КэшируемыеРеквизитыЗадачи);

    // Количество действий задач
    Движения.КоличествоДействийЗадач.Записывать = Истина;
    РегистрыНакопления.КоличествоДействийЗадач.ЗаполнитьНаборПоДействию(
        Движения.КоличествоДействийЗадач, Ссылка, РеквизитыДействия, РеквизитыЗадачи);
    ...
КонецПроцедуры
```

Также обновляется при изменении задачи (смена статуса/срока/реквизитов) через:
- `РаботаСПроцессамиПоДействиям` → `ЗаполнитьНаборПоДействию`
- `РаботаСЗадачамиВызовСервера` → те же вызовы при внеплановом перепроведении

При **обновлении ИБ** используется:
```bsl
РегистрыНакопления.КоличествоДействийЗадач.ОбработатьОбновлениеДействияЗадачи(ДействиеЗадачи);
```

## 2. Регистры сведений

### 2.1. РС.ДействияЗадач

**Режим записи:** ПодчинениеРегистратору (регистратор — Документ.ДействиеЗадачи)  
**Периодичность:** Непериодический  
**Назначение:** Кэш текущих данных действия задачи (статус, трудозатраты, контрольный срок).

**Ключевые измерения/ресурсы:**
- Измерение **Исполнитель** (УчастникЗадач)
- Измерение **ДействиеЗадачи** (ДокументСсылка.ДействиеЗадачи) — индексируется
- Ресурс **Автор** (УчастникЗадач)
- Ресурсы: Трудозатраты, ЕстьПодзадачи, СостояниеКонтроля, КонтрольныйСрок, КонтрольныйСрокОбщий, ОжидаетПроверки

**Кто записывает:**  
Документ **ДействиеЗадачи** в `ОбработкаПроведения`:
```bsl
Движения.ДействияЗадач.Записывать = Истина;
Движение = Движения.ДействияЗадач.Добавить();
Движение.Регистратор = Ссылка;
Движение.ЕстьПодзадачи = РаботаСЗадачами.ЕстьПодзадачи(Ссылка);
Движение.Трудозатраты = Трудозатраты();
Движение.СостояниеКонтроля = ПараметрыКонтроляДляКэша.СостояниеКонтроля;
Движение.КонтрольныйСрок = ПараметрыКонтроляДляКэша.СрокИсполнения;
Движение.КонтрольныйСрокОбщий = ПараметрыКонтроляДляКэша.СрокИсполненияОбщий;
Движения.ДействияЗадач.ОбновитьДанныеДействия(РеквизитыДействия);
Движения.ДействияЗадач.ОбновитьДанныеЗадачи(РеквизитыДействия, РеквизитыЗадачи);
```

При изменении Трудозатрат (без перепроведения) — напрямую через ManagerModule:
```bsl
НаборЗаписей = СоздатьНаборЗаписей();
НаборЗаписей.Отбор.Регистратор.Установить(ДействиеЗадачи);
НаборЗаписей.Прочитать();
Для Каждого Запись Из НаборЗаписей Цикл
    Запись.Трудозатраты = Трудозатраты;
КонецЦикла;
НаборЗаписей.Записать();
```

### 2.2. РС.ВсеИсполнителиДействийЗадач

**Режим записи:** Независимый  
**Периодичность:** Непериодический  
**Назначение:** Хранит расширенный список исполнителей действий с учётом замещений.

**Измерения:**
- **ДействиеЗадачи** (ДокументСсылка.ДействиеЗадачи) — ведущее, основной отбор
- **Исполнитель** (УчастникЗадач) — ведущее, основной отбор
- **Основание** (СправочникСсылка.ЗамещающиеИПомощники) — ведущее

**Кто записывает:**
1. При проведении Документа.ДействиеЗадачи — основные исполнители
2. При активации/деактивации замещения (`Справочники.ЗамещающиеИПомощники.ManagerModule`):
```bsl
// При активации замещения
НаборВсеИсполнители = РегистрыСведений.ВсеИсполнителиДействийЗадач.СоздатьНаборЗаписей();
НаборВсеИсполнители.Отбор.ДействиеЗадачи.Установить(ДействиеЗадачи);
НаборВсеИсполнители.Отбор.Исполнитель.Установить(РеквизитыЗамещения.Замещающий);
НаборВсеИсполнители.Отбор.Основание.Установить(Замещение);
Стр = НаборВсеИсполнители.Добавить();
Стр.Основание = Замещение;
Стр.ДействиеЗадачи = ДействиеЗадачи;
Стр.Исполнитель = РеквизитыЗамещения.Замещающий;
НаборВсеИсполнители.Записать();

// При деактивации замещения — очищается
НаборВсеИсполнители.Отбор.Основание.Установить(Замещение);
НаборВсеИсполнители.Записать(); // пустой набор = удаление
```

### 2.3. РС.ЗадачиПоАвторам

**Режим записи:** ПодчинениеРегистратору (регистратор — Документ.Задача или Документ.ДействиеЗадачи)  
**Периодичность:** Непериодический  
**Назначение:** Хранит задачи в привязке к авторам (для списков "Мои задачи").

**Измерение:** Автор (УчастникЗадач)

**Кто записывает:**  
Документ **Задача** в `ОбработкаПроведения`:
```bsl
Движения.ЗадачиПоАвторам.Записывать = Истина;
Движение = Движения.ЗадачиПоАвторам.Добавить();
Движение.Регистратор = Ссылка;
Движение.Трудозатраты = Трудозатраты();
Движение.ЕстьПодзадачи = РаботаСЗадачами.ЕстьПодзадачи(Ссылка);
Движение.СостояниеКонтроля = ПараметрыКонтроляДляКэша.СостояниеКонтроля;
Движение.КонтрольныйСрок = ПараметрыКонтроляДляКэша.СрокИсполнения;
Движения.ЗадачиПоАвторам.ОбновитьДанныеЗадачи(РеквизитыЗадачи);
```

### 2.4. РС.СведенияОбИсполнителяхЗадач

**Режим записи:** Независимый  
**Периодичность:** Непериодический  
**Назначение:** Сведения об исполнителях задач-исполнителей (ЗадачаИсполнителя → участники).

**Измерение:** Задача (ЗадачаСсылка.ЗадачаИсполнителя) — ведущее

---

### 2.5. РС.ИсторияЗадач

**Режим записи:** Независимый  
**Периодичность:** Непериодический  
**Назначение:** История событий по задачам (смена состояний, комментарии).

**Ключевое измерение:** ДействиеЗадачи (ДокументСсылка.ДействиеЗадачи) — ведущее  
**Ресурсы:** Автор (Сотрудники/Пользователи) и другие реквизиты события.

---

### 2.6. РС.ПоступившиеОбновленияЗадач

**Режим записи:** Независимый  
**Периодичность:** Непериодический  
**Назначение:** Уведомления о поступивших обновлениях по задачам для исполнителей.

**Ключевое измерение:** ДействиеЗадачи (ДокументСсылка.ДействиеЗадачи)

**Кто записывает:**  
Общий модуль `РаботаСЗадачами`:
```bsl
РегистрыСведений.ПоступившиеОбновленияЗадач.ДобавитьЗапись(
    НовоеПоступившееОбновлениеЗадачи.Задача,
    НовоеПоступившееОбновлениеЗадачи.СобытиеОбновления,
    ЛокальнаяЗапись);
```

---

### 2.7. РС.НаименованияЗадачУчастниковДействий

**Режим записи:** Независимый  
**Периодичность:** Непериодический  
**Назначение:** Кэш наименований задач для конкретных участников/видов действий.

**Измерение:** ВидДействия (СправочникСсылка.ВидыДействий) — ведущее, основной отбор

## 3. Схема движений при событиях жизненного цикла задачи

### 3.1. Создание документа Задача (первое проведение)

```
Документ.Задача.ОбработкаПроведения()
    ├── РН.КоличествоЗадач                    → Добавить запись, ОбновитьДанныеЗадачи()
    │   └── Ресурсы: Новых += 1, Всего += 1
    └── РС.ЗадачиПоАвторам                    → Добавить запись
        └── Привязка: Автор → Задача
```

### 3.2. Проведение документа ДействиеЗадачи (назначение / изменение)

```
Документ.ДействиеЗадачи.ОбработкаПроведения()
    ├── РН.КоличествоДействийЗадач            → ЗаполнитьНаборПоДействию()
    │   └── Ресурсы по статусу (ВРаботе / ОжидающихВыполнения / etc.)
    ├── РС.ДействияЗадач                      → ОбновитьДанныеДействия() + ОбновитьДанныеЗадачи()
    │   └── Трудозатраты, ЕстьПодзадачи, СостояниеКонтроля, КонтрольныйСрок
    └── РС.ВсеИсполнителиДействийЗадач        → (при добавлении исполнителей)
```

### 3.3. Смена статуса задачи

При записи/перепроведении документа **Задача** с новым статусом:

| Переход статуса            | Изменения в РН.КоличествоЗадач                            |
|----------------------------|-----------------------------------------------------------|
| Черновик → Новая           | Черновиков -= 1, Новых += 1                               |
| Новая → В работе           | Новых -= 1, ВРаботе += 1                                  |
| В работе → Ожидает проверки | ВРаботе -= 1, ОжидающихПроверки += 1                     |
| Любой → Выполнена          | Соответствующий счётчик -= 1, Выполненных += 1            |
| Наступление просрочки      | Просроченных += 1, ПросроченныхОжидающихВыполнения += 1  |

При записи/перепроведении документа **ДействиеЗадачи** с новым статусом:

| Переход статуса            | Изменения в РН.КоличествоДействийЗадач                    |
|----------------------------|-----------------------------------------------------------|
| Новое → В работе           | Новых -= 1, ВРаботе += 1                                  |
| В работе → Выполнено в срок | ВРаботе -= 1, Выполненных += 1, ВСрок += 1               |
| В работе → Выполнено просроч. | ВРаботе -= 1, Выполненных += 1, Просроченных += 1       |
| Любой → Ожидает проверки   | ОжидающихПроверки += 1                                    |
| Поступило обновление       | ПоступилиОбновления += 1                                  |

### 3.4. Завершение задачи (перевод в закрытое состояние)

```
Перепроведение Документ.Задача (статус = Выполнена/Закрыта)
    └── РН.КоличествоЗадач
        └── Выполненных += 1, прочие статусы -= 1

Перепроведение Документ.ДействиеЗадачи (все действия завершены)
    └── РН.КоличествоДействийЗадач
        └── Выполненных += 1, ВРаботе -= 1
```

### 3.5. Назначение замещающего исполнителя

```
Справочники.ЗамещающиеИПомощники.ManagerModule → активация замещения
    └── РС.ВсеИсполнителиДействийЗадач
        └── Добавить запись: {ДействиеЗадачи, Замещающий, Основание=СправочникЗамещения}
```

## 4. Ключевые процедуры и их расположение

| Процедура / Метод                          | Объект                                              | Что делает                                                     |
|--------------------------------------------|-----------------------------------------------------|----------------------------------------------------------------|
| `ОбработкаПроведения`                      | Документ.Задача / ObjectModule.bsl                  | Создаёт движения в РН.КоличествоЗадач и РС.ЗадачиПоАвторам    |
| `ОбработкаПроведения`                      | Документ.ДействиеЗадачи / ObjectModule.bsl          | Создаёт движения в РН.КоличествоДействийЗадач и РС.ДействияЗадач |
| `ЗаполнитьНаборПоДействию`                 | РН.КоличествоДействийЗадач / ManagerModule.bsl      | Заполняет набор движений по реквизитам действия и задачи       |
| `ОбновитьДанныеЗадачи`                     | РН.КоличествоЗадач / ManagerModule.bsl              | Обновляет ресурсы записи по текущим реквизитам задачи          |
| `ОбновитьДанныеДействия`                   | РС.ДействияЗадач / ManagerModule.bsl                | Обновляет реквизиты действия (статус, исполнители)             |
| `ОбновитьДанныеЗадачи`                     | РС.ДействияЗадач / ManagerModule.bsl                | Обновляет реквизиты задачи в записи регистра                   |
| `ОбработатьОбновлениеДействияЗадачи`       | РН.КоличествоДействийЗадач / ManagerModule.bsl      | Обновляет движения без перепроведения (обновление ИБ)          |
| `ОбработатьОбновлениеДействияЗадачи`       | РС.ДействияЗадач / ManagerModule.bsl                | Синхронно с РН (обновление ИБ)                                 |
| `ДобавитьЗапись`                           | РС.ПоступившиеОбновленияЗадач / ManagerModule.bsl   | Добавляет уведомление об обновлении задачи                     |
| `КэшируемыеРеквизитыДействий/Задач`        | РН.КоличествоДействийЗадач / ManagerModule.bsl      | Возвращает список отслеживаемых реквизитов для кэширования     |
| `ПересчитатьТекущиеИтоги`                  | РН.КоличествоЗадач, РН.КоличествоДействийЗадач      | Пересчёт итогов регистра (плановый / при обслуживании)         |

## 5. Итоговая карта регистров

```
Документ.Задача
├──► РН.КоличествоЗадач         (накопление, остатки, регистратор=Задача)
```
