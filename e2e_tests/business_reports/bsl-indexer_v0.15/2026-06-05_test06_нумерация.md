# Бизнес-отчёт: Нумерация и регистрация документов в 1С:Документооборот КОРП 3.0

**Дата:** 2026-06-05
**Тест:** TEST-06
**Инструмент:** bsl-indexer v0.15
**Конфигурация:** Тест ДО3 (1С:Документооборот КОРП 3.0)

---

## 1. Автоматическая нумерация при создании документа

При создании нового документа предприятия (`ОбработкаЗаполнения` в `Catalogs/ДокументыПредприятия/Ext/ObjectModule.bsl`, строки 67–485) реквизиты нумерации инициализируются в пустые значения:
- `РегистрационныйНомер = ""`
- `ЧисловойНомер = 0`
- `ДатаРегистрации = '00010101'`

Таким образом, **автоматический номер при создании не назначается**. Номер формируется только в момент регистрации документа.

Исключение — «временные номера»: если в справочнике ВидыДокументов включён флаг `ИспользоватьВременныеНомера`, то при каждом сохранении незарегистрированного документа вызывается `Нумерация.УстановитьВременныйНомерПередЗаписью`, которая проставляет временный порядковый номер (отдельный счётчик, видимый в карточке как «Врем. № ...»). Этот номер не является регистрационным.

## 2. Регистрация документа — бизнес-процесс и механика

**Регистрация** — это отдельный **бизнес-процесс** (`BusinessProcesses/Регистрация`), в котором есть точка маршрута `Зарегистрировать` с ролью исполнителя (делопроизводитель или назначенный регистратор).

### Два способа зарегистрировать документ

**A. Прямая регистрация из карточки документа** (`Catalogs/ДокументыПредприятия/Forms/ФормаЭлемента`):
- Пользователь нажимает кнопку «Зарегистрировать» — вызывается клиентская функция `ЗарегистрироватьДокумент()`.
- Функция записывает документ с параметром `"Регистрация" = Истина`.
- В обработчике `ПередЗаписью` объектного модуля (строки 746–1285) вызывается `Нумерация.СформироватьЧисловойНомерДокумента` и затем `Нумерация.СформироватьСтроковыйНомерДокумента` — заполняются `ЧисловойНомер` и `РегистрационныйНомер`.
- В `ПриЗаписи` фиксируются бизнес-события (перерегистрация, смена номера), освобождается старый номер через `Нумерация.ОсвободитьНомер`.

**B. Через задачу бизнес-процесса «Регистрация»** (`CommonModules/ИнтеграцияЗадач`, процедура `ПередИнтерактивнымВыполнениемДействияРегистрацияЗарегистрировать`):
- Если результат задачи = «Зарегистрировано», вызывается `Делопроизводство.ЗарегистрироватьПредмет(Предмет, СообщениеОбОшибке, РегистрационныйНомер, ПараметрыРегистрации)`.
- Поддерживаются: **ручная нумерация** (оператор вводит номер вручную), **пропущенные номера** (из регистра `ПропускиРегистрационныхНомеров`).
- Если нумератор не задан — система требует ввода номера вручную.
- Результаты: «Зарегистрировано» / «Не зарегистрировано» (с указанием причины отказа).

**C. Через веб-сервис DMReg** (`WebServices/DMReg/Ext/Module.bsl`): метод `RegisterDocument` → внутренняя функция `ЗарегистрироватьДокумент(DocumentInfo)` → `Делопроизводство.ЗарегистрироватьПредмет`.

## 3. Где хранятся настройки нумерации

Настройки нумерации хранятся в **двух местах**:

### 3.1. Регистр сведений НастройкиНумерации
Главное хранилище — **регистр сведений `НастройкиНумерации`** (независимый). Поля:
| Поле | Тип | Описание |
|---|---|---|
| ВидДокумента | CatalogRef.ВидыДокументов | Вид документа, для которого действует настройка |
| Организация | CatalogRef.Организации | Фильтр по организации |
| Подразделение | CatalogRef.СтруктураПредприятия | Фильтр по подразделению |
| Контрагент | CatalogRef.Контрагенты | Фильтр по контрагенту |
| Проект | CatalogRef.Проекты | Фильтр по проекту |
| ВопросДеятельности | CatalogRef.ВопросыДеятельности | Фильтр по вопросу деятельности |
| Тематика | CatalogRef.ТематикиДокументов | Фильтр по тематике |
| ГрифДоступа | CatalogRef.ГрифыДоступа | Фильтр по грифу доступа |
| СпособНумерации | Перечисление.СпособыНумерации | «Автоматически» / «Вручную» |
| Нумератор | CatalogRef.Нумераторы | Ссылка на нумератор |
| Нумеровать | Строка | Описание схемы нумерации (заполняется автоматически) |
| Назначение | Перечисление.НазначенияНумераторов | «РегистрационныйНомер» или «ВременныйНомер» |

Запись и чтение выполняются через функции `Нумерация.ПрочитатьНастройкиНумерацииВидаДокумента` / `Нумерация.ЗаписатьНастройкиНумерацииВидаДокумента` из общего модуля `Нумерация`.

Карточка вида документа (`Catalogs/ВидыДокументов/Forms/ФормаЭлемента`) содержит таблицу **НастройкиНумерации**, в которой администратор задаёт правила: один вид документа может иметь **несколько строк** с разными нумераторами для разных организаций/подразделений/контрагентов — таким образом реализуются разные схемы нумерации для разных условий.

### 3.2. Регистр сведений Нумерация (счётчики)
**Регистр сведений `Нумерация`** (независимый) хранит текущие значения счётчиков. Структура:
- **Ресурс:** `ТекущийНомер` (Число 10,0) — текущее значение счётчика
- **Измерения (ключ уникальности счётчика):**
  - `Нумератор` (CatalogRef.Нумераторы, Master=true)
  - `ПериодНумерации` (Дата) — начало периода (год, квартал, месяц или Дата(1,1,1) для непериодических)
  - `ГрифДоступа` (CatalogRef.ГрифыДоступа, Master=true)
  - `Организация` (CatalogRef.Организации, Master=true)
  - `СвязанныйДокумент` (CatalogRef.ДокументыПредприятия, Master=true)
  - `Подразделение` (CatalogRef.СтруктураПредприятия, Master=true)
  - `Проект` (CatalogRef.Проекты, Master=true)
  - *(а также ВидДокумента, ВопросДеятельности, Тематика, УзелКОД — берутся из реквизитов нумератора)*

## 4. Как формируется регистрационный номер — префиксы, суффиксы, счётчики

Формирование номера реализовано в общем модуле `CommonModules/Нумерация/Ext/Module.bsl` (1 653 строки) и разделено на два шага:

### Шаг 1 — Числовой номер (`СформироватьЧисловойНомерДокумента`)
1. Определяется нумератор документа через `ПолучитьНумераторДокумента`.
2. Читаются реквизиты нумератора: `Периодичность`, `ТипСвязи`, флаги независимости.
3. Формируется набор измерений счётчика (Нумератор + ПериодНумерации + опциональные: Организация, СвязанныйДокумент, Подразделение, ВидДокумента, Проект, ВопросДеятельности, Тематика, ГрифДоступа, УзелКОД).
4. С исключительной блокировкой данных (`БлокировкаДанных`) читается `ТекущийНомер` из `РегистрСведений.Нумерация`, увеличивается на 1 и записывается обратно. Результат — `ЧисловойНомер` документа.

### Шаг 2 — Строковый номер (`СформироватьСтроковыйНомерДокумента`)
1. Читается `ФорматНомера` нумератора — строка-шаблон, например: `[ИндексОрганизации]-[Номер]/[Год2]`
2. Шаблон разбирается функцией `РазобратьФорматНомера`.
3. **Служебные поля шаблона** (в квадратных скобках):

| Поле шаблона | Содержание |
|---|---|
| `[Номер]` | Числовой порядковый номер (ЧисловойНомер) |
| `[День]` | День даты регистрации |
| `[Месяц]` | Месяц даты регистрации |
| `[Квартал]` | Квартал даты регистрации |
| `[Год4]` | Год (4 цифры) |
| `[Год2]` | Год (2 цифры) |
| `[ИндексВидаДокумента]` | Индекс вида документа |
| `[ИндексОтветственного]` | Индекс ответственного (из РегистрСведений.ИндексыНумерации) |
| `[ИндексВопросаДеятельности]` | Индекс вопроса деятельности |
| `[ИндексПодразделения]` | Индекс подразделения |
| `[ИндексОрганизации]` | Индекс организации |
| `[ИндексНоменклатурыДел]` | Индекс номенклатуры дел |
| `[ИндексКонтрагента]` | Индекс контрагента |
| `[ИндексПроекта]` | Индекс проекта |

4. Итоговый `РегистрационныйНомер` = конкатенация разделителей и подставленных значений полей.

**Расширение Теста:** нумератор содержит дополнительный реквизит `тст_ДлинаЧисловогоНомера` — позволяет задавать фиксированную длину числовой части (с ведущими нулями).

## 5. Разные схемы нумерации для разных видов документов

**Да, полностью поддерживается.** Механизм многоуровневый:

### Уровень 1 — Справочник «Нумераторы» (`Catalogs/Нумераторы`)
Каждый нумератор — независимый объект со своим:
- `ФорматНомера` — шаблон строкового номера
- `Периодичность` — периодичность сброса счётчика (год, квартал, месяц, день, или никогда)
- `Назначение` — РегистрационныйНомер или ВременныйНомер
- `ИспользоватьПропущенныеНомера` — включить повторное использование пропущенных номеров (из `РегистрСведений.ПропускиРегистрационныхНомеров`)
- флаги `НезависимаяНумерацияПо*` — по каким измерениям вести независимые счётчики

Предопределённые нумераторы: `ДокументыПредприятия` («Документы») и `Штрихкоды` («Штрихкоды»).

### Уровень 2 — Настройки нумерации вида документа
В карточке каждого вида документа (таблица НастройкиНумерации) можно:
- Назначить разные нумераторы для разных организаций/подразделений/контрагентов/проектов/вопросов деятельности/тематик
- Задать способ нумерации: «Автоматически» (счётчик) или «Вручную» (оператор вводит номер)
- Задать нумератор для ВременногоНомера (отдельная строка с Назначением = ВременныйНомер)

### Уровень 3 — Независимые счётчики внутри нумератора
Флаги `НезависимаяНумерацияПо*` в нумераторе позволяют вести **отдельный счётчик** (отдельную запись в регистре Нумерация) для каждой комбинации: Организация + Подразделение + Проект + СвязанныйДокумент + ГрифДоступа + ВопросДеятельности + Тематика + УзелКОД + ВидДокумента.

### Итог
Система позволяет настроить: входящие документы одного вида нумеруются по одному нумератору с форматом `Вх-[Номер]/[Год4]`, внутренние приказы — по другому нумератору с форматом `[ИндексОрганизации]-[Номер]-[Год2]`, исходящие — с независимой нумерацией по организациям. Всё конфигурируется через карточку вида документа без изменения кода.

## Архитектурная схема (резюме)

```
Справочник ВидыДокументов
  └── НастройкиНумерации (РегистрСведений.НастройкиНумерации)
        ├── СпособНумерации (Авто / Вручную)
        ├── Нумератор → Справочник.Нумераторы
        │     ├── ФорматНомера (шаблон с [полями])
        │     ├── Периодичность
        │     ├── НезависимаяНумерацияПо* (флаги)
        │     └── ИспользоватьПропущенныеНомера
        └── Фильтры: Организация, Подразделение, Проект...

При регистрации:
  Нумерация.СформироватьЧисловойНомерДокумента()
    → РегистрСведений.Нумерация (счётчик ТекущийНомер +1, с блокировкой)
  Нумерация.СформироватьСтроковыйНомерДокумента()
    → РегистрационныйНомер = подстановка полей по шаблону ФорматНомера

Бизнес-процесс «Регистрация»:
  Точка маршрута «Зарегистрировать»
    → Делопроизводство.ЗарегистрироватьПредмет()
      → Запись документа с параметром Регистрация=Истина
        → СформироватьЧисловойНомер + СформироватьСтроковыйНомер
```
