# Регистры, обновляемые при работе с задачами в 1С:ДО КОРП 3.0

**Дата:** 2026-06-05  
**Конфигурация:** 1С:Документооборот КОРП 3.0 (ДО3)  
**Источник данных:** MCP-сервер bsl-indexer v0.15, репозиторий «Тест ДО3»

---

## 1. Регистры накопления

### 1.1. КоличествоЗадач (RegisterType: Balance — остаточный)

**Измерения:**
| Измерение | Тип |
|-----------|-----|
| Автор | DefinedType.УчастникЗадач |
| ВидЗадачи | CatalogRef.ВидыЗадач |
| Проект | CatalogRef.Проекты |
| Флаг | EnumRef.ФлагиОбъектов |
| ТипПриложения | EnumRef.ТипыПриложенийЗадач |
| ВидПриложения | DefinedType.ВидПриложенияЗадач |
| Контрагент | CatalogRef.Контрагенты |

**Ресурсы** (числовые счётчики состояния задачи автора):
`ВРаботе`, `Всего`, `Выполненных`, `Новых`, `ОжидающихВыполнения`, `ОжидающихПроверки`, `Просроченных`, `ПросроченныхОжидающихВыполнения`, `Черновиков`

**Дополнительные атрибуты:** `МожетБытьПросрочена` (Boolean), `Срок` (DateTime)

**Назначение:** Хранит сводные счётчики задач в разрезе автора, вида задачи, проекта, приложения и контрагента. Используется для формирования итогов списка «Задачи от меня».

**Измерения:**
| Измерение | Тип |
|-----------|-----|
| Исполнитель | DefinedType.УчастникЗадач |
| Замещающий | CatalogRef.Сотрудники |

| Проект | CatalogRef.Проекты |
| Флаг | EnumRef.ФлагиОбъектов |
| ТипПриложения | EnumRef.ТипыПриложенийЗадач |
| ВидПриложения | DefinedType.ВидПриложенияЗадач |
| ВидЗадачи | CatalogRef.ВидыЗадач |
| Контрагент | CatalogRef.Контрагенты |

**Ресурсы** (числовые счётчики состояния действия/исполнителя):
`ВРаботе`, `Всего`, `ВСрок`, `Выполненных`, `Истекающих`, `Новых`, `ОжидающихВыполнения`, `ОжидающихПроверки`, `ПоступилиОбновления`, `Просроченных`, `ПросроченныхОжидающихВыполнения`

**Дополнительные атрибуты:** `МожетБытьПросрочена` (Boolean), `Срок` (DateTime), `ОписаниеПоступившихОбновлений` (String 150)

**Назначение:** Хранит счётчики действий задач в разрезе исполнителя (с учётом замещения), автора, вида действия. Используется для формирования итогов списка «Задачи мне» и «Задачи отдела».

## 2. Регистры сведений

### 2.1. ДействияЗадач (WriteMode: RecorderSubordinate)

**Тип:** Подчинён регистратору-документу `ДействиеЗадачи`

**Ключевые ресурсы (неполный список):**
`Автор`, `ВидДействия`, `ВидЗадачи`, `ВидПриложения`, `ВидСостоянияУчастниковЗадач`, `ВРаботе`, `ВСрок`, `Выполнено`, `ДатаВыполнения`, `ДатаНачала`, `ДатаНачалаУчета`

**Назначение:** Детальная запись по каждому действию задачи (строке участника). Содержит текущее состояние исполнителя, флаги выполнения, сроки. Используется для формирования детальных списков «Задачи мне» с группировкой.

---

### 2.2. ВсеИсполнителиДействийЗадач (WriteMode: Independent)

**Измерения:**
| Измерение | Тип |
|-----------|-----|
| ДействиеЗадачи | DocumentRef.ДействиеЗадачи |
| Исполнитель | DefinedType.УчастникЗадач |
| Основание | CatalogRef.ЗамещающиеИПомощники |

**Назначение:** Плоский регистр-связка: хранит всех исполнителей (включая замещающих) по каждому документу `ДействиеЗадачи`. Используется при формировании набора записей `КоличествоДействийЗадач` — для каждого замещающего создаётся дополнительная строка.

---

### 2.3. ЗадачиПоАвторам (WriteMode: RecorderSubordinate)

**Тип:** Подчинён регистратору-документу `Задача`

**Ключевые ресурсы:**
`ВидЗадачи`, `ВидПриложения`, `ВидСостоянияЗадачи`, `ВРаботе`, `Выполнена`, `ДатаВыполнения`, `ДатаНачалаУчета`, `СостояниеКонтроля`, `КонтрольныйСрок`, `ЕстьПодзадачи`, `Трудозатраты`

**Назначение:** Денормализованная запись по каждой задаче для автора. Хранит текущее состояние задачи с детализацией контроля сроков. Используется для виджетов и сводок рабочего стола автора.

---

### 2.4. ЗадачиПоАвторам.ОбновитьПодзадачи — дополнительное обновление

При изменении `ВышестоящаяЗадача`, `СостояниеЗадачи`, `ПометкаУдаления` регистр `ЗадачиПоАвторам` пересчитывается для вышестоящей задачи через вызов `РегистрыСведений.ЗадачиПоАвторам.ОбновитьПодзадачи(ВышестоящаяЗадача)`.

---

## 3. Ключевые процедуры, пишущие в регистры

### 3.1. Documents/Задача/Ext/ObjectModule.bsl — ОбработкаПроведения (строки 2698–2727)

Вызывается при **проведении** документа Задача. Записывает напрямую в два регистра:

```bsl
// Количество задач
Движения.КоличествоЗадач.Записывать = Истина;
Движение = Движения.КоличествоЗадач.Добавить();
Движения.КоличествоЗадач.ОбновитьДанныеЗадачи(РеквизитыЗадачи);

// Задачи по авторам
Движения.ЗадачиПоАвторам.Записывать = Истина;
Движения.ЗадачиПоАвторам.ОбновитьДанныеЗадачи(РеквизитыЗадачи);
```

Реквизиты задачи получаются через `КэшируемыеРеквизитыЗадач()` — единый список полей для кэширования.

---

### 3.2. Documents/Задача/Ext/ObjectModule.bsl — ПриЗаписи (строки 2093–2696)

Вызывается при **любой записи** документа Задача. Содержит логику:

1. **Обновление ДействияЗадач и КоличествоДействийЗадач** — если изменились кэшируемые реквизиты задачи (Участники, Проект, Срок, ВидЗадачи и др.), для каждого активного действия вызывается:
   ```bsl
   РегистрыСведений.ДействияЗадач.ОбновитьДанныеЗадачи(АктивноеДействие, ДанныеДействия, РеквизитыЗадачи);
   РегистрыНакопления.КоличествоДействийЗадач.ОбновитьДанныеЗадачи(АктивноеДействие, ДанныеДействия, РеквизитыЗадачи);
   ```

2. **Обновление ЗадачиПоАвторам.ОбновитьПодзадачи** — при изменении ВышестоящаяЗадача/СостояниеЗадачи/ПометкаУдаления.

3. **Реакция на смену состояния** — через блок `ОбновитьДействияПоСостоянию` (см. раздел 4).

---

### 3.3. Documents/ДействиеЗадачи/Ext/ObjectModule.bsl — ОбработкаПроведения (строки 470–505)

Вызывается при **проведении** документа `ДействиеЗадачи`. Пишет в два регистра одновременно:

```bsl
// Количество действий задач
Движения.КоличествоДействийЗадач.Записывать = Истина;
РегистрыНакопления.КоличествоДействийЗадач.ЗаполнитьНаборПоДействию(
    Движения.КоличествоДействийЗадач, Ссылка, РеквизитыДействия, РеквизитыЗадачи);

// Действия задач
Движения.ДействияЗадач.Записывать = Истина;
Движения.ДействияЗадач.ОбновитьДанныеДействия(РеквизитыДействия);
Движения.ДействияЗадач.ОбновитьДанныеЗадачи(РеквизитыДействия, РеквизитыЗадачи);
```

---

### 3.4. AccumulationRegisters/КоличествоДействийЗадач/Ext/ManagerModule.bsl — ЗаполнитьНаборПоДействию (строки 1089–1128)

Ключевая процедура заполнения набора записей `КоличествоДействийЗадач`. Создаёт **одну запись без замещения** + **по одной записи для каждого замещающего** из `ВсеИсполнителиДействийЗадач`:

```bsl
ВсеЗамещенияПоДействию = РегистрыСведений.ВсеИсполнителиДействийЗадач.ЗамещенияПоДействию(ДействиеЗадачи);
Для Каждого СтрокаЗамещения Из ВсеЗамещенияПоДействию Цикл
    ЗаписьПоЗамещению = НаборЗаписей.Добавить();
    ЗаписьПоЗамещению.Замещающий = СтрокаЗамещения.Замещающий;
КонецЦикла;
```

---

### 3.5. AccumulationRegisters/КоличествоЗадач/Ext/RecordSetModule.bsl — ОбновитьДанныеЗадачи

Метод набора записей, вычисляющий значения ресурсов по виду состояния задачи:

```bsl
ВРаботе   = Перечисления.ВидыСостоянийЗадач.ЭтоЗадачаВРаботе(ВидСостоянияЗадачи);
Выполнена = Перечисления.ВидыСостоянийЗадач.ЭтоВыполненнаяЗадача(ВидСостоянияЗадачи);
...
Запись.Всего = 1;
Запись.ВРаботе = ?(ВРаботе, 1, 0);
Запись.Выполненных = ?(Выполнена, 1, 0);
Запись.Просроченных = ?(Просрочена, 1, 0);
...
```

---

### 3.6. AccumulationRegisters/КоличествоЗадач/Ext/ManagerModule.bsl — ОбработатьОбновлениеЗадачи (строки 569–609)

Транзакционное обновление набора записей `КоличествоЗадач` по задаче — вызывается из очереди кэшируемых обновлений (не при прямом проведении):

```bsl
НаборЗаписей.Прочитать();
НаборЗаписей.ОбновитьДанныеЗадачи(РеквизитыЗадачи);
НаборЗаписей.Записать();
```

---

### 3.7. CommonModules/РаботаСЗадачамиВызовСервера — ОбновитьДвиженияДействияЗадачи (строки 1586–1633)

Внешний вызов (не из ОбработкаПроведения), который полностью перезаписывает движения `ДействиеЗадачи` — вызывается при изменении состава участников или замещений без перепроведения документа.

## 4. Изменения регистров при смене статуса задачи

Смена статуса задачи обрабатывается в `ПриЗаписи` через флаг `ОбновитьДействияПоСостоянию`. Логика по переходам:

| Переход статуса | Что происходит с регистрами |
|---|---|
| Черновик → Новая | Все действия отправляются на исполнение (`НаправитьНаИсполнение`). В `КоличествоЗадач`: `Черновиков` -1, `Новых` +1. В `КоличествоДействийЗадач`: `Новых` +1 для каждого исполнителя |
| Новая → ВРаботе | `ОтметитьВРаботе()` — действия переводятся в статус «В работе». В `КоличествоЗадач`: `Новых` -1, `ВРаботе` +1; в `КоличествоДействийЗадач` аналогично |
| ВРаботе → НаПроверке | `ОтметитьОжидаетПроверки()` + `ОтметитьНаПроверке()`. В `КоличествоЗадач`: `ОжидающихПроверки` +1 |
| НаПроверке → Закрыта | `ОтметитьВыполнена()` + `ОтметитьПроверено()`. В `КоличествоЗадач`: `Выполненных` +1, `ОжидающихПроверки` -1 |
| НаПроверке → ВРаботе (возврат) | `ОтметитьСнятьОтложена()`, снятие с проверки. В `КоличествоЗадач`: `ОжидающихПроверки` -1, `ВРаботе` +1 |
| → Отменена | `ОтметитьОтменена()` — все действия деактивируются. В `КоличествоЗадач`: предыдущий статус -1 |
| → Отложена | `ОтметитьОтложена()`. В `КоличествоЗадач` — перекладывается в категорию ожидания |
| Просрочена (по таймеру) | Регламентное задание `ПометкаЗадачПросроченными` → `КоличествоЗадач.ПометитьПросроченнуюЗадачу()` и `КоличествоДействийЗадач.ПометитьПросроченнуюЗадачу()` обновляют флаги `Просроченных`, `ПросроченныхОжидающихВыполнения`, `МожетБытьПросрочена` |

**Ключевой механизм:** при каждой смене статуса вызывается `ОбработатьОбновлениеЗадачи` (для `КоличествоЗадач`) и для каждого активного действия — `ОбновитьДанныеЗадачи` (для `КоличествоДействийЗадач` и `ДействияЗадач`). Фактические значения счётчиков пересчитываются в `RecordSetModule.ОбновитьДанныеЗадачи` / `ОбновитьДанныеДействия` через проверку `ВидСостоянияЗадачи` / `ВидСостоянияУчастниковЗадач`.

**Регламентные задания:**
- `ОбслуживаниеИтоговЗадач` — пересчёт итогов обоих регистров накопления
- `ПометкаЗадачПросроченными` — обновление флага `МожетБытьПросрочена` и счётчиков просроченных

## Итоговая карта регистров

```
Документ Задача (проведение)
  └─► РН.КоличествоЗадач          (движения, ОбработкаПроведения)
  └─► РС.ЗадачиПоАвторам          (движения, ОбработкаПроведения)
  └─► РН.КоличествоДействийЗадач  (при изменении реквизитов, ПриЗаписи → для каждого действия)
  └─► РС.ДействияЗадач            (при изменении реквизитов, ПриЗаписи → для каждого действия)

Документ ДействиеЗадачи (проведение)
  └─► РН.КоличествоДействийЗадач  (движения, ОбработкаПроведения → ЗаполнитьНаборПоДействию)
  └─► РС.ДействияЗадач            (движения, ОбработкаПроведения)
  └─► РС.ВсеИсполнителиДействийЗадач  (читается при заполнении набора для замещающих)
```
