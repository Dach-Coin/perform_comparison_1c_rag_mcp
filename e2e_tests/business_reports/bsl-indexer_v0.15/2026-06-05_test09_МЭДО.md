# Подсистема МЭДО в 1С:Документооборот КОРП 3.0
**Источник данных:** bsl-indexer v0.15.0, репозиторий «Тест ДО3»

## 1. Обзор подсистемы

МЭДО (Межведомственный электронный документооборот) реализован в конфигурации как самостоятельная подсистема обмена документами между государственными органами. Подсистема включает:

- **3 документа** (УведомлениеМЭДО, ДанныеДокументаМЭДО, КвитанцияМЭДО)
- **4 справочника** (ВидыДокументовМЭДО, МестаСоставленияДокументовМЭДО, ПричиныОтказаВРегистрацииМЭДО, Контрагенты — с командой НастройкиДляМЭДО)
- **4 регистра сведений** (НастройкиОрганизацийМЭДО, НастройкиКонтрагентовМЭДО, СостоянияДокументовМЭДО, ЖурналСобытийМЭДО)
- **6 общих модулей** (МЭДО, МЭДОДокументооборот, МЭДОСтруктурыДанных, МЭДОПереопределяемый, МЭДОВызовСервера, МЭДОКлиент и др.)
- **1 регламентное задание** (ВыполнениеОбменаМЭДО)
- **1 обработка** (ТекущиеДелаМЭДО)
- **12 определяемых типов** (КонтрагентМЭДО, ПредметМЭДО, ГрифДоступаМЭДО и др.)
- **6 констант** (ИспользоватьМЭДО, АвтоматическиОтправлятьКвитанцииМЭДО, ВариантАвтосозданияУведомленийМЭДО, РазмерПорцииОбработкиМЭДО, ВремяХраненияЖурналаСобытийМЭДО и др.)

> Все данные ниже получены напрямую из MCP-сервера. Отдельно указаны выводы, сделанные из анализа кода.

## 3. Процесс отправки документа через МЭДО

### 3.1 Полная цепочка отправки документа

Процесс реализован через **файловый обмен** (каталоги на файловой системе), а не через HTTP/веб-сервисы.

```
Пользователь устанавливает ГотовКОтправке = Истина
         ↓
[Вариант A: вручную] Форма ДанныеДокументаМЭДО → кнопка «Отправить по МЭДО»
         → Процедура ОтправитьПоМЭДО() [&НаКлиенте]
         → МЭДОВызовСервера.ОтправитьИсходящиеДокументы(Организация, ДанныеОтвета, [Документ])
         → МЭДО.ОтправитьИсходящиеДокументы(Настройки, ДанныеОтвета, МассивДокументов)
         → МЭДО.ОтправитьИсходящийДокумент(Настройки, ИсходящийДокумент, ДанныеОтвета)

[Вариант B: автоматически] Регламентное задание ВыполнениеОбменаМЭДО
         → МЭДО.ВыполнитьОбменМЭДО()
         → Для каждой организации из РС.НастройкиОрганизацийМЭДО:
              → ПолучитьВходящиеСообщения(Настройки)
              → ОтправитьИсходящиеКвитанции(Настройки, ДанныеОтвета)
              → ОтправитьИсходящиеДокументы(Настройки, ДанныеОтвета, Неопределено)
              → ОтправитьИсходящиеУведомления(Настройки, ДанныеОтвета, Неопределено)
```

### 3.2 Алгоритм отправки одного документа (ОтправитьИсходящийДокумент)

Процедура реализована в `CommonModules/МЭДО/Ext/Module.bsl` (строки 3041–3092):

1. Вызов `МЭДОПереопределяемый.ДанныеИсходящегоДокументаДляОтправки()` — получение данных документа для формирования пакета
2. Если ошибка — снимается признак ГотовКОтправке
3. Перебор пакетов из ТЧ «Пакеты» документа ДанныеДокументаМЭДО
4. Для каждого пакета фильтрация получателей по версии МЭДО (поддержка разных версий)
5. `ЗаписатьСодержимоеКонтейнераИсходящегоДокумента()` — формирование ZIP-архива ЭСД
6. `ЗаписатьСообщениеПоИсходящемуДокументу(КаталогОтправки, ...)` — запись в каталог отправки на файловой системе
7. При ошибке — очистка временных файлов, снятие признака

## 4. HTTP-сервисы и веб-сервисы для интеграции с МЭДО

**Специализированных HTTP-сервисов или веб-сервисов для МЭДО в конфигурации НЕТ.**

Это подтверждается двумя независимыми проверками через MCP:
- Поиск строки "МЭДО" в телах всех файлов `HTTPServices/**` — 0 совпадений
- Поиск строки "МЭДО" в телах всех файлов `WebServices/**` — 0 совпадений

Имеющиеся 8 HTTP-сервисов и 19 веб-сервисов конфигурации относятся к другим подсистемам (ЭДО, обмен данными, мобильное приложение, налоговый мониторинг и др.).

**Механизм интеграции:** МЭДО работает через **файловую систему** — обмен ZIP-архивами (ЭСД) через два каталога на ОС:
- `КаталогПолучения` — из него читаются входящие сообщения
- `КаталогОтправки` — в него записываются исходящие сообщения

Каталоги настраиваются в регистре сведений `НастройкиОрганизацийМЭДО` отдельно для каждой организации.

## 5. Регламентные задания

### 5.1 ВыполнениеОбменаМЭДО

| Параметр | Значение |
|---|---|
| Файл | `ScheduledJobs/ВыполнениеОбменаМЭДО.xml` |
| Синоним | Выполнение обмена МЭДО |
| Метод | `CommonModule.МЭДО.ВыполнитьОбменМЭДО` |
| Predefined | true |
| Use (по умолчанию) | false (выключено) |
| Перезапуск при сбое | 3 раза, интервал 10 сек |

**Что делает при срабатывании:**
1. Проверяет через `ОбщегоНазначения.ПриНачалеВыполненияРегламентногоЗадания()` — защита от параллельного запуска
2. Проверяет доступность внешних ресурсов через `МЭДОПереопределяемый.ПроверитьОбменСВнешнимиРесурсами()`
3. Для каждой организации из РС.НастройкиОрганизацийМЭДО:
   - Получает входящие сообщения (документы, уведомления, квитанции)
   - Отправляет исходящие квитанции
   - Отправляет исходящие документы
   - Отправляет исходящие уведомления
4. Очищает устаревшие записи журнала событий МЭДО

> По умолчанию задание **отключено** (`Use=false`). Активируется при включении настройки «ИспользоватьМЭДО».
