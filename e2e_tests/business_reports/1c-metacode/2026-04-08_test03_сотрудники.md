# Справочник Сотрудники — 1С:Документооборот КОРП 3.0 (DO3)

**Дата анализа:** 2026-04-08  
**Конфигурация:** test-do3 / ДокументооборотКОРП  
**Сервер MCP:** 1c-metacode-test-do3  

---

## 1. Общее описание

Справочник **Сотрудники** хранит сотрудников, закреплённых на конкретных должностях в структурных единицах предприятия. Комментарий из конфигурации: *«Содержит сотрудников на определенных должностях в структурных единицах»*.

Ключевая идея модели: одно физическое лицо может быть связано с несколькими записями справочника Сотрудники (разные должности, подразделения, периоды). Основная запись определяется через регистр сведений **ОсновныеСотрудники**.

---

## 2. Реквизиты справочника Сотрудники

| Реквизит | Тип (определён косвенно) | Описание |
|----------|--------------------------|----------|
| `Наименование` | Строка | Отображаемое имя сотрудника |
| `Владелец` | СправочникСсылка.ФизическиеЛица | Физическое лицо — основа записи сотрудника |
| `Должность` | СправочникСсылка.Должности | Штатная должность |
| `Подразделение` | СправочникСсылка.СтруктураПредприятия | Структурная единица (отдел, департамент) |
| `ГрафикРаботы` | СправочникСсылка.ГрафикиРаботы | Режим работы |
| `Помещение` | Ссылка (помещение/кабинет) | Рабочее место |
| `ДатаНачалаДействия` | Дата | Дата начала работы в данной роли |
| `ДатаОкончанияДействия` | Дата | Дата окончания работы в данной роли |
| `Действует` | Булево | Признак действующего сотрудника |
| `ПредставлениеВДокументах` | Строка | Как отображается в документах (ФИО и должность) |
| `ПредставлениеВПереписке` | Строка | Как отображается в переписке |

**Итого реквизитов:** 11

> **Примечание:** Явного реквизита "ФИО" нет — ФИО физического лица хранится в справочнике **ФизическиеЛица** (реквизит `Наименование`). Для сотрудника ФИО доступно через владельца.

## 4. Связи с ключевыми справочниками

### 4.1. Справочник ФизическиеЛица

**Тип связи:** владелец (реквизит `Владелец` в Сотрудниках ссылается на ФизическиеЛица).

Одно физическое лицо может иметь несколько записей в справочнике Сотрудники (совместительство, смена должности).

**Реквизиты ФизическихЛиц:**
| Реквизит | Описание |
|----------|----------|
| `Наименование` | ФИО физлица |
| `ДатаРождения` | Дата рождения |
| `ИНН` | ИНН |
| `СтраховойНомерПФР` | СНИЛС |
| `Пол` | Пол |
| `ГруппаДоступа` | Группа доступа физлица |
| `ФайлФотографии` | Фотография |
| `Комментарий` | Комментарий |
| `Владелец` | Владелец (иерархия) |
| `Родитель` | Родитель (иерархия) |

**Программный API связи:**
```bsl
// ОбщиеМодули.Сотрудники
Функция ФизЛицоСотрудника(Сотрудник) Экспорт
// Возвращает: СправочникСсылка.ФизическиеЛица

// ОбщиеМодули.Сотрудники  
Функция ЭтоСотрудникиОдногоФизЛица(Сотрудник1, Сотрудник2) Экспорт
// Возвращает: Булево
```

**Регистр ОсновныеСотрудники** — хранит основного сотрудника для каждого физлица:
- Измерение: `ФизическоеЛицо`
- Ресурс: `Сотрудник`

### 4.2. Справочник Должности

**Тип связи:** реквизит `Должность` в Сотрудниках.

Справочник Должности имеет минимальную структуру:
| Реквизит | Описание |
|----------|----------|
| `Владелец` | Владелец (иерархия) |
| `тст_ТиповаяПечатнаяФорма` | Кастомизация DO3 для test — типовая печатная форма |

Должность хранит только название; всё остальное — через сотрудника.

**Программный API:**
```bsl
// ОбщиеМодули.Сотрудники
Функция ДолжностьСотрудника(Сотрудник) Экспорт
// Возвращает: СправочникСсылка.Должности
```

### 4.3. Справочник СтруктураПредприятия (подразделения)

**Тип связи:** реквизит `Подразделение` в Сотрудниках.

**Реквизиты СтруктурыПредприятия:**
| Реквизит | Описание |
|----------|----------|
| `Руководитель` | Ссылка на сотрудника-руководителя |
| `ГрафикРаботы` | График работы по умолчанию для подразделения |
| `ВидПодразделения` | Вид (из справочника ВидыПодразделений) |
| `Ранг` | Числовой ранг для иерархии |
| `УказанОсобыйРанг` | Флаг особого ранга |
| `Комментарий` | Комментарий |
| `Владелец` | Владелец (иерархия) |

**Программный API:**
```bsl
// ОбщиеМодули.Сотрудники
Функция ПодразделениеСотрудника(Сотрудник) Экспорт
// Возвращает: СправочникСсылка.СтруктураПредприятия

// ОбщиеМодули.Сотрудники
Функция ПредставлениеПодразделенияИДолжностиСотрудника(Подразделение, Должность) Экспорт
// Возвращает: Строка
```

## 5. Механизм замещения сотрудников

### 5.1. Справочник ЗамещающиеИПомощники

Механизм замещения реализован через отдельный справочник **ЗамещающиеИПомощники**.

**Реквизиты:**
| Реквизит | Тип | Описание |
|----------|-----|----------|
| `Сотрудник` | СправочникСсылка.Сотрудники | Замещаемый сотрудник (кого замещают) |
| `Замещающий` | СправочникСсылка.Сотрудники | Кто замещает |
| `ВидЗамещения` | ПеречислениеСсылка.ВидыЗамещения | Замещающий / Помощник |
| `ДатаНачала` | Дата | Дата начала замещения |
| `ДатаОкончания` | Дата | Дата окончания замещения |
| `Действует` | Булево | Признак активного замещения |
| `Основание` | Строка | Причина замещения |
| `Создал` | СправочникСсылка.Пользователи | Кто создал запись |
| `Наименование` | Строка | Наименование записи |
| `Комментарий` | Строка | Комментарий |
| `Владелец` | Владелец | Иерархия |

### 5.2. Вспомогательные объекты замещения

- **Перечисление ВидыЗамещения** — варианты: Замещающий / Помощник
- **Справочник ОбластиЗамещения** — область (сфера) замещения (реквизиты: Владелец, Порядок)

### 5.3. API замещения (ключевые функции)

| Функция/Процедура | Модуль | Описание |
|---|---|---|
| `АктуальныеЗамещения(Кому, ОбластиЗамещения)` | Справочники.ЗамещающиеИПомощники (МодульМенеджера) | Возвращает все актуальные замещения для сотрудника/пользователя |
| `АктуальныеЗамещенияСотрудников(СотрудникиМассив, ОбластиЗамещения)` | Справочники.ЗамещающиеИПомощники | Замещения массива сотрудников |
| `АктуальныеЗамещенияПоДействиямЗадач(ДействияЗадач, ЗамещающиеИПомощники)` | Справочники.ЗамещающиеИПомощники | Замещения по задачам бизнес-процессов |
| `ВсеЗамещенияПоДействиямЗадач(...)` | Справочники.ЗамещающиеИПомощники | Все (не только одно) замещения по задачам |
| `ОбновитьДанныеЗадачПоЗамещению(Замещение)` | Справочники.ЗамещающиеИПомощники | Синхронизация задач при изменении замещения |
| `СотрудникиВключаяЗамещения(ТекущийПользователь)` | ОбщиеМодули.ДействияСерверПовтИсп | Сотрудники + активные замещения пользователя |
| `ДобавитьУведомленияПоЗамещению(...)` | ОбщиеМодули.РаботаСУведомлениями | Уведомления о событиях замещения |
| `ЗаписьЗамещения(Замещение)` | РегистрыСведений.СоставСубъектовПравДоступа | Делегирование прав доступа замещающему |
| `ЕстьЗамещающиеПоДействию(ДействиеЗадачи)` | РегистрыСведений.ВсеИсполнителиДействийЗадач | Проверка наличия замещающих по конкретному действию |

### 5.4. Как работает замещение

1. Создаётся запись в справочнике **ЗамещающиеИПомощники** с указанием: кто замещает, кого, в каких областях, на какой период.
2. При записи вызывается `ОбновитьДанныеЗадачПоЗамещению` — задачи БП переназначаются замещающему.
3. Права доступа делегируются через `ЗаписьЗамещения` в регистр `СоставСубъектовПравДоступа`.
4. Замещающий получает уведомления через `ДобавитьУведомленияПоЗамещению`.
5. Отличие замещающего от помощника: помощник видит задачи, но замещающий получает их с приоритетом.

## 8. Выводы

1. **Архитектура "физлицо + сотрудник"**: один человек (ФизическоеЛицо) может иметь несколько позиций (Сотрудники). Основная позиция определяется через РС ОсновныеСотрудники.

2. **Минимальная структура Должностей**: справочник Должности содержит только имя и кастомный реквизит `тст_ТиповаяПечатнаяФорма`. Все данные о месте сотрудника на должности — в самом справочнике Сотрудники.

3. **Замещение — полноценный механизм**: справочник ЗамещающиеИПомощники, перечисление ВидыЗамещения (Замещающий/Помощник), справочник ОбластиЗамещения. Интегрирован с БП (задачи), уведомлениями и правами доступа.

4. **Регистры рабочего времени**: несколько регистров (ДоступноеВремяСотрудников, ЗанятостьСотрудников помечены к удалению; актуальны ХронометражРабочегоВремени и НастройкиРабочегоКалендаря).

5. **Полномочия**: отдельный регистр ПолномочияСотрудников (измерения: Владелец-сотрудник, Полномочия).

6. **Специфика DO3/test**: имеется интеграция с SAP (РС ДанныеSAPСотрудники), функциональная подчинённость (`тст_СтруктураФункциональнойПодчиненности`), кастомные печатные формы Должностей.
