# Бизнес-отчёт: Поиск процедуры определения исполнителей задачи с учётом замещений
**Дата:** 2026-04-08
**Сервер:** 1c-metacode-test-do3
**Конфигурация:** 1С:Документооборот КОРП 3.0 (DO3)

---

## Запрос пользователя

> Найти код, который определяет фактических исполнителей задачи с учётом замещений.
> Процедура учитывает замещения сотрудников, работает с ролями исполнителей,
> вызывается при назначении задачи.

---

## Результат: найдена процедура

### Главная функция

**`ОпределитьФактическихИсполнителей`**
- Модуль: `ОбщиеМодули.РаботаСЗадачами`
- Тип: **Функция (Экспорт)**

**Сигнатура:**
```bsl
Функция ОпределитьФактическихИсполнителей(
    ДействияЗадач,                     // Массив из ДокументСсылка.ДействиеЗадачи
    ВыполнитьОтИмени,                  // СправочникСсылка.Пользователи
    ВыбранныйФактическийИсполнитель,   // Структура
    РеквизитыДействийЗадач = Неопределено  // Соответствие
) Экспорт
```

**Возвращает структуру:**
| Поле | Тип | Описание |
|------|-----|----------|
| `ДействияБезФактИсполнителя` | Массив из ДокументСсылка.ДействиеЗадачи | Задачи, для которых не удалось автоопределить исполнителя |
| `ДействияБезКомуАдресовано` | Массив из ДокументСсылка.ДействиеЗадачи | Задачи без адресата |
| `ФактическиеИсполнителиПолные` | Соответствие | Полный список фактических исполнителей |
| `ФактическиеИсполнителиПоДействиям` | Соответствие | Исполнители сгруппированные по действиям |
| `ОснованияФактИсполнителейПоДействиям` | Соответствие | Основания назначения (прямое/замещение) |

**Описание:** Выполняет попытку автоматического определения фактического исполнителя — определяет, является ли текущий пользователь прямым адресатом задачи или замещает адресата.

---

### Вспомогательная функция замещений

**`ПодходящиеЗамещения`**
- Модуль: `ОбщиеМодули.ЗамещающиеИПомощники`
- Тип: **Функция (Экспорт)**

**Сигнатура:**
```bsl
Функция ПодходящиеЗамещения(
    ДействиеЗадачи,                 // ДокументСсылка.ДействиеЗадачи
    ВидЗамещения = Неопределено,    // ПеречислениеСсылка.ВидыЗамещения
    КешДанных = Неопределено        // Структура (ускорение работы)
) Экспорт
```

**Возвращает таблицу значений:**
| Колонка | Тип |
|---------|-----|
| `Замещение` | СправочникСсылка.ЗамещающиеИПомощники |
| `Замещающий` | СправочникСсылка.Сотрудники |

**Описание:** Возвращает замещения, актуальные для текущего действия задачи на момент выполнения. Фильтрует по дате (Действует) и при необходимости по виду замещения.

---

### Связанная функция: запись доступа замещающих

**`ЗаписатьДоступЗамещающихПоДействиюЗадачи`**
- Модуль: `ОбщиеМодули.ЗамещающиеИПомощники`
- Тип: **Процедура (Экспорт)**

```bsl
Процедура ЗаписатьДоступЗамещающихПоДействиюЗадачи(
    ДействиеЗадачи   // ДокументСсылка.ДействиеЗадачи
) Экспорт
```

Записывает данные для доступа замещающих к действию задачи — вызывается при создании/изменении действия задачи.

## Структура данных замещений

### Справочник `ЗамещающиеИПомощники`
| Реквизит | Назначение |
|----------|------------|
| `Сотрудник` | Кто замещается (основной исполнитель) |
| `Замещающий` | Кто замещает |
| `ВидЗамещения` | Тип замещения (Перечисление.ВидыЗамещения) |
| `ДатаНачала` | Начало периода замещения |
| `ДатаОкончания` | Конец периода замещения |
| `Действует` | Признак активности замещения |
| `Основание` | Причина замещения |
| `Владелец` | Структурная единица |
| `Создал` | Кто создал запись |

## Дополнительные функции подсистемы

### В модуле `ОбщиеМодули.РаботаСЗадачами`

| Функция | Описание |

## Вывод

Процедура определения фактических исполнителей с учётом замещений реализована в двух взаимосвязанных модулях:

1. **`ОпределитьФактическихИсполнителей`** (`ОбщиеМодули.РаботаСЗадачами`) — основная точка входа, вызывается при выполнении задачи (`ВзятьВРаботу`).

2. **`ПодходящиеЗамещения`** (`ОбщиеМодули.ЗамещающиеИПомощники`) — ядро механизма замещений, работает с данными справочника `ЗамещающиеИПомощники`.

Алгоритм:
- Проверяет, является ли пользователь прямым адресатом задачи
- Если нет — ищет активные замещения в справочнике `ЗамещающиеИПомощники` (по дате, виду замещения, области)
- Возвращает структуру с фактическими исполнителями и основаниями их назначения
- Если автоопределение невозможно — возвращает признак `НужноВыбратьФактическогоИсполнителя = Истина` → открывается форма выбора

**Вызов при назначении задачи:** `ЗаписатьДоступЗамещающихПоДействиюЗадачи` вызывается при каждой записи действия задачи (событие `ПриЗаписиДействия`/`ПередЗаписьюДействия`), что обеспечивает актуальность данных о доступе замещающих в момент активации задачи.
