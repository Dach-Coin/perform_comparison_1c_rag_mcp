## 1. Общая архитектура системы нумерации

Система нумерации в ДО КОРП построена на нескольких слоях:

1. **Справочник Нумераторы** — объект конфигурации, хранящий шаблон (формат) номера, периодичность сброса, правила независимой нумерации
2. **Регистр сведений Нумерация** — счётчик текущего номера (хранит ТекущийНомер по набору измерений)
3. **Регистр сведений НастройкиНумерации** — привязка нумераторов к видам документов
4. **Перечисления** — ПериодичностьНумераторов, СпособыНумерации, НазначенияНумераторов
5. **Общие модули** — Нумерация, НумерацияКлиент, НумерацияКлиентСервер, НумерацияПереопределяемый

---

## 2. Автоматическая нумерация при создании документа

**Да, в ДО КОРП реализована автоматическая нумерация.** Механизм работает следующим образом:

- При создании нового документа система определяет нумератор через функцию `Нумерация.ПолучитьНумераторДокумента(Объект)`.
- Затем через `НумерацияКлиентСервер.ПолучитьПараметрыНумерации(Объект)` получаются все параметры: ВидДокумента, Организация, Подразделение, Проект, Тематика, ГрифДоступа и другие.
- Номер формируется процедурами `Нумерация.СформироватьЧисловойНомерДокумента` или `Нумерация.СформироватьСтроковыйНомерДокумента` в зависимости от типа.
- Если включена функция временных номеров (флаг `ВидыДокументов.ИспользоватьВременныеНомера`), документу сначала присваивается временный номер.
- После регистрации временный номер заменяется на постоянный регистрационный.

**Поддержка пропущенных номеров:** если в нумераторе включен флаг `ИспользоватьПропущенныеНомера`, система предлагает использовать ранее пропущенный номер через `НумерацияКлиент.ВыбратьПропущенныеНомера`.

## 3. Регистрация документа — бизнес-процесс

В ДО КОРП есть отдельный **бизнес-процесс "Регистрация"** (`БизнесПроцессы.Регистрация`).

### Атрибуты БП Регистрация:
| Реквизит | Назначение |
|---------|-----------|
| Исполнитель | Регистратор (сотрудник, выполняющий регистрацию) |
| РезультатРегистрации | Результат (зарегистрирован / отказано) |
| ПовторитьРегистрацию | Флаг повтора при отказе |
| Шаблон | Шаблон процесса |
| ИсточникДанных | Предмет регистрации (документ) |
| Состояние | Текущее состояние процесса |
| СрокИсполнения | Срок регистрации |
| Автор | Инициатор |

### Ключевые функции регистрации (модуль Делопроизводство):

- **`ЗарегистрироватьПредмет(Предмет, СообщениеОбОшибке, РегистрационныйНомер)`** — главная функция регистрации документа; возвращает Булево (успех/неуспех)
- **`ДокументЗарегистрирован(Документ)`** — проверяет, зарегистрирован ли документ
- **`ПредметМожетБытьЗарегистрирован(Предмет, РегистрационныйНомер, ДатаРегистрации)`** — предварительная проверка
- **`НомерУникален(Объект, ЭтоВременныйНомер)`** — проверка уникальности номера

### Клиентский ввод данных регистрации:
- **`ДелопроизводствоКлиент.ВвестиДанныеРегистрации(РегистрационныйНомер, ДатаРегистрации)`** — диалог ввода регистрационных данных

### Признак обязательной регистрации:
В Справочнике ВидыДокументов есть реквизит `тст_НеобходимаРегистрация` — позволяет настроить, является ли регистрация обязательным этапом для данного вида документов.

## 4. Где хранятся настройки нумерации

### 4.1. Регистр сведений "Нумерация" (счётчик номеров)

**Измерения** — определяют уникальность счётчика:
| Измерение | Назначение |
|-----------|-----------|
| Нумератор | Ссылка на справочник Нумераторы |
| ВидДокумента | Вид документа |
| Организация | Организация |
| Подразделение | Подразделение |
| ПериодНумерации | Дата начала периода (год/квартал/месяц) |
| Проект | Проект |
| Тематика | Тематика документа |
| ВопросДеятельности | Вопрос деятельности |
| ГрифДоступа | Гриф доступа |
| СвязанныйДокумент | Связанный документ |
| УзелКОД | Узел корпоративного обмена данными |

**Ресурс:** `ТекущийНомер` — текущее значение счётчика

### 4.2. Регистр сведений "НастройкиНумерации" (привязка нумераторов)

**Измерения** — ключ привязки:
ВидДокумента, ТипДокумента, Организация, Подразделение, Проект, Тематика, ВопросДеятельности, ГрифДоступа, Контрагент, Назначение, УзелКОД

**Ресурсы:**
- `Нумератор` — ссылка на нумератор
- `СпособНумерации` — способ нумерации (из перечисления)

### 4.3. Регистр сведений "ИндексыНумерации"

Хранит индекс нумерации для объектов (используется в шаблоне номера).
- Измерение: Объект
- Ресурс: Индекс

### 4.4. Регистр сведений "ПропускиРегистрационныхНомеров"

Хранит информацию о пропущенных (освобождённых) номерах.
- Измерения: все те же + `ПропущенныйНомер`

## 5. Формирование регистрационного номера

### 5.1. Справочник "Нумераторы" — ключевые реквизиты:

| Реквизит | Назначение |
|---------|-----------|
| ФорматНомера | Шаблон номера (текстовый, с параметрами типа `{Год}`, `{Номер}`, `{Индекс}`) |
| Пример | Пример сформированного номера |
| Периодичность | Периодичность сброса счётчика (из перечисления ПериодичностьНумераторов) |
| Назначение | Назначение: временный или регистрационный номер (перечисление НазначенияНумераторов) |
| ИспользоватьПропущенныеНомера | Флаг использования пропущенных номеров |
| тст_ДлинаЧисловогоНомера | Длина числовой части номера (дополнение нулями) |

### 5.2. Алгоритм формирования номера:

1. `РазобратьФорматНомера(ФорматНомера)` — разбирает шаблон в структуру
2. `ПолучитьЗначенияПараметровНомера(Объект, СтруктураФорматаНомера)` — вычисляет значения каждого параметра (год, месяц, организация, индекс и т.д.)
3. `СформироватьНомерДокументаПоФормату(СтруктураФорматаНомера, ЗначенияПараметров)` — подставляет значения в шаблон

### 5.3. Периодичность сброса счётчика:

Перечисление `ПериодичностьНумераторов` определяет, когда счётчик сбрасывается в 0.
Функции `НачалоПериодаНумерации(Периодичность, Дата)` и `КонецПериодаНумерации(Периодичность, Дата)` вычисляют границы текущего периода.

### 5.4. Индекс нумерации:

В регистре `ИндексыНумерации` хранится индекс конкретного объекта. `ПоказатьИндексНумерации(Форма)` управляет отображением поля Индекс на форме — оно показывается только если хотя бы один нумератор использует индекс.

### 5.5. Регистрационный штамп:

После регистрации создаётся визуальный штамп через `Делопроизводство.СоздатьРегистрационныйШтамп(СведенияОРегистрации)` и может быть вставлен в файл документа через `ВставитьРегистрационныйШтампИШтрихкод`.

## 6. Разные схемы нумерации для разных видов документов

**Да, полностью поддерживается.** Механизм реализован через:

1. **Регистр НастройкиНумерации** — для каждого сочетания (ВидДокумента + Организация + Подразделение + ...) можно назначить свой нумератор.
2. **Независимая нумерация** — в справочнике Нумераторы есть набор флагов `НезависимаяНумерацияПо*`:
   - По виду документа
   - По организации
   - По подразделению
   - По проекту
   - По тематике
   - По вопросу деятельности
   - По грифу доступа
   - По связанному документу
   - По узлу КОД
3. **СпособНумерации** — поле ресурса регистра НастройкиНумерации; из перечисления `СпособыНумерации` (автоматически / вручную и т.д.)
4. Функции `ЗаписатьНастройкиНумерацииВидаДокумента` и `ПрочитатьНастройкиНумерацииВидаДокумента` позволяют программно управлять настройками.

## 7. Итоговая схема взаимодействия объектов

```
ВидыДокументов (ИспользоватьВременныеНомера, тст_НеобходимаРегистрация)
       ↓
РС.НастройкиНумерации [ВидДокумента + Орг + ... → Нумератор + СпособНумерации]
       ↓
Справочники.Нумераторы [ФорматНомера, Периодичность, НезависимаяНумерацияПо*, ИспользоватьПропущенныеНомера]
       ↓
РС.Нумерация [Нумератор + ВидДокумента + Орг + Период + ... → ТекущийНомер]
       ↓
ОбщийМодуль.Нумерация → СформироватьНомер → РегистрационныйНомер
       ↓
БизнесПроцессы.Регистрация (Исполнитель → ЗарегистрироватьПредмет → Штамп)
```
