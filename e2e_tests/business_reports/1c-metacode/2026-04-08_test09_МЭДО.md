## 1. Обзор подсистемы

МЭДО (Межведомственный электронный документооборот) — подсистема для обмена электронными документами между государственными органами. В конфигурации реализована как самостоятельный функциональный блок с собственными документами, общими модулями, регистрами, перечислениями и регламентным заданием.

Включение подсистемы управляется константой **ИспользоватьМЭДО**.

## 3. Процесс обмена документами через МЭДО

### 3.1 Архитектура модулей

Подсистема состоит из 8 общих модулей:

| Модуль | Назначение |
|--------|-----------|
| **МЭДО** | Основной серверный модуль. Бизнес-логика обмена, обработчик РЗ |
| **МЭДОВызовСервера** | Клиент-серверный модуль — вызовы с клиента на сервер |
| **МЭДОДокументооборот** | Интеграция МЭДО с основными объектами ДО |
| **МЭДОКлиент** | Клиентские процедуры (UI, отображение результатов) |
| **МЭДОКлиентПереопределяемый** | Переопределяемые клиентские процедуры |
| **МЭДОПереопределяемый** | Переопределяемые серверные процедуры (точка расширения) |
| **МЭДОПовтИсп** | Кэшируемые функции (повторное использование) |
| **МЭДОСтруктурыДанных** | Фабрика структур данных МЭДО |

### 3.3 Схема процесса обмена

#### Исходящий документ (отправка)
```
1. Пользователь помечает документ "Готов к отправке" (ГотовКОтправке = Истина)
2. РЗ ВыполнениеОбменаМЭДО → МЭДО.ВыполнитьОбменМЭДО()
3. МЭДО.ИсходящиеДокументыКОтправке() — выбирает документы к отправке
4. МЭДОПереопределяемый.ДанныеИсходящегоДокументаДляОтправки() — собирает данные
5. Формируется контейнер ЭСД (ZIP), структура НовыйДанныеИсходящегоДокументаДляОтправки:
   - Организация (Отправитель), Получатели, ВидДокумента, ГрифДоступа
   - ГлавныйФайл + Приложения + ПодписьКонтейнера (ЭЦП)
   - Пакеты для каждого получателя
6. МЭДОВызовСервера.ОтправитьИсходящиеДокументы() — копирует в КаталогОтправки (или FTP)
7. Создаётся Документ.ДанныеДокументаМЭДО (контейнер с ИдентификаторомДокумента, архивом ЭСД)
8. Статус меняется на "Отправлен"
```

#### Исходящее уведомление
```
1. МЭДО.ИсходящиеУведомленияКОтправке() — список готовых уведомлений
2. МЭДО.ДанныеИсходящегоУведомленияДляОтправки() — данные уведомления
   Заполняются блоки в зависимости от типа:
   - ИсходящееУведомление_ЗаполнитьОпубликование
   - ИсходящееУведомление_ЗаполнитьОтказВРегистрации
   - ИсходящееУведомление_ЗаполнитьПостановкуНаКонтроль
   - ИсходящееУведомление_ЗаполнитьПодготовкуДоклада
   - ИсходящееУведомление_ЗаполнитьНаправлениеДоклада
3. Отправка аналогична документу
```

#### Входящий документ (получение)
```
1. РЗ ВыполнениеОбменаМЭДО → читает КаталогПолучения (или FTP)
2. Для каждого ZIP-файла: МЭДО.ОбработатьВходящееЭСД(ФайлZip, Организация, ТипКонтента)
3. Разбор XML по формату МЭДО 2.7 / 2.7.1 (XDTO-пакеты IEDMSContainerМЭДО_2_7, IEDMSMessageМЭДО_2_7_1)
4. При ТипКонтента = "Транспортный контейнер":
   - Создаётся/обновляется основной документ (ВходящееПисьмо или другой ПредметМЭДО)
   - МЭДО.ЗаписатьДанныеВходящегоДокументаМЭДО() — создаёт ДанныеДокументаМЭДО
5. При ТипКонтента = "Уведомление":
   - Создаётся Документ.УведомлениеМЭДО
   - Обновляется состояние исходящего документа
6. МЭДО.ВходящиеДокументыКОбработке() — дополнительная обработка входящих
7. Автоматически формируется КвитанцияМЭДО (подтверждение приёма)
```

## 4. HTTP-сервисы и веб-сервисы

**HTTP-сервисы МЭДО:** не обнаружены.  
**Веб-сервисы МЭДО:** не обнаружены.

Обмен с МЭДО реализован **файловым методом**: через каталоги файловой системы или FTP. Настройка в регистре НастройкиОрганизацийМЭДО:
- **СпособОбмена** = Перечисление.СпособыОбменаМЭДО (Папка / FTP)
- **КаталогОтправки** / **КаталогОтправкиFTP**
- **КаталогПолучения** / **КаталогПолученияFTP**

XML-схемы пакетов подключены через XDTO-пакеты:
- `IEDMSContainerМЭДО_2_7` — транспортный контейнер МЭДО версии 2.7
- `IEDMSContainerМЭДО_2_7_1` — транспортный контейнер МЭДО версии 2.7.1
- `IEDMSMessageМЭДО_2_7` — сообщение МЭДО версии 2.7
- `IEDMSMessageМЭДО_2_7_1` — сообщение МЭДО версии 2.7.1

## 9. Определяемые типы (расширяемые)

Подсистема использует определяемые типы для интеграции с документами ДО:

- **ОпределяемыйТип.ПредметКвитанцииМЭДО** — предмет квитанции (Документ или Уведомление)

- **ОпределяемыйТип.ГрифДоступаМЭДО** — гриф доступа
- **ОпределяемыйТип.ВидДокументаМЭДО** — вид документа
