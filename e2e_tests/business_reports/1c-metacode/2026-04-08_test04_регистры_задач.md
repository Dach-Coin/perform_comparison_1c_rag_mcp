## 1. Регистры накопления

### РН КоличествоЗадач
Хранит агрегированные счётчики задач по авторам. Используется для быстрого отображения виджетов и счётчиков в интерфейсе.

**Измерения:**
| Поле | Тип |
|------|-----|
| Автор | ОпределяемыйТип.УчастникЗадач |
| ВидЗадачи | СправочникСсылка.ВидыЗадач |
| ВидПриложения | ОпределяемыйТип.ВидПриложенияЗадач |
| Контрагент | СправочникСсылка |
| Проект | СправочникСсылка.Проекты |
| ТипПриложения | ПеречислениеСсылка.ТипыПриложенийЗадач |
| Флаг | ПеречислениеСсылка.ФлагиОбъектов |

**Ресурсы:**
| Поле | Назначение |
|------|-----------|
| Всего | Общее количество задач |
| Новых | Задачи, ещё не взятые в работу |
| ВРаботе | Задачи в статусе «В работе» |
| ОжидающихВыполнения | Ожидают исполнения |
| ОжидающихПроверки | На проверке у автора |
| Выполненных | Завершённые задачи |
| Просроченных | Просроченные (в любом статусе) |
| ПросроченныхОжидающихВыполнения | Просроченные и ещё не выполненные |
| Черновиков | Задачи-черновики |

**Механизм обновления:** через очередь кэширующих данных (асинхронно).  
Ключевые процедуры менеджера: `ОбработатьОбновлениеЗадачи`, `ОбработатьОчередьОбновленияКэширующихДанных`, `ОбновитьКэширующиеДанныеПолностью`, `ПометитьПросроченнуюЗадачу`.

Хранит счётчики действий задач в разрезе исполнителей. Основной регистр для отображения «Моих задач» в обзоре и виджетах исполнителей.

**Измерения:**
| Поле | Тип |
|------|-----|
| Автор | ОпределяемыйТип.УчастникЗадач |
| ВидДействия | СправочникСсылка.ВидыДействийЗадач |
| ВидЗадачи | СправочникСсылка.ВидыЗадач |
| ВидПриложения | ОпределяемыйТип.ВидПриложенияЗадач |
| Замещающий | СправочникСсылка.Сотрудники |
| Исполнитель | ОпределяемыйТип.УчастникЗадач |
| Контрагент | СправочникСсылка |
| Проект | СправочникСсылка.Проекты |
| ТипПриложения | ПеречислениеСсылка.ТипыПриложенийЗадач |
| Флаг | ПеречислениеСсылка.ФлагиОбъектов |

**Ресурсы:**
| Поле | Назначение |
|------|-----------|
| Всего | Всего действий |
| Новых | Новые (не взятые в работу) |
| ВРаботе | В работе у исполнителя |
| ВСрок | Выполненные в срок |
| ОжидающихВыполнения | Ожидают выполнения |
| ОжидающихПроверки | На проверке |
| Выполненных | Выполненные |
| Истекающих | Срок истекает скоро |
| ПоступилиОбновления | Есть новые обновления |
| Просроченных | Просроченные |
| ПросроченныхОжидающихВыполнения | Просроченные и ожидающие |

**Ключевые процедуры:**
```
РегистрыНакопления.КоличествоДействийЗадач (МодульМенеджера):
  ЗаполнитьНаборПоДействию(НаборЗаписей, ДействиеЗадачи,
      РеквизитыДействия, РеквизитыЗадачи) Экспорт
  ОбновитьДанныеЗадачи(ДействиеЗадачи, РеквизитыДействия,
      РеквизитыЗадачи) Экспорт

РегистрыНакопления.КоличествоДействийЗадач (МодульНабораЗаписей):
  ОбновитьДанныеДействия(РеквизитыДействия) Экспорт
  ОбновитьДанныеЗадачи(РеквизитыДействия, РеквизитыЗадачи) Экспорт
```

## 2. Регистры сведений

### РС ДействияЗадач
Основной кэширующий регистр — хранит текущее состояние каждого действия задачи для быстрого отображения в списках. Обновляется синхронно при каждом изменении действия или задачи.

**Измерения:** Дата, ДействиеЗадачи, Исполнитель

**Ресурсы (39 полей):** полный снимок состояния действия — Автор, ВидДействия, ВидЗадачи, ВидСостоянияУчастниковЗадач, ВРаботе, ВСрок, Выполнено, ДатаВыполнения, ДатаНачала, ДатаНачалаУчета, ДатаОкончанияУчета, ДатаСоздания, ЕстьЗамещающие, ЕстьПодзадачи, Заголовок, Задача, Запланировано, Истекает, КоличествоПереносовСроков, КонтрольныйСрок, КонтрольныйСрокОбщий, Новое, ОжидаетВыполнения, ОжидаетПроверки, ОписаниеПоступившихОбновлений, ПоступилиОбновления, Приоритет, Проект, Просрочено, ПросроченоИОжидаетВыполнения, РезультатДействия, СостояниеКонтроля, СостояниеУчастникаЗадачи, Срок, ТипПриложения, ТрудоемкостьДо, ТрудоемкостьОт, Трудозатраты, Флаг

**Ключевые процедуры:**
```
РегистрыСведений.ДействияЗадач (МодульМенеджера):
  ОбновитьДанныеЗадачи(ДействиеЗадачи, РеквизитыДействия,
      РеквизитыЗадачи) Экспорт
  ОбновитьСостояниеКонтроля(ДействиеЗадачи,
      ПараметрыКонтроляДляКэша) Экспорт

РегистрыСведений.ДействияЗадач (МодульНабораЗаписей):

```

**Измерения:** ДействиеЗадачи, Исполнитель, Основание  
**Ресурсы:** нет (только связь «действие — исполнитель — основание замещения»)

**Ключевые процедуры:**
```

  ЗамещенияПоДействию(ДействиеЗадачи, ВидЗамещения) Экспорт
  ЕстьЗамещающиеПоДействию(ДействиеЗадачи) Экспорт

ОбщиеМодули.ЗамещающиеИПомощники:
  ЗаписатьДоступЗамещающихПоДействиюЗадачи(ДействиеЗадачи) Экспорт
```

## 3. Ключевые процедуры записи

### Точка входа — подписка на событие «При записи»

При сохранении документа Задача вызывается подписка:

```bsl
// ОбщиеМодули.ИнтеграцияЗадач
Процедура ПриЗаписиЗадачи(ЗадачаОбъект, Отказ) Экспорт
// Обработка события "При записи" задачи
```

Внутри этой процедуры вызывается контекст изменений:
```bsl
// ОбщиеМодули.ИнтеграцияЗадач
Процедура ИнициализироватьКонтекстИзмененияЗадачиДействияЗадачи(
    ЗадачаОбъект) Экспорт
// Инициализирует контекст для сбора изменений перед записью

Процедура ЗаполнитьКонтекстИзмененияРеквизитов(Контекст, ЗадачаОбъект)
// Заполняет контекст данными о новом и старом состоянии

Процедура ОбработатьИзмененияРеквизитовПриОбновленииПоИсточнику(Контекст)
// Обрабатывает изменения: пишет в историю, регистрирует бизнес-событие
```

## 4. Жизненный цикл задачи

### Создание задачи

При первой записи Задачи происходит:

1. **ПриЗаписиЗадачи** (ИнтеграцияЗадач) — подписка фиксирует факт создания
2. Создаются документы **ДействиеЗадачи** для каждого исполнителя/участника
3. Заполняется **РС ДействияЗадач** — для каждого действия создаётся запись с полным снимком состояния (статус «Новое», ВидСостоянияУчастниковЗадач = Новое)
4. Заполняется **РН КоличествоДействийЗадач** — счётчики Всего +1, Новых +1
5. В **РС ВсеИсполнителиДействийЗадач** добавляются все исполнители и их замещающие
6. В **РС СведенияОбИсполнителяхЗадач** записываются исполнители задачи
7. В **РС ИсторияЗадач** добавляется событие «Создание»
8. **РН КоличествоЗадач** ставится в очередь для асинхронного обновления

---

### Изменение задачи (исполнитель берёт в работу)

Вызов `НаправитьНаИсполнение()` → `ОтметитьВРаботе()` инициирует:

1. **УстановитьСостояние** (Документы.Задача) — новое состояние записывается в объект
2. **ОбработатьИзменениеСостоянияДействияЗадачи** (РаботаСЗадачами)
3. **РС ДействияЗадач** обновляется: ВРаботе = Истина, Новое = Ложь, ОжидаетВыполнения = Истина
4. **РН КоличествоДействийЗадач**: Новых -1, ВРаботе +1
5. **РС ПоступившиеОбновленияЗадач** — если автор должен видеть обновление
6. **РС ИсторияЗадач** — добавляется событие «Взято в работу»

---

### Выполнение задачи (смена статуса на «Выполнено»)

Вызов `ОтметитьВыполненаДляОжидающихПроверки()` или `Проверить()`:

1. **ОбработатьИзменениеСостоянияДействияЗадачи**
2. **РС ДействияЗадач**: Выполнено = Истина, ОжидаетВыполнения = Ложь, ОжидаетПроверки = Истина (если требуется проверка)
3. **РН КоличествоДействийЗадач**: ВРаботе -1, Выполненных +1 или ОжидающихПроверки +1
4. **ОбновитьЗадачуПоСостояниюДействия** (ИнтеграцияЗадач) — пересчёт задачи
5. Если задача завершена: **ПриЗакрытииЗадачи** (ИнтеграцияЗадач)
6. **РС ИсторияЗадач** / **РС ИсторияСобытийЗадач** — событие выполнения
7. **РН КоличествоЗадач** ставится в очередь: Выполненных +1

## Итоговая схема зависимостей

```
Документы.Задача (запись/изменение)
  │
  ├─→ ИнтеграцияЗадач.ПриЗаписиЗадачи (подписка)
  │     ├─→ ИнициализироватьКонтекстИзменения...
  │     ├─→ ЗаполнитьКонтекстИзмененияРеквизитов
  │     └─→ ОбработатьИзменения...ПриОбновленииПоИсточнику
  │           ├─→ РС ИсторияЗадач (Добавить)
```
