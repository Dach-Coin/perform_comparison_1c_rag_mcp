- 8 типов уведомлений, 16 состояний, 3 версии формата

**Что пришлось додумывать (домыслы):**
- Реальные типы XDTO (объекты communication, container, notification, acknowledgment и их поля) — читались из кода, не из схемы XDTO (схема не раскрыта в индексе)
- Детали конфигурирования FTP (пароль, сервер) — не читались, только наличие полей
- Смысл константы АвтоматическиОтправлятьКвитанцииМЭДО — тип Boolean предполагается по названию

**Чего не хватило:**
- Типы XDTO пакетов (XDTO-схемы IEDMSMessage/IEDMSContainer) — не раскрываются в индексе (хранятся как ссылки на XSD)
- Роли и их права в деталях (Роль БазовыеПраваМЭДО, РаботаСМЭДО) — не в индексе
- HTTP-сервиса специфически для МЭДО — обнаружено, что его нет (подтверждено поиском)
