## Субъективная оценка

- **Ответ на вопрос:** ЧАСТИЧНО
- **Что получено из MCP:** полный список модулей МЭДО, процедуры обмена, регламентное задание, константы, реквизиты документов КвитанцияМЭДО и ДанныеДокументаМЭДО из кода, реквизиты УведомлениеМЭДО из кода.
- **Что пришлось додумывать:** точный список всех реквизитов документов (metadatasearch не работает — нет структурированных метаданных объектов); табличные части документов (не обнаружены в чанках); наличие/отсутствие HTTP-сервисов (вывод сделан из анализа кода).
- **Какой информации не хватило:** metadatasearch полностью нерабочий (все 4 вызова пустые) — это системная проблема сервера. Нет прямого доступа к метаданным (реквизиты, ТЧ) объектов по имени. Информацию о реквизитах пришлось извлекать из кода (структуры данных в МЭДОСтруктурыДанных).
