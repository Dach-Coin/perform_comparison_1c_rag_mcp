- Полная структура метаданных всех 5 объектов: ВходящееПисьмо, БП.Рассмотрение, БП.Исполнение, ЗадачаИсполнителя, ИсходящееПисьмо

- Структура модуля СтартПроцессовСервер
- Механизм связей ИсходящееПисьмо→ВходящееПисьмо через РС.СвязиОбъектов и ТипыСвязей
- Справочник Резолюции с полной структурой реквизитов

### Что пришлось додумывать
- Точная последовательность вызовов внутри карты маршрута (читал только заголовки процедур)
- Детали заполнения БП.Исполнение из резолюции (метод СформироватьИсполнениеОбработка не был вскрыт до строк)

### Чего не хватило
- Тело процедуры `СформироватьИсполнениеОбработка` (как именно создаётся БП.Исполнение из резолюции)
- Точные поля РС.ХодОбработки, записываемые при каждом шаге (только структура, не код записи)
- Подробности адресации задач через РС.ИсполнителиРолей
