  - Значения перечислений ВариантыМаршрутизацииЗадач и РезультатыСогласования

  - Полный перечень общих модулей, участвующих в логике (кроме РаботаСВизамиСогласования и РаботаСКомплекснымиБизнесПроцессами — остальные выведены из контекста)
