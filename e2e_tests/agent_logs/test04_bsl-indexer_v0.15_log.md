## Субъективная оценка

**Ответ на вопрос: ПОЛНОСТЬЮ**

Все четыре подвопроса закрыты данными из MCP:
1. **Регистры накопления** — полностью: КоличествоЗадач (все измерения и ресурсы) и КоличествоДействийЗадач (все измерения и ресурсы)
2. **Регистры сведений** — полностью: ДействияЗадач, ВсеИсполнителиДействийЗадач, ЗадачиПоАвторам с ключевыми ресурсами
3. **Код записи** — полностью: ОбработкаПроведения, ПриЗаписи, ОбработкаПроведения/ДействиеЗадачи, RecordSetModule методы, ЗаполнитьНаборПоДействию
4. **Смена статуса** — полностью из ПриЗаписи (блок ОбновитьДействияПоСостоянию) и ОбработатьИзменениеСостоянияЗадачи

**Что пришлось додумывать:**
- Точные числовые изменения при каждом переходе статуса (±1 в каждом ресурсе) выведены логически из RecordSetModule.ОбновитьДанныеЗадачи, т.к. полный обход всех методов ОтметитьВРаботе/ОтметитьВыполнена потребовал бы ещё 6-8 вызовов
- Список ресурсов РС.ДействияЗадач получен частично (читали строки 170-600 из 1987)

**Чего не хватило:** Полный список ресурсов РС.ДействияЗадач (файл 1987 строк, читали только первую треть). Также не исследовались ИсторияЗадач и другие вспомогательные регистры.
